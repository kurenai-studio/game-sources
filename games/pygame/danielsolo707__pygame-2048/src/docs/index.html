About this project

This started as a single-file Pygame 2048 clone. Its board logic is separated from the UI so it can be tested without a display, and this site ships a matching browser demo for visitors.

Desktop (Python)

python main.py after installing requirements. Score persists in a local file.

Logic tests

Merge rules, win/lose detection, and scoring covered by pytest.
