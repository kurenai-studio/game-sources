# Как заменить сторонние библиотеки

Через LibGDX/LWJGL игра использует неизменённые JLayer 1.0.1-gdx, JOrbis 0.0.17 и OpenAL Soft. Их LGPL-лицензии и исходники лежат рядом с игрой, а также внутри JAR в `META-INF/third-party-sources/`.

В заголовках Java-исходников указана LGPL версии 2 или новее; Maven-метаданные могут указывать LGPL 2.1. Тексты лицензий приложены. Они относятся к этим библиотекам, а не автоматически ко всему коду ElMagica. Ограничений на изменение библиотек или обратную разработку объединённой программы для отладки таких изменений здесь не добавляется.

## Что приложено

- `jlayer-1.0.1-gdx-sources.jar` и `jorbis-0.0.17-sources.jar` — соответствующие исходники из Maven вместе с POM. Source JAR открывается как обычный ZIP.
- `jlayer-gdx-build.zip` — исходники проекта с POM для сборки и сериализованным ресурсом декодера. Ссылка на конкретный коммит есть в манифесте лицензий.
- `openal-soft-1.25.2.zip` — исходники версии с файлами CMake. Все включённые платформенные библиотеки сообщают `1.1 ALSOFT 1.25.2`; результаты лежат в `docs/openal-versions.json`.
- `openal-soft-lwjgl-build.zip` — зафиксированная версия форка LWJGL с workflow сборки. Это материал для сборки, но строка версии готовой библиотеки не раскрывает точный исторический CI-коммит. Совпадение пересобранного файла байт в байт не проверялось.

Ссылки и SHA-256 записаны в `docs/third-party/manifest.json` в исходниках проекта; в архиве игры — в `third-party/manifest.json`.

## Java-кодеки

Собери исходники кодека через JDK. У JLayer есть Maven POM; при упаковке сохрани `resources/sfd.ser`. Исходники JOrbis можно собрать через `javac` и упаковать через `jar`.

Поставь свой JAR первым в classpath:

```text
java -cp "modified-codec.jar;ElMagica-Beta1.0.jar" com.elmagica.game.lwjgl3.Lwjgl3Launcher
```

На Linux/macOS разделитель — `:`, а не `;`.

Другой вариант — взять исходники ElMagica, заменить нужную Gradle-зависимость локальным JAR и пересобрать игру. Для своего изменённого файла нужно обновить данные проверки зависимостей. Сама игра использует WAV, но LibGDX также поставляет кодеки MP3/OGG.

## OpenAL Soft

Распакуй исходники OpenAL и следуй их README и инструкции CMake для своей системы. Базовые команды:

```sh
cmake -S . -B build
cmake --build build --config Release
```

Укажи LWJGL путь к своей ABI-совместимой библиотеке:

```text
java -Dorg.lwjgl.openal.libname="/absolute/path/to/library" -jar ElMagica-Beta1.0.jar
```

Нужен реальный путь к DLL, `.so` или `.dylib` для твоей системы. Для каталогов поиска нативных библиотек также есть `org.lwjgl.librarypath`.

Архив не подписан, защиты от замены библиотек нет. Эти способы основаны на настройках LWJGL; отдельный изменённый кодек или OpenAL во время проверки публикации не собирался.
