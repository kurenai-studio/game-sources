基于 **Python + pygame** 的回合制现代联合作战推演。地图为 n×n 方块战场，每格承载海拔、地形、
设施与控制状态；玩家部署陆、海、空、天不同武器系统，通过**侦察—决策—打击**链条达成作战目标。

核心不是「数值互砍」，而是还原现代战争的信息维度：**看不见就打不着，看得见也未必打得中，
打得中也未必穿得透；打掉了对方的天基资产，精确制导也会跟着失准。**

> 📖 **完整机制说明见 [`GAME_GUIDE.md`](GAME_GUIDE.md)** —— 逐条公式、预设兵器一览、
> 编辑器操作、数据格式、战术建议与自检工具。本文只做门面与索引。
>
> 🧩 **要做模组或想定？见 [`SDK.md`](SDK.md)** —— 数据模型、规则钩子、命令流与回放 API
> 的逐项参考，附最小可跑示例。文档与代码的清单一致性由 `tools/check_sdk.py` 强制校验。

## 快速开始

```bash
pip install pygame-ce          # 或 pip install pygame
python main.py
```

**第一次玩？** 主菜单点「**快速上手**」（或按 `T`）进入教学想定，6 步带你在 3~5 分钟内
走完一遍核心循环：认识战场 → 发现识别 → 跟踪开火 → 对手视角 → 构筑工事 → 结束回合。

其他运行方式：

```bash
python main.py --check                     # 校验全部地图与武器库数据
python main.py --sim 16 --map strait_shield # 无界面双 AI 推演 16 回合
python tools/diag.py                       # 作战逻辑自检（26 条不变量）
```

环境：Python 3.10+ / pygame 2.5+。窗口可自由缩放（最小 1180×740）。

## 机制速览

四十余项机制按主题归类，完整规则见 [GAME_GUIDE 第 5 章](GAME_GUIDE.md#5-核心机制)。

### 情报与感知

| 机制 | 一句话 |
|---|---|
| **侦察—打击链** | 未发现→接触→识别→跟踪，四级情报对应四种打击权限 |
| **电子战频段** | 雷达 / 通信 / 导航三频段独立干扰与反制 |
| **电子诱饵** | 假目标骗走你的精确制导弹药 |
| **卫星过顶** | 每 3 回合过顶侦察；卫导被压制则精确制导失准 |
| **天候与时段** | 昼夜与雨雾削弱雷达 / 光学，红外优势随之翻转 |

### 火力与交战

| 机制 | 一句话 |
|---|---|
| **防空逐发拦截** | 多层防空各自结算，逐发消耗备弹与通道 |
| **防区外打击** | 远程弹药有飞行时间，途中目标机动或情报中断都会脱靶 |
| **弹道导弹与多段拦截** | 上升段 / 中段两轮 / 末段各有窗口；破片命中只是打残，弹头可能带伤突防 |
| **信火一体** | 指挥所下达集中火力，下级单位受领后协同交战 |
| **火力准备** | 先标定射界，再按准备度加成射击 |
| **多管齐射** | 齐射可提高命中率，但受备弹与上限约束 |
| **兵种相克** | 破甲 / 爆破两条通道与目标硬度连续匹配：坦克炮打坦克是打散兵的 1.6 倍，榴弹打坦克只剩六成 |
| **交叉火力** | 直瞄武器从 ≥3 个方位扇区压制同一地面目标才有加成；据守在工事里的最怕这个 |

### 部署与战场

| 机制 | 一句话 |
|---|---|
| **同格共存** | 空中单位可与地面部队同格（空中支援地面）；地面之间仍互斥 |
| **野战工事** | 就地构筑三级工事，按**工时**推进（Lv1/2/3 = 1/2/3 工时）；打塌后重建要先清障 |
| **烟幕与风** | 遮蔽目标格并**随风漂移**：8 方位、0–3 级，雨雪吹散得快、雾天糊在原地 |
| **基地与后勤** | 油 / 弹 / 备件都是实数库存；断补给一天就只能单发点射，三天后命中率与拦截通道一起掉 |
| **设施打击** | 摧毁机场 / 港口 / 雷达站，让对手的体系瘫掉 |

### 复现与扩展

| 机制 | 一句话 |
|---|---|
| **对局回放** | 想定 + 对局种子 + 命令流 = 完整重演任意一局，逐项一致 |
| **AI 对战观战** | 双方 AI 自动打完整局，你只看不打：可暂停、调倍速、跳回合、一键存回放 |
| **可分享想定包** | `.bwscn` 带逐文件 sha256 与版本号，缺图也能完整重演 |
| **可复现随机** | 所有随机判定由对局种子派生，同种子必得同结果 |
| **模组接口** | 第三方 Python 模块可注册新武器、新兵种并订阅规则钩子 |
| **规则钩子** | 想定 JSON 可声明「条件 + 效果」规则——不写 Python 也能做模组 |
| **战术体检** | `--check` 不只查结构：目标点谁也打不到、制高点一边倒、防空伞漏成筛子都会点名 |
| **AI 战术** | 会改主意、会认输、会配合：目标转移、分档撤退、集火接力、交叉火力、佯攻牵制 |

### 内容与性能（v2.1）

| 机制 | 一句话 |
|---|---|
| **战役编辑器** | 可视化编排多关卡战役：关卡顺序、难度曲线、跨关继承策略 |
| **单位图标包** | 兵种图标可替换成自制资源包，一套素材按阵营着色通用 |
| **分块渲染** | 大地图只渲染视口内的地形块，内存与地图尺寸脱钩 |
| **增量探测** | 空间索引 + 世代号缓存，只重算状态真正变化的目标 |

## 想定与数据

全部数据都是**可编辑的 JSON**，改完重启即生效——不需要改代码。

```
data/
  maps/*.json           想定文件（training_ground 教学想定、strait_confrontation 大型战役）
  units/armory.json     武器库（兵种 / 武器 / 传感器）
  campaigns/*.json      战役定义（多关卡串联）
  icon_packs/*/         单位图标包（pack.json + 各兵种 PNG）
  lang/*.json           语言包（8 种语言 + <代码>_ui.json 界面分层包，可被用户数据目录覆盖）
```

**想自己造战役？** 两种方式：

1. **可视化编辑**——主菜单「地图 / 武器编辑器」，支持框选批量编辑与框选刷地形；
2. **写 JSON**——照抄一份现有想定改。格式速查见
   [GAME_GUIDE 第 13 章](GAME_GUIDE.md#13-数据文件格式)。

**想做多关卡战役？** 编辑器新增「战役编排」标签页：左边排关卡、右边填内容，
底部有难度曲线。多关之间的**难度**与**继承策略**（全继承 / 只继承精锐 / 独立）
都能在界面上直接设——不用写一行 JSON。

**分享想定**——编辑器与系统菜单都能导出 `.bwscn` 想定包；主菜单「导入想定」
可挑选安装。社区包放进用户数据目录的 `packages/` 即可。


CI 在 Python 3.10–3.13 × Ubuntu/Windows 矩阵上跑完整校验（3.9 未纳入矩阵，故不作支持承诺）；布局自检与冒烟测试
会在回归发生时直接让流水线失败。

自检脚本会把用户数据目录重定向到临时目录，**不会污染你的设置与存档**。
需要手动隔离时设 `BLOCKWARGAME_USER_DIR=<路径>` 即可；无声卡环境另加
`SDL_AUDIODRIVER=dummy` 与 `BLOCKWARGAME_NO_AUDIO=1`。

## 开发与打包

```bash
git clone <repo> && cd freebird-block-wargame-py
python -m pip install -r requirements.txt
```

工作流：`main` 分支受保护 → `feature/<主题>` 分支开发 → PR 触发 CI（多版本 + 多平台）
→ 合并后打 `v*` 标签触发发布流水线。

```bash
python packaging/make_portable.py    # 生成便携版（单文件 .pyz）
python packaging/build_linux.sh      # 生成 Linux 安装包
powershell packaging/build_windows.ps1   # 生成 Windows 安装包
```
