# v1.4.0 — Action-skill 剑舞连携与守卫技能

- 开局解锁 Q「折光穿枝」、R「藤芽升锋」、F「露华回旋」，支持地空连携、独立冷却与光能仲裁。
- 露冠守卫新增「折冠散晶」「根庭绽刺」「露冠辉落」，保留冲锋与根浪；普通 48 生命、挑战 64 生命，固定预警与反击窗口。
- 专用 ACTION-A 动作、约束剑路、发力链、技能音色和固定容量特效；安全开场提供可重复、可跳过训练。
- Q/R/F HUD、旅程说明、难度设置；Boss 重试键改为 **T**。旧存档兼容，新技能直接可用。
- 生产构建移除动作与技能实验室；源码保留开发预览和复现脚本。

## 验证

76 项单元测试、82 项浏览器回归、格式检查、TypeScript 与生产构建通过。原生 WebGPU 在 AMD RDNA 3 实际执行。72 组既有击飞与受身配对无根部或控制恢复差异；10/20/60 fps 固定输入轨迹一致。

三轮配对 P95 中位数：普通游玩主线程 6.2→6.4 ms；技能平台 5.6→6.1 ms；击飞恢复 6.4→7.0 ms；守卫技能战 7.6→7.9 ms。帧间隔均为 33.4→33.4 ms，这是本机 headless 测量结果，不表示保证 60 fps。显示对象与纹理计数稳定。

## 附件与限制

- `action-skill-v1.4.0-review.zip`：26 段同步对照录像、关键姿势、review.html。解压后打开，可切换正常和四分之一速度。
- `action-skill-v1.4.0-evidence.zip`：性能原始数据、兼容性、几何、WebGPU、生产验证与最终检查日志。
- 旧版没有 Q/R/F、新招及挑战难度，对照保留旧版真实行为。录像定位场景并保护生命，用于动作观察；完整通关由浏览器回归另行验证。
- 动作观感请结合正常与慢放录像评估。仅支持桌面键盘；WebGPU 不可用时回退 Canvas；Phaser 主包仍较大。
