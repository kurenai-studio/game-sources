# Arrows and Boxes

A game about arrows and boxes made for the [Defold Game Jam 2026](https://itch.io/jam/defold-game-jam-2026)

## Assets

Most assets were made by [@Waffeln](https://x.com/waffeln3210)

Except for:

- `assets/audio/footsteps.ogg` - https://kenney.nl/assets/impact-sounds
- `assets/audio/impact_plank.ogg` - https://kenney.nl/assets/rpg-audio
- `assets/audio/burn.ogg` - https://www.zapsplat.com/music/small-sudden-flame-burst-burn-blow-1/
- `assets/fonts/Kenney Mini Square Mono.ttf` - https://kenney.nl/assets/kenney-fonts
- `assets/textures/input_prompts.png` - https://kenney.nl/assets/input-prompts-pixel
