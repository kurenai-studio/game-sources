# 🔨 Whack-a-Mole

🔨 Whack-a-Mole — a modern, dependency-free HTML5 game built with Canvas and vanilla JavaScript.

🎮 **Play Online:** https://gamelabz.github.io/html5-game-whack-a-mole/

## 📸 Screenshot

![Whack-a-Mole](assets/images/screenshot.png)

## 🎯 About

Moles pop up fast and random — smack them before they duck to build combos and beat the clock.

## 🕹️ Controls

- Whack: Click / Tap a hole
- Start: button
- Restart: R

## ✨ Features

- Random mole spawning with timing
- Score streaks and combo multiplier
- Countdown timer and game-over screen

## 🚀 Run Locally

No installation required. Open the game directly in a browser:

```bash
# Option A: just open the file
open index.html

# Option B: serve it with a tiny static server
npx serve .
```

Then visit the printed URL (default `http://localhost:3000`).

## 🛠️ Tech Stack

- HTML5 `<canvas>`
- CSS3 (custom properties, flexbox, glassmorphism)
- Vanilla JavaScript (ES2020, no frameworks)
