# 🧱 BlockWorld

**A first-person 3D voxel sandbox built with Java and libGDX.**

BlockWorld is a small, playable 3D sandbox where you can explore a procedurally generated block world, mine and place blocks, and build structures limited only by your imagination.

This project started as a hands-on game development experiment to learn Java, 3D graphics, game physics, and world generation.

## 🎮 Features

- First-person camera and mouse look
- Procedurally generated block terrain
- WASD movement, jumping, and gravity
- Block mining and placement
- Grass, dirt, and stone blocks
- A simple three-slot hotbar

## 🕹️ Controls

| Control | Action |
|---|---|
| W / A / S / D | Move |
| Mouse | Look around |
| Space | Jump |
| Left-click | Mine a block |
| Right-click | Place a block |
| 1 / 2 / 3 | Select a block type |
| Esc | Release the mouse cursor |

## 🚀 How to Play

You'll need Git and a compatible Java Development Kit (JDK).
(Java 17 or 21 recommended).

1. Clone the repository:

   ```bash
   git clone https://github.com/kalyanpavan6817-stack/BlockWorld.git
   ```

2. Open the project folder:

   ```bash
   cd BlockWorld
   ```

3. Run the desktop game on Windows:

   ```powershell
   .\gradlew.bat lwjgl3:run
   ```

The first run may take a little longer while Gradle downloads the required dependencies.
