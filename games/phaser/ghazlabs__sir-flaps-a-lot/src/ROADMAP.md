# Roadmap

## Vision

Sir Flaps-a-Lot is a compact Phaser game used as a practical open-source contribution exercise.
The project prioritizes clear architecture, beginner-friendly contribution flow, and incremental gameplay polish.

## Current Status

- Core MVP loop is playable.
- Scene flow is implemented (`Lore`, `Menu`, `Game`, `GameOver`).
- Vite-based local development and production build are available.

## Now: OSS Baseline

- Keep contribution docs current and easy to follow.
- Maintain issue/PR templates for consistent collaboration.
- Keep lint, formatting, build, and tests healthy in CI.

## Next: Gameplay Quality

- Fix high-impact gameplay consistency issues.
- Improve balancing and readability across devices.
- Add small quality-of-life upgrades requested by contributors.

## Later: Polish and Extensibility

- Add richer visual and audio feedback.
- Introduce more configurable gameplay parameters.
- Expand beginner-friendly contribution tracks.
