# Little Coaster -
## Submission for the Defold community challenge : tiny worlds
forum: https://forum.defold.com/t/community-challenge-tiny-worlds/81931

All assets were made from scratch for the challenge. 
**Exercises completed:**
- world building
- modeling
- UV
- armature rigging
- animation
- texturing
- Defold pbr integration

Texture set size - 2048x2048
* Project is not well optimized and may not run well on some devices.

-------------------
This project uses the Defold PBR core extension

extension: https://github.com/defold/defold-pbr
Live demo: http://defold.com/defold-pbr/
