# ACTION-A-DOLL-HIT：分级受击与布娃娃击飞

基于第五轮工作区开发，随 v1.2.0 发布。下述基线、录像和性能原始文件为本机验收材料，不随源码克隆；发布录像见 GitHub Release 附件。开发预览需要本地运行。

## 运行与体验

```powershell
cd C:\VSC\github\NEW-project-1
npm ci
npm run dev
```

- 游戏：<http://127.0.0.1:5173/>
- 开发动作预览：<http://127.0.0.1:5173/?action-a>
- 对照录像：<http://127.0.0.1:5173/artifacts/action-a-doll-hit/review.html>
- 预览选择主控及“受击”类型，可切换方向、空中起始、慢放、暂停、步进和自动受身；按钮或空格 / Shift 手动受身。
- 游戏受击后，短暂失控结束可按空格或 Shift 受身。这个按键只执行恢复，不同时跳跃、冲刺，也不重置技能冷却。

| 来源 | 水平 / 上抛速度（px/s） | 失控 | 弹跳上限 |
| --- | --- | --- | --- |
| 苔影 | 180 / 120 | 0.18 s | 0 |
| 玻璃蛾 | 320 / 240 | 0.30 s | 1 |
| 守卫冲锋 | 620 / 400 | 0.30 s | 2 |
| 根浪 | 280 / 590 | 0.30 s | 2 |

提前 0.12 秒输入可以缓冲受身；受身过渡为 0.12 秒。自动流程最长 2.2 秒，累计翻转最多两圈。减少动态降低视觉翻转及装饰摆动，保留实际冲量与恢复窗口。

## 模块结构

- `src/action-a/doll-hit/state.ts`：`HitContext`、`DollHitProfile`、`DollHitState`、统一冲量配置及状态机。状态依次经过冲击、空中失衡、接触弹跳、翻滚、起身；受身可提前退出。
- `src/action-a/doll-hit/solver.ts`：`DollPose` 与四个复用惯性端点。以最多 1/120 秒子步积分，经关节方向锥和双段 IK 约束保持骨段长度。
- `src/action-a/actor.ts`：从上次最终姿态进入，旋转身体、求解四肢、保持剑身刚性和握柄绑定，对支撑面进行整体抬升修正，最后提交既有 Canvas 合成。退出清空惯性端点、脚部锚点和旧刀光。
- `src/main.ts`：负责扣血、120 Hz 根部运动、平台跨步接触、竞技场边界、输入消费和检查点恢复。伤害通过保护检查后才创建实例；倒地不会再次扣血。未恢复期间延续保护。
- `src/boss.ts`：原布尔命中结果保留，附带冲锋 / 根浪方向及命中实例。普通敌人由原类型映射。
- `src/action-a/preview.ts`：开发预览；生产分支不加载预览。展示阶段、速度、弹跳、受身窗口、约束误差及既有骨骼诊断。

模拟暂停会冻结状态；传送、重生和重新开始清空实例。状态不序列化，旧存档不需要迁移。致命伤及坠落仍立即执行既有安全恢复。

## 复现验证与素材

```powershell
npm test
npm run test:e2e
npm run format:check
npm run build
# 单独终端：第五轮快照服务
npx vite artifacts/action-a-doll-hit/baseline --host 127.0.0.1 --port 5179
# 性能测试应独占浏览器测量，避免同时录制
node scripts/action-a-doll-performance.mjs
node scripts/action-a-doll-review.mjs
```

基线清单为 `artifacts/action-a-doll-hit/baseline.json`，对应第五轮本地源码，而非远程 v1.1.0。

录像使用固定随机种子和镜头，120 Hz 模拟 / 动作更新，30 fps 编码。四种伤害各 6 秒，先自动起身，再输入受身；基线播放相同命中指令，保留旧版实际响应。`before` / `after` 下保存视频、关键姿势图和逐帧根部记录。对照页提供正常 / 四分之一速度同步从头播放。

性能原始结果存于 `performance.json`：普通场景与连续击飞各三轮配对，预热两秒，保留主线程、帧间隔、动作、约束和绘制原始数据。分配量采用堆采样估计，不能视为精确对象分配总量。约束求解仍有少量临时 IK 结果分配；角色纹理与显示对象使用固定池。

## 验收范围

本次结果：56 项单元测试、70 项完整浏览器回归通过，无跳过；新增预览根部轨迹后另行复跑 4 项模块浏览器测试通过。格式检查、TypeScript 和生产构建通过。原生 WebGPU 回归在本机实际执行，生产模式确认没有预览 / 调试入口、无资源错误。

三轮 P95 中位数：普通场景主线程 5.1 → 5.1 ms，连续击飞 5.3 → 5.5 ms（约 +3.8%）；两场景帧间隔均为 33.4 → 33.4 ms。对象与纹理数量稳定，满足本轮预算。这是本机无头浏览器测量，不代表所有设备。

左右朝向四种击飞的逐步几何采样：固定画布越界为 0，支撑面超出允许的 2 px 鞋底范围仅浮点误差；骨段误差约 `1.4e-14` 世界像素。另有 10/20/60 fps 根部轨迹与握柄约束断言。视频各 24 秒，附 16 张关键姿势图；几何数据与录像日志保留在本地 artifacts 目录。

当前自动化覆盖冲量、实例去重、缓冲、暂停、翻转及弹跳限制、固定时间推进、骨段长度、实际伤害入口、握柄约束、Boss 冲锋、竞技场边界、攻击打断、死亡恢复，以及原有完整回归。最终结果见同目录 `acceptance.json`。

这是一套受约束的角色布娃娃表现：根部参与游戏平台碰撞，四肢采用当前支撑面的有限修正；并非任意地形、多刚体互撞的通用物理引擎。自动化约束测试不能替代关节遮盖、贴图裁切及退出自然度的完整人工检查。视觉自然度仍待用户通过正常速度和慢放对照确认。
