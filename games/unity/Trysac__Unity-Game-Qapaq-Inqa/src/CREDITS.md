# Credits

## Code base

The first version of this game (2021) was a university homework built on the "TileVania"
project of the GameDev.tv *Complete Unity 2D Developer* course, released under the MIT licence
by EmbraceIT Ltd. trading as GameDev.tv. That notice is kept in [`LICENSE`](LICENSE). The
game has since been rewritten; the course's ideas (a run-and-jump platformer with ladders,
coins and a level exit) remain at its root.

## What the game uses

Everything in the game was made for this project; no third-party assets are included.

| Asset | Where | How it was made |
|---|---|---|
| Sprites, tile sets, backdrops, app icon | `Assets/Art` | Drawn by `tools/art/build.py` (Python standard library) |
| Music (five pentatonic tracks) and sound effects | `Assets/Audio` | Synthesized by `tools/audio` (Python standard library, encoded with ffmpeg) |
| Scene, UI panel settings, player settings | `Assets/Scenes`, `Assets/UI` | Generated by `Assets/Editor/ProjectBuilder.cs` |
| HUD and menu style | `Assets/UI/Hud.uss` | Written for this project |
| Codex texts | `Assets/Scripts/Core/Levels.cs` | English rendering of the original game's Spanish notes |
| Font | — | Unity's default runtime font |

## Removed third-party content

Earlier versions of this repository (before the `fix/asset-licensing` changes) contained
content that may not be redistributed in a public repository, or whose origin was not recorded:

| Content | Why it was removed |
|---|---|
| Unity Asset Store packages under `Assets/Imports`: Pixel Adventure 1 and 2, Pixel Art Platformer - Village Props (Cainos), Bandits - Pixel Art, Painted HQ 2D Forest Medieval Background, Pixel Potions, 2D Trees, 2d Free Pixel Art Realistic Crystals Pack, GrottoEscape2, Standard Assets (CrossPlatformInput, 2d-extras, Open Sans), listed in `Assets/Assets_Unity_Store.txt` | Covered by the Asset Store EULA, which does not allow redistributing the files in a public repository. None shipped a CC0 licence file. The two permissive pieces (Unity's MIT `2d-extras` and the Apache-licensed Open Sans font) were no longer used and went with their package. |
| `Assets/Audio/melodia INCA.mp3`, `_agic.ogg`, `_oin.ogg` | Music and sounds of unknown origin. |
| `Assets/Fonts/_NCANTAT.TTF` | Display font of unknown origin and licence. |
| `Assets/Sprites And Tiles` (the `SPA_*` sprite sheets, the Inca mask, door, heart, artifact and message images) | Origin not recorded; the mask image appears to come from the web. |
| Scenes, prefabs and animations built on the above, and `QapaqInqa_Game_Captures/` | They only showed or used the removed art. |

These files remain in the git history, which was not rewritten.
