# Whale Coin Collector 🐋🪙

A simple and fun arcade-style game built with **Phaser 3**. Collect as many coins as you can as a happy swimming whale!

## 🎮 Features
- **Animated Sprites:** Hand-crafted whale and spinning coin animations.
- **Custom UI:** Custom game frame for a polished, retro look.
- **Dynamic Scoring:** Your score updates in real-time as you collect coins.

## 🚀 How to Play
1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/whale-coin-collector.git
   ```
2. **Open `index.html`** in your browser (or use a local server like `http-server`).
3. **Controls:** Use the **Arrow Keys** to swim around and collect the coins.

## 🛠️ Built With
- [Phaser 3](https://phaser.io/) - A fast, free, and fun open source framework for Canvas and WebGL browser games.
- Vanilla JavaScript & CSS.

## 🎨 Assets
- **Whale & Coin Sprites:** Custom pixel art.
- **Game Frame:** Custom themed overlay.
