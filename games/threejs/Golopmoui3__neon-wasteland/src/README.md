# NEON WASTELAND ⚡

Процедурный 3D-шутер на выживание в неоновых Пустошах. Чистый Three.js, без сборки и без ассетов — вся графика и звук генерируются кодом.

## Запуск

Двойной клик по `start.bat` (нужен Python или Node.js — любой из них).

Вручную: любая папка-сервер, например `python -m http.server 8137`, затем открыть [http://localhost:8137](http://localhost:8137).

> Прямо открывать `index.html` двойным кликом нельзя — браузеры блокируют ES-модули с `file://`.

## Что внутри

- **Открытый процедурный мир** ~600×600: рельеф на fbm-шуме, неоновый лес, кристаллы, горы по краю, арена с Маяком в центре
- **Волны врагов** с четырьмя типами ИИ: Грунт, Спринтер, Плевун (стреляет), Громила
- **Боссы каждые 5 волн** с ударной волной и толстым HP
- **3 оружия**: плазма-пистолет (∞), дробовик «Гром», рельсотрон «Копьё» (пробивает насквозь)
- **Прокачка**: уровни за XP, монеты, лут (монеты/аптечки/патроны) с магнитом
- **Магазин у Маяка** [E]: HP, урон, скорострельность, скорость, патроны — цены растут
- **9 квестов** с наградами
- **День/ночь** (цикл 150 с): солнце, звёзды, неон ярче ночью
- **HUD**: миникарта, киллфид, цифры урона, покачивание камеры, screen shake
- **Звук**: полный синтез через WebAudio — ни одного аудиофайла
- **Сохранения**: прогресс (волна, уровень, монеты, прокачка, квесты) живёт в localStorage — «Продолжить» на стартовом экране
- **8 достижений** с тостами и счётчиком на экране смерти
- **CI**: смоук-проверка синтаксиса и целостности на каждый push

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | движение |
| Мышь / ЛКМ | обзор / огонь |
| Shift / Space | бег / прыжок |
| 1 2 3 | смена оружия |
| E | магазин (у Маяка) |
| M | крупная миникарта |
