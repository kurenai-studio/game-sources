# ❌⭕ Tic-Tac-Toe

❌⭕ Tic-Tac-Toe — یک بازی HTML5 مدرن و بدون وابستگی، ساخته‌شده با Canvas و جاوااسکریپت خالص.

🎮 **بازی آنلاین:** https://gamelabz.github.io/html5-game-tic-tac-toe/

## 📸 تصویر بازی

![Tic-Tac-Toe](assets/images/screenshot.png)

## 🎯 درباره بازی

هوش مصنوعی شکست‌ناپذیر minimax را در صفحه ۳×۳ شکست بده، یا اگر می‌توانی به تساوی بسنده کن.

## 🕹️ کنترل‌ها

- گذاشتن علامت: کلیک روی خانه
- انتخاب نشان / شروع‌کننده: دکمه‌ها
- شروع دوباره: R

## ✨ ویژگی‌ها

- هوش مصنوعی minimax شکست‌ناپذیر
- تشخیص برد/مساوی با نمایش خط برنده
- شمارنده پیروزی/شکست/مساوی ماندگار

## 🚀 اجرا در محیط محلی

نصبی لازم نیست. بازی را مستقیماً در مرورگر باز کن:

```bash
# روش اول: باز کردن مستقیم فایل
open index.html

# روش دوم: سرویس با یک سرور استاتیک کوچک
npx serve .
```

سپس به نشانی چاپ‌شده مراجعه کن (پیش‌فرض `http://localhost:3000`).

## 🛠️ تکنولوژی

- HTML5 `<canvas>`
- CSS3 (متغیرهای سفارشی، flexbox، گلس‌مورفیسم)
- جاوااسکریپت خالص (ES2020، بدون فریم‌ورک)
