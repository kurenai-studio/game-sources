# Snapping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pieces dropped beside their true neighbour join into clusters that move as one, clusters dropped on their place lock there, and the board signals joins, locks and completion.

**Architecture:** A node-free `PuzzleState` (`src/game/puzzle_state.gd`) holds union-find clusters over piece ids, one shared offset per cluster and a locked flag, and applies the lock and join rules in `drop()`. The board keeps one `PieceNode` per piece id, lifts every node of the touched cluster, writes the cluster's offset to the state on each move, and on every release calls `drop()` and then moves, raises or re-parents the nodes and emits signals. Locked nodes live in a `LockedPieces` layer under `Pieces`, so the existing hit-test loop never sees them.

**Tech Stack:** Godot 4.7.2, GDScript, Mobile renderer. Tests are plain headless scripts extending `BaseTest`.

**Spec:** `docs/superpowers/specs/2026-11-02-snapping-design.md`. Also read `INTENT.md` and `AGENTS.md`.

## Global Constraints

- Godot 4.7.2, GDScript, Mobile renderer. Android only. Package name `io.github.aaryash_shakya.pieceful`, do not change it.
- `PuzzleState` depends only on `CutPiece` and Godot value types: no nodes, no scenes, no engine random. It never stores outlines, bounds or other geometry.
- A piece node's `position` is exactly its cluster's offset from home. Pieces never rotate.
- Tolerance: `maxf(10.0, 0.22 * sqrt(width * height / piece_count))` image pixels, with the cut's actual piece count. "Within" means `<=`.
- A drop checks the lock first, then joins. Joins and locks are checked on drop only, never while dragging.
- Every release of a held cluster is a drop: finger up, cancelled touch, focus out and pause.
- A drag event allocates nothing and moves at most the held cluster's nodes.
- Out of scope: sound, vibration, effects other than the lift shadow, saving, cleanup, setup screen, slots, a cached locked-piece image. Do not change `src/cut/` or `Scatter`.
- Run `godot --headless --import` after adding any file with a new `class_name`, then `godot --headless --script tests/<name>.gd`. A passing run prints `0 failure(s)` and exits 0.
- Match the surrounding code style, sparse comments that explain why. Conventional commits, one per task.

## Review Focus

- A touch the system cancels, or the app pausing, while a cluster is held near home: the cluster still locks, so no loose cluster rests on its place (Task 3, `_test_release_by_cancel_or_pause_drops`).
- A drop aligned with both its home and a loose neighbour: it locks and does not join, and the neighbour stays where it was (Task 2, `_test_lock_wins_over_join`).
- A drop whose alignment with a cluster is only through another cluster that joins in the same drop: all of them join in that one drop, whatever order neighbours are listed in (Task 2, `_test_multi_join_spreads`).
- The holding finger lifting while a second finger is down (the hold-and-pinch path): the release applies the join and lock rules like a plain finger up (Task 4, `_test_holding_finger_lift_joins`).
- Edge pan while a cluster is held: every member follows the camera, not only the touched piece (Task 4, `_test_edge_pan_carries_cluster`).

  - inner `class DropResult` with `var root := -1`, `var joined := false`, `var locked := false` (referenced as `PuzzleState.DropResult`)

### Task 2: Joining clusters on drop

**Files:**
- Modify: `src/game/puzzle_state.gd` (`drop`), `tests/test_puzzle_state.gd`

**Interfaces:**
- Consumes: everything Task 1 produces.
- Changes: `drop(piece)` for a loose cluster not within the tolerance of zero now joins. `DropResult.root` is the merged cluster's root and `joined` is true when at least one cluster joined. No new public names.

The rule, which the tests pin and which must not depend on the order of any neighbour list:

```text
dropped := offset of the dropped cluster as it was dropped
joining := the dropped cluster's root; absorbed := []
spread from every piece of every cluster in joining: for each neighbour q, r := find(q);
    if r is not in joining, r is loose, and offset(r).distance_to(dropped) <= tolerance:
        add r to joining and absorbed, and spread from r's pieces too
if absorbed is empty: return (root, joined = false, locked = false)
target := offset of the absorbed cluster with the most pieces, ties to the lowest root id
new_root := root of the cluster in joining with the most pieces (dropped one included), ties to the lowest root id
every other root in joining gets new_root as parent; new_root's members are all their members, ascending
new_root's offset := target exactly
if target.length() <= tolerance: lock new_root (offset Vector2.ZERO)
return (new_root, joined = true, locked = whether it locked)
```
