# store-ops — עלייה לחנויות (סביבת עבודה, לא המשחק)

תיקייה זו היא **לוח העבודה** לסטנדרטי Google Play ו-Apple App Store.

- אין כאן לחיצת Publish, תשלום, או כניסה לחשבונות.
- קובץ המשימות החי: [`TASKS.md`](TASKS.md)
- רשימת הפרמטרים: [`PARAMETERS.md`](PARAMETERS.md)

כשתבקש כאן בצ'אט **«עדכן רשימת משימות»** — הסוכן מעדכן את `TASKS.md` לפי מה שבוצע / נחסם / נשאר.
