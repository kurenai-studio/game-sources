# The Coffeehouse Always Wins

Simple roguelike game revolving around brewing coffee with random beans and ingredients. Made for [Godot Wild Jam 92](https://itch.io/jam/godot-wild-jam-92), with the theme "brewing".

Made with:
* [Godot Engine](https://github.com/godotengine/godot) 4.6.2
* [GIMP](https://gitlab.gnome.org/GNOME/gimp-data)
* [Furnace](https://github.com/tildearrow/furnace)

Running and exporting requires Godot.
