# Feed Mother

Short isometric horror interactive fiction game with platforming elements. Contains 4 endings, all of which can be obtained in a few minutes.

Made for the Hawktober Horrors 2026 game jam with:
* [Godot](https://github.com/godotengine/godot) 4.7.2
* [GIMP](https://gitlab.gnome.org/GNOME/gimp)
* [Furnace](https://github.com/tildearrow/furnace) by tildearrow
