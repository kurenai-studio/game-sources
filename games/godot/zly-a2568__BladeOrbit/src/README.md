# 暗夜斧旋 (Whirling Dread)

一款使用 Godot 4 引擎制作的 **俯视角幸存者类（Survivor-like）** 动作小游戏。

你扮演一名手持旋转战斧的勇士，身处四面涌来的怪物潮中。蝙蝠与幽灵从黑暗中不断逼近，你只能依靠环绕在身边的斧刃风暴杀出重围——击杀升级、拾取强化，活到最后一刻。

---

## 游戏类型

- **幸存者类（Survivor-like）**：自动攻击 + 怪物潮 + 升级强化
- 玩法方向：俯视角 2D、割草生存、子弹天堂（Bullet Heaven）

## 核心玩法

- **自动攻击**：斧头围绕角色旋转，碰到敌人自动造成伤害，无需手动瞄准
- **怪物潮**：蝙蝠（直线追踪）与幽灵（A* 寻路绕障碍）持续刷新，难度随等级递增（刷新间隔逐渐缩短）
- **经验升级**：击杀敌人获得经验，解锁更高难度与更猛烈的敌人潮
- **随机掉落**：敌人死亡后 50% 概率掉落强化道具（基于权重的别名采样算法），增益包括：
  - 回血（+2 生命）
  - 增加斧头数量（最多 15 把）
  - 提升斧头转速
  - 提升暴击倍率 / 暴击概率
- **打击反馈**：受击闪红、镜头震屏、飘字伤害数字

## 操作方式

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 |
| 攻击 | 自动，无需操作 |

## 环境要求

- Godot 4.7 或更高版本（使用 GDScript）

## 运行方式

1. 用 Godot 打开项目根目录（`project.godot` 所在目录）
2. 直接运行主场景（`F5`）即可游玩

## 项目结构

```
fight/
├── project.godot          # 项目配置（名称、输入、渲染、物理引擎）
├── Autoload/
│   └── SoundManager.gd    # 音效管理（战斗 / 拾取 / 受击）
├── Resource/
│   ├── Terrain.tres       # 地形 TileSet
│   ├── Tiles/             # 角色、怪物、斧头、道具、地形贴图
│   ├── Sounds/            # 音效（受击、激光、拾取）
│   └── Fonts/             # 字体
└── Scene/
    ├── game.tscn          # 主场景
    ├── player.gd          # 玩家：移动、生命、等级、受击无敌帧、镜头震动
    ├── axe.gd             # 环绕角色的旋转斧头（伤害、暴击、飘字）
    ├── enemies.gd         # 怪物生成器 + AStarGrid2D 寻路网格
    ├── enemy.gd           # 敌人基类（受击、死亡、掉落、经验）
    ├── bat.gd             # 蝙蝠：直线追击玩家
    ├── ghost.gd           # 幽灵：沿 A* 路径索敌
    ├── item.gd            # 强化道具（权重随机、拾取加成）
    ├── attacking_number.gd# 伤害飘字
    └── knob.gd            # 摇杆（支持触屏操作）
```
