# Space Shooter

A simple arcade space shooter written in Python with [pygame-ce](https://pyga.me/). Dodge enemy ships, shoot them down, and see how long you can survive as the levels get faster.

## Run

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python space_shooter.py
```

## Controls

| Key            | Action     |
| -------------- | ---------- |
| Arrows / WASD  | Move       |
| Space          | Shoot      |
| P              | Pause      |
| Enter          | Start      |
| Esc            | Quit       |
