About Suika 2048

Suika 2048 is a browser puzzle prototype by Enis Uysal (Pengusto), inspired by 2048 and Suika Game. Slide matching tiles together to merge them and work toward 2048. Choose fruit or number themes and a 4×4, 5×5 or 6×6 board.

How to play

Use the arrow keys on a keyboard to move the tiles up, right, down or left. Select Restart to begin again. Changing the board size starts a new game.

This is a portfolio prototype with rough edges; touch controls are not implemented.
