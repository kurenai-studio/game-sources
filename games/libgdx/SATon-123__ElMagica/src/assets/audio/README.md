# Музыка и звуки

Три музыкальные петли и одиннадцать эффектов. Их создаёт `tools/generate_audio.py` на стандартной библиотеке Python — без скачанных записей и сторонних сэмплов. Формат: моно WAV, PCM 16 бит, 22050 Гц.

`menu.wav` играет в меню и у торговца, `combat.wav` — на обычных этажах, `boss.wav` — у босса. Длина петель: 46,08 / 20,48 / 15,36 секунды. В основе ре минор, арпеджио, бас, мягкий фон и ударные. Края затухают до тишины, чтобы не щёлкало при повторе.

Эффекты: выстрел мага и стрелка, попадание, полученный урон, смерть, подбор, покупка, подготовка босса, нажатие кнопки, переход этажа и уклонение. Звук подготовки босса называется `boss_cue.wav`.

Громкость музыки и эффектов отдельная, настройки сохраняются локально. Эти записи идут под MIT-лицензией проекта. Скрипт оставлен рядом с кодом, чтобы звук можно было подкрутить; для обычной игры Python не нужен.
