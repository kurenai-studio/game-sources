# 烫手炸弹 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在森林里加第三个 POI「蘑菇圈」，进去玩一局四个菌子传炸弹：引信看不见只能看火花，炸死一个重新点燃，最后一个活着的赢，名次换蘑菇币。

**Architecture:** 跟赛跑同一套分层——`BombRound` 是纯逻辑模型（`RefCounted`，不碰节点，引信/传递/判死/人机判断全在里面，可无头跑完整局），`bomb.gd` 只做编排（把模型状态喂给节点和 UI），视觉分 `BombArena`/`BombSeat`/`BombVisual` 三个只管画的小文件，`Sfx` 程序化生成全部音效。

**Tech Stack:** Godot 4.7.2 / GDScript / Mobile 渲染器 / Android

**Spec:** `docs/superpowers/specs/2026-10-18-bomb-tag-design.md`

## Global Constraints

- Godot 锁定 4.7.2，渲染器 `mobile`；本场景不使用任何 `CharacterBody3D` 或物理刚体。
- 可调数字全部进 `game/config.gd` 的 `const`，测试里也从 `Config` 取值，不许在测试里抄一遍字面量。
- 浮层、字体、按钮统一用 `game/ui/ui_style.gd` 的 `theme()` / `panel()` / `style_button()`。
- 场景自包含，节点间直接 `$` 引用；森林侧的面板每帧惰性 `get_first_node_in_group`，不在 `_ready` 里查。
- 美术与音频全部程序化生成，不引入外部素材文件。
- 大件几何用 `MultiMesh`；球体分段不超过 16×8。
- 无头测试入口：`bash scripts/test.sh`（它先刷一次全局类缓存）。
- 提交信息用中文，写法照现有 log（`传炸弹：xxx`）。
- 真机是 Redmi 24122RKC7C，`adb` 装在 `D:/dev/Android/Sdk/platform-tools`。

## Review Focus

排在最前面的是「不测就一定会漏」的五类：

1. **玩家已经炸死了还按按钮** —— 期望：被静默忽略，不崩、不生成幽灵炸弹。
2. **只剩一个存活者时求邻居** —— 期望：返回 -1 而不是自己，`request_throw` 被拒，不进入死循环。
3. **暂停面板开着的时候** —— 期望：嗤嗤声和震动都停，回来才继续（音效无法无头测，靠 `tick_interval` 的纯函数测试 + 真机走查）。
4. **一局结束之后再 tick 或再按按钮** —— 期望：引信不再烧、事件不再产生、蘑菇币只加一次。
5. **玩家整局一次都不按** —— 期望：引信照样烧完，玩家被炸死、结算，不能卡成死局。

要点：16bit 小端 PCM 用 `PackedByteArray.encode_s16()` 逐采样写入。嗤嗤声 = 白噪声过一个一阶低通再乘包络；滴答 = 短促的高频脉冲 + 快速衰减；爆炸 = 低频正弦（60~80Hz）加一个白噪声爆点 + 指数衰减；接住 = 上滑的正弦短音；扔出 = 噪声过一个由宽到窄的带通（用两级一阶低通差分近似即可）。所有函数都用 `mix_rate` 参数，不读全局采样率，才可无头测。

### Task 2: 纯逻辑模型 `BombRound`

整个游戏的全部规则都在这一个文件里。它跑完整局只需要 `tick()` 和 `request_throw()`，不碰任何节点，所以能无头跑几百局来校准平衡。

**Files:**
- Create: `game/minigame/bomb_round.gd`
- Create: `tests/test_bomb_round.gd`
- Modify: `game/config.gd`（追加 v3 传炸弹一节）

**Interfaces:**
- Consumes: `Config.BOMB_*`
- Produces:
  - `class_name BombRound extends RefCounted`
  - `enum Style { STEADY, GAMBLER, SPITEFUL }`（蓝 / 红 / 紫）
  - `const SEATS := 4`、`const PLAYER := 0`、`const NPC_STYLE := [Style.STEADY, Style.GAMBLER, Style.SPITEFUL]`（按座位 1/2/3）
  - 字段：`alive: Array[int]`、`death_order: Array[int]`、`holder: int`（-1 = 空中）、`thrower: int`、`target: int`、`flight: float`、`lock: float`、`fuse: float`、`queued_side: int`（0/±1）、`over: bool`、`elapsed: float`、`events: Array[Dictionary]`
  - `func _init(seed_value: int = 1) -> void`：立即 `_ignite()`，`events` 里出现一条 `ignite`
  - `func tick(delta: float) -> void`
  - `func request_throw(side: int) -> bool`：`side` = -1 左 / +1 右；`lock > 0` 时把方向记进 `queued_side` 并返回 `false`，空中 / 已死 / `over` 时返回 `false`
  - `func neighbour(seat: int, side: int) -> int`：相邻存活者，没人了返回 -1
  - `func tier() -> int`：0 稳燃 / 1 冒白星 / 2 发白
  - `func danger() -> float`：`clampf(1.0 - fuse / 3.0, 0.0, 1.0)`，给音效和红边用
  - 事件字典四种：`{"kind":"ignite","seat":int}`、`{"kind":"throw","from":int,"to":int}`、`{"kind":"explode","seat":int,"in_flight":bool}`、`{"kind":"over","winner":int}`

**座位编号与左右**：座位按 **南(0, 玩家) → 西(1) → 北(2) → 东(3)** 排，玩家面朝北，所以**下标 +1 是玩家的左手边**。`request_throw(-1)` 走 +1 方向，`request_throw(+1)` 走 -1 方向。

- [ ] **Step 3: 实现 `game/minigame/bomb_round.gd`**

`tick()` 的顺序必须是（这个顺序就是「空中炸算扔的人」的实现）：

```
if over: return
elapsed += delta
燃引信（速率 1 ± BOMB_FUSE_JITTER，每 0.4 秒重掷一次速率）
if fuse <= 0: _explode(); return
if flight > 0:
    flight -= delta
    if flight <= 0: _land()
    return                      # 飞行期间谁都不能动作
lock = maxf(0.0, lock - delta)
if holder == PLAYER:
    if queued_side != 0 and lock <= 0: _throw(queued_side)
    return
_npc_think()
```

`_explode()`：`in_flight := flight > 0.0`，死者 = `thrower if in_flight else holder`；从 `alive` 移除、追加进 `death_order`；清空 `holder/thrower/target/flight/lock/queued_side`；追加 `explode` 事件；`alive.size() == 1` 时置 `over` 并追加 `over` 事件，否则 `_ignite()`。

`_ignite()`：从 `alive` 里用 `_rng` 随机挑一个当 `holder`，`lock = Config.BOMB_CATCH_LOCK`，`fuse` 按 `alive.size()` 取对应区间（4→`BOMB_FUSE_4`、3→`BOMB_FUSE_3`、2→`BOMB_FUSE_2`）里的随机值，`queued_side = 0`，追加 `ignite` 事件。玩家收到炸弹时也要重掷 `_error`。

`_throw(side)`：`to = neighbour(holder, side)`，`< 0` 直接返回 `false`；否则追加 `throw` 事件，`thrower = holder`、`target = to`、`holder = -1`、`flight = Config.BOMB_THROW_SECONDS`、`queued_side = 0`。

`_land()`：`holder = target`、`target = -1`、`thrower = -1`、`lock = Config.BOMB_CATCH_LOCK`、`_error = _rng.randf_range(-e, e)`。

`_npc_think()`：`style = NPC_STYLE[holder - 1]`，`deadline = clampf(Config.BOMB_NPC_THROW_AT[style] - _error, 0.3, 2.5)`；`fuse > deadline` 就继续抱；否则挑边扔出去——`Style.SPITEFUL` 且上一手扔给他的人还活着时，扔回那一侧，其余情况 `_rng.randf() < 0.5` 决定左右。
