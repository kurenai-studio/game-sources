A playable 3D puzzle: two facing islands share one input, but the reflected character moves the opposite way (18 levels). Upstream `LICENSE` is copied next to this file and also kept under `src/`. Code, level design, and game design by Tommaso Brighina.

## Icon

`src/icon.svg` (md5 `2f4c650cef86f97abcde1de9d035da5b`) is an original twin-island mark made for this snapshot, replacing the default Godot icon that shipped upstream.
