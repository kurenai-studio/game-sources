# Pumpkin Smash

A lightweight Halloween arcade game built with Python and Pygame.

Smash falling pumpkins and dodge the ghost as the challenge intensifies.

## Features

* Arcade gameplay - Click falling pumpkins before they escape.
* Progressive difficulty - Increasing pumpkin speed intensifies each round.
* Multiple targets - Unlock additional pumpkins as your score increases.
* Ghost hazard - Clicking the ghost ends the game.
* Animated effects - Floating characters and fading explosions.
* Atmospheric visuals - Gradient skies and autumn-inspired scenery.

## Getting Started

### Requirements

* Python 3.9+
* Pygame

### Installation

Clone the repository:

```bash
git clone https://github.com/mcckyle/pumpkin-smash.git
cd pumpkin-smash
```

Install the dependencies:

```bash
python -m pip install pygame
```

### Launch

```bash
python main.py
```

Ensure that the pumpkin, ghost, and explosion image assets are available in the project directory before launching the game.

## Controls

| Input | Action |
| --- | --- |
| Left mouse button | Smash a pumpkin |
| Click the ghost | End the game |
| Window close button | Exit the game |
