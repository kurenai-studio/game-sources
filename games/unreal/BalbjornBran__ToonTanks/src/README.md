# ToonTanks
 Another minigame for learning purposes. Towers with cannon trying to kill the player who is a tiny Tank and he needs to kill the towers to win.
 
 This game is also very simple, the player will be able to finish the game at least. The objective is kill all the towers before the towers kill you.
 
 We're testing Pawns class, owr own gamemode, inheritance with the player pawn and the enemies and health components.
 
 You can move with WASD, and attack with LMB. Alt-F4 to close it.
