镇夜录 v0.1.0-alpha - macOS 测试版

这是公开试玩版本，不代表最终品质。

运行方法
1. 支持 Intel 与 Apple Silicon（M 系列）Mac；Intel 最低 macOS 11，M 系列最低 macOS 13。
2. 将 ZIP 完整解压后，双击“镇夜录.app”。
3. 若系统提示无法验证开发者，请右键“镇夜录.app”并选择“打开”。
4. 仍被阻止时，可前往“系统设置 > 隐私与安全性”选择“仍要打开”。
5. 若提示“应用已损坏”，请打开“终端”执行：
   xattr -cr /Applications/镇夜录.app

操作
- WASD 或方向键：移动
- 空格键：镇魂阵
- Esc：暂停或返回
- 法器自动攻击

内容
- 五大章节、十八种法器与进化、十三组联动、八门心法。
- 十七节点道行命盘、五十四件装备模板、五位多阶段首领。
- 无尽轮回：每五波轮换地域并迎战带词缀的首领，可从暂停界面主动结算。

建议重点反馈
- 前三分钟是否容易理解，难度是否合适。
- 哪种法器、联动、装备或命盘节点过强或过弱。
- 哪一章、哪一波或哪个首领出现明显难度突变。
- 界面文字、命盘连线、危险提示是否看得清。
- 卡顿、崩溃、音量异常或无法继续游戏的步骤。

存档
存档位于 ~/Library/Application Support/Godot/app_userdata/镇夜录 下。
删除该目录中的 zhenye_save.json 可以重新开始。

第三方素材与字体许可见 THIRD_PARTY.md 和 THIRD_PARTY_LICENSES 文件夹。
