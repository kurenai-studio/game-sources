# Подготовка к публикации

Это запись локальной проверки от **14 октября 2026 года**, а не обещание, что проект невозможно сломать или что у платформы никогда не возникнет вопросов. Проверки зависимостей ниже относятся к этой дате.

## Что проверили

- Все 56 внешних JAR совпали с официальными копиями или контрольными суммами Maven Central / Gradle Plugin Portal. Список — в `dependencies.json`, результат сверки — в `dependency-integrity.json`.
- Запрос к OSV не нашёл предупреждений для проверенных Maven-зависимостей, включая плагины сборки. Это результат запроса на тот момент, не доказательство отсутствия уязвимостей.
- Нативные C-библиотеки в этот запрос не входят. Их лицензии и уведомления сохранены. Во всех семи вариантах OpenAL проверена версия 1.25.2.
- Исходники LGPL-библиотек, ссылки на сборку и инструкция по замене приложены. Точное происхождение исторических CI-сборок OpenAL и побайтовая воспроизводимость не подтверждены. Подробности в `LIBRARY_REPLACEMENT.md`.
- Недостающие в JAR уведомления взяты отдельно из исходных проектов. Ссылки и хеши лежат в `third-party/manifest.json`.
- Хеш Gradle wrapper сверен с опубликованным Gradle. Проверка дистрибутива и зависимостей закреплена в конфигурации. Actions закреплены на конкретные коммиты, доступ к репозиторию у workflow только на чтение.
- 91 картинка вынесена в отдельные файлы. Исходные листы сохранены, логотипы шаблона заменены на иконку мага.

## Как собрать чистый архив

После успешной сборки:

```sh
python tools/verify_publication.py
python tools/prepare_github.py
```

Нужен Python 3. Для нарезки изображений отдельно нужен Pillow.

Проверка ищет типичные ключи и токены в тексте, личные пути Windows и подозрительные имена файлов. Также проверяет размер файлов, хеши ассетов и лицензий, наличие нужных файлов внутри JAR. Поиск по шаблонам может что-то пропустить — это не замена внимательному просмотру.

Экспорт берёт только перечисленные в скрипте файлы и папки. Кэши, настройки IDE, старые архивы и логи туда не идут. Результат лежит в `GitHub-ready`: исходники отдельно, готовая игра отдельно. Скрипт сам ничего на GitHub не отправляет.

## Что остаётся за рамками

Проверялась Windows; workflow на GitHub нужно проверять по его реальному запуску. Отключённая упаковка GraalVM и её зависимости в эту проверку не входили. Java в архив игры не включена.

Полной проверки патентов, товарных знаков, сходства изображений и авторских прав не проводилось. Происхождение ассетов записано без заявлений об их уникальности или исключительных правах.

Защита аккаунта остаётся на владельце: 2FA, доступные настройки проверки секретов и приватных сообщений об уязвимостях. Подготовка файлов не гарантирует отсутствие жалоб или ограничений платформы.
