# 打工人生存记(消耗1块钱deepseek自动生成加上传开源)

一个全年龄向的 2D 休闲躲避小游戏：躲开职场里的“画饼”和“加班”，收集“准时下班”和“周末”，努力撑过三个难度递增的关卡。

游戏使用 **Python + pygame** 编写，不读取任何外部图片或音频文件，也不附带项目字体文件；中文显示使用操作系统自带字体。角色、障碍、收集品、图标、粒子与界面全部由几何图形和文字实时绘制，整体静音。

> GitHub 项目地址：<https://github.com/Bigpiglee/work-life-survival>

## 快速开始

### 1. 环境要求

- Python 3.9 或更高版本（推荐 3.10+）
- pygame 2.6+；Python 3.14+ 使用 API 兼容、导入名同为 `pygame` 的 `pygame-ce`

克隆仓库并安装依赖：

```bash
git clone https://github.com/Bigpiglee/work-life-survival.git
cd work-life-survival
python -m pip install -r requirements.txt
```

`requirements.txt` 已经用环境标记处理了 Python 版本差异，直接安装即可。

### 2. 启动游戏

```bash
python main.py
```

### 3. 无窗口自检

```bash
python main.py --self-test
```

自检会自动使用 SDL 的 dummy 视频驱动，不打开窗口，依次验证标题界面、开始游戏、方向键与 WASD 移动、收集加分、碰撞扣精力、三个关卡流转、最终结算和重新开始。全部通过时退出码为 `0`，并输出 `all checks passed.`。

本次开发环境实测：

- Windows
- Python 3.14.6
- pygame-ce 2.5.8（`import pygame`）
- `python main.py --self-test`：全部检查通过
- 另外在真实窗口模式下启动并自动运行约 2 秒，主循环、按键、渲染和 ESC 退出均正常

## 操作说明

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动角色 |
| Enter / 空格 | 在标题页开始游戏；在关卡完成页继续；在结算页重新开始 |
| P | 游戏进行中暂停 / 继续 |
| Enter / 空格 / P | 暂停时继续游戏 |
| R | 结算页重新开始 |
| M | 结算页返回标题 |
| ESC | 任意场景直接退出游戏 |

窗口右上角的关闭按钮同样可以退出。窗口失去焦点时会自动暂停，并清空当前按住的移动键，避免切回窗口后角色继续移动。

## 玩法规则

### 目标

在三个关卡中坚持到倒计时结束。每关结束后会显示本关奖励，按 Enter 进入下一关；三关全部完成后进入总结算。

### 障碍：躲开红色卡片

| 障碍 | 效果 |
| --- | --- |
| 画饼 | 撞到后损失 1 点精力，连击清零 |
| 加班 | 撞到后损失 1 点精力，连击清零 |

角色初始拥有 **3 点精力**。受击后有约 1.45 秒的保护时间，期间再次碰到障碍不会继续扣精力；保护时间会用淡淡的金色光圈提示。

精力归零时本局结束，进入结算页。

### 收集：拿到绿色 / 蓝色卡片

| 收集品 | 基础分 |
| --- | --- |
| 准时下班（绿色工牌） | 100 |
| 周末（蓝色日历） | 200 |

连续收集会累积连击，提高得分倍率：

| 连击数 | 得分倍率 |
| --- | --- |
| 1–2 | ×1 |
| 3–5 | ×2 |
| 6–9 | ×3 |
| 10 及以上 | ×4 |

被任意障碍命中后连击清零。关卡切换不会清空连击。

### 其他得分

- **生存分**：游戏进行中每坚持 1 秒获得 5 分。
- **通关奖励**：每关结束时获得 `250 + 150 × 关卡序号（从 0 开始） + 40 × 剩余精力` 分。
- **精力补充**：从第二关开始，如果当前精力不足 3 点，进入新关卡时自动恢复 1 点（上限 3 点）。

### 关卡设计

| 关卡 | 时长 | 特点 |
| --- | --- | --- |
| 第 1 关 · 实习期 | 26 秒 | 低速、单件生成，适合熟悉操作 |
| 第 2 关 · 转正冲刺 | 28 秒 | 下落更快、生成间隔更短，可能同时出现两件；开始补 1 点精力 |
| 第 3 关 · 周五保卫战 | 30 秒 | 最高速度与障碍比例，双件生成概率更高；开始补 1 点精力 |

所有关卡都保证每关第一次生成的是收集品，避免开局就被障碍堵住。

## 界面与计分统计

- **开始界面**：标题、玩法说明、四件物品图鉴、操作提示、本次会话最高分。
- **游戏界面**：当前关卡、剩余时间、进度条、本局得分、精力、连击倍率、短暂文字提示。
- **关卡完成界面**：本关得分、通关奖励、剩余精力、累计得分、下一关提示。
- **结算界面**：胜利 / 精力耗尽两种结果、头衔、本局得分，以及通关进度、坚持时间、两类收集数量、成功躲避障碍数、最高连击、被命中次数、本次会话最佳分。
- 本次会话最高分只保存在内存中，不写入文件，因此每次重新启动程序会重新记录。

## 技术说明与限制

- **无外部资源**：没有加载 PNG、JPG、WAV、MP3 或项目自带字体文件；因此也不存在素材版权问题。
- **中文显示**：通过匹配操作系统自带字体（微软雅黑、黑体、等线、Noto Sans SC 等）来显示中文。如果系统中没有任何中文字体，会回退到 pygame 默认字体，可能出现方框；安装任一常见中文字体即可。
- **无音频**：为了避免引入音频文件，游戏完全静音。
- **分辨率**：固定窗口 960 × 640，60 FPS，不支持缩放或全屏。
- **存档**：不写任何本地文件；最高分仅在本次运行期间有效。
- **全年龄内容**：无暴力、血腥或攻击性内容，“画饼”“加班”仅作为轻松的职场梗出现在几何卡片上。

### 常见问题

**启动时报 `No available video device` / `pygame.error`**

请在有图形桌面的环境中运行；远程、无头服务器可先用 `python main.py --self-test` 验证依赖和核心逻辑。

**WASD 没有反应**

游戏同时使用实时键盘状态和 `KEYDOWN` / `KEYUP` 事件跟踪 WASD，并已关闭窗口文本输入，正常情况下不会再被输入法吞键。如果仍然无效：

1. 先用鼠标点击一下游戏窗口，确保窗口获得键盘焦点；
2. 将中文输入法切换到英文模式，或按 `Shift` 切换到英文输入；
3. 确认 `main.py` 是当前版本，并重新运行 `python main.py`；
4. 方向键可用时，也可以先用方向键完成游戏。

**中文显示成方框**

当前系统缺少匹配到的中文字体。可安装微软雅黑、思源黑体或 Noto Sans SC 后重新启动。

**Python 3.14 安装官方 pygame 失败**

官方 pygame 可能尚未提供该版本的预编译包。仓库的 `requirements.txt` 在 Python 3.14+ 会自动安装 `pygame-ce`，它使用相同的 `import pygame` API；也可以手动执行：

```bash
python -m pip install pygame-ce
```
