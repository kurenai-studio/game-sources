Multi-Engine Game Study

Eight engines.
One game.

Astro Drift is a single Asteroids-style game implemented across eight game engines, side by side. Identical physics constants. Identical controls. Each port layers its own engine-specific twist.

Godot 4
PLAYABLE
GDScript · WebAssembly export
The full game with waves, lives, scoring, and splitting asteroids. Twist: CRT post-process shader — phosphor bloom, scanlines, barrel distortion, chromatic aberration. Toggle with Ins.
FLAGSHIP → play
Love 2D
PLAYABLE
Lua · love.js Emscripten port
Twist: authentic 1979 vector-display phosphor. Every shape drawn three times — wide additive halo + narrow halo + crisp stroke with per-frame brightness flicker. Looks like a real CRT.
vector look → play
PyGame
PLAYABLE
Python · pygbag / Pyodide WASM
Twist: numpy procedural nebula + AI autopilot. The backdrop is generated entirely from numpy Gaussians. Hit Ins to hand the ship to a 20-line heuristic AI.
python in browser → play

Panda 3D
VIDEO
Python · Disney VR engine
Twist: 2D game reprojected into 3D space. Ship is a lit box mesh on the XY plane with world-bound wrap, Z-up right-handed coordinates, ambient + directional lighting, and a procedurally-drawn grid.
source on github ↗
Defold
VIDEO
Lua · King's open-source engine
Twist: msg.post scoreboard actor. Flat game-object + collection architecture with hand-authored input bindings and a GUI scene. Built headlessly via bob.jar to a native Windows binary.
source on github ↗
Solar 2D
VIDEO
Lua · Corona SDK successor
Twist: mobile-first content scaling. Letterbox scaling so the game looks right on any device. Runs in the Solar 2D Simulator with hand-authored config.lua + build.settings.
