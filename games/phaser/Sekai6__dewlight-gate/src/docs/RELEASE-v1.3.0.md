# v1.3.0 — ACTION-A 发力、接触与注意力

本版合并第六、七轮动作引擎升级，覆盖主控、苔影、玻璃蛾与露冠守卫。

- **SUPPORT**：承重阶段、急停换脚、移动平台局部锚点与重心平衡。
- **RECOVERY**：布娃娃结束时的视觉恢复、可达的非持剑手撑地与空地衔接。
- **CONTACT**：脚部、握柄、恢复撑手和惯性端点共用刚性长度约束与接触所有权，减少相互覆盖。
- **IMPULSE**：髋、胸、肩、头和装饰使用有延迟、阻尼与限幅的响应，表现发力与回弹。
- **INTENT**：小幅头胸注意力，包含目标保持、威胁优先和敌人预警方向锁定；不改变朝向、AI 或攻击方向。
- 开发动作预览增加独立模块开关、发力曲线、接触状态与绕背目标回放；生产版本移除开发入口。

现有攻击判定、85 ms 命中点、敌人预警、击飞受身规则、资源与存档格式兼容。

发布准备期间已通过 65 项单元测试、74 项浏览器回归、格式检查、TypeScript 和生产构建；本机原生 WebGPU 测试实际执行。CI 如缺少适配器会明确跳过，跳过不代表 GPU 验证通过。

与第六轮工作区比较：72 组受击／受身用例的根部轨迹、控制恢复时间与资源无差异；四场景各 720 个模拟步的战斗结果一致。4,200 个几何采样无裁切，采样内握柄误差与支撑漂移均在验收范围内。

同机四场景三轮配对的主线程 P95 中位数增幅分别约 +2.0%、+3.9%、−1.8%、+1.6%，帧间隔 P95 未恶化，纹理与显示对象计数稳定。结果仅代表本次环境和采样场景。

Release 附件提供四角色前后对照录像、关键姿势图与性能原始记录。录像使用第六轮工作区基线、固定输入与镜头、120 Hz 模拟／动作采样、30 fps 编码；正常与慢放观感仍需自行评估。

接触仍限于现有水平平台，不是任意地形物理系统。运行与系统说明见 [README](../README.md)、[第六轮](ACTION-A-ROUND6.md)和[第七轮](ACTION-A-ROUND7.md)。
