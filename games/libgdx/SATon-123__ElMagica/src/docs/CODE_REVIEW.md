# Заметки по проверке кода

Основа простая: отдельные классы для мага, врагов, атак, комнат, очереди спавна, торговца, меню и звука. Без ECS, физического движка и сетевых сервисов. Структура Gradle и запуск LibGDX сохранены.

Проект развивается с помощью Codex. Цель — код, который можно понять и самому править, без намеренных ошибок и попыток изображать неопытность.

## Что проверялось

- Хитбоксы атак и весь путь снаряда за кадр, включая края водяного луча по диагонали.
- Очередь врагов, ожидание свободного места, отдельные этажи боссов и открытие выхода.
- Подбор лута, физические объекты торговца и покупки.
- Русский и английский интерфейс, сохранение настроек, раздельная громкость.
- Пары begin/end и освобождение текстур, шрифта, музыки и звуков.
- Чистый экспорт исходников, ассеты внутри JAR и отдельный архив игры.

В проверках логики звук не создаётся. Для массовых попаданий есть короткий интервал между одинаковыми звуками, чтобы взрыв по толпе не превращался в кашу. Отключение эффектов останавливает уже запущенные звуки. Музыка при нулевой громкости сохраняет позицию, а при смене сцены переключается на другой трек.

## Уборка комментариев — 15 октября 2026

В 32 Java-файлах обновлены только комментарии: короткие заметки на русском вместо формальных объяснений и шаблонного текста. Исполняемый код и строки интерфейса не менялись — это проверено сравнением Java-токенов всех 64 файлов. Сторонний `StartupHelper` оставлен как есть.

После правок прошли `build` и `lwjgl3:releaseSmokeCheck`: компиляция, существующие проверки логики, сборка JAR и скрытый запуск.

## Что пока не проверено

Локально проверялась Windows. Linux/macOS и работа workflow на GitHub здесь не подтверждены. Отдельно стоит послушать музыку и эффекты в игре: автоматический тест не скажет, нравится ли их громкость и звучание.

Сохранения забегов и мультиплеера нет, Java в архив не входит. На поздних этажах места может не хватать — спавн тогда ждёт свободную безопасную клетку.
