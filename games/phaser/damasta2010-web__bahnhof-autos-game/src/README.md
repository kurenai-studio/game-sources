# Bahnhof Autos Game

Ein einfacher Phaser 3 Prototyp (plain JavaScript).

Features
- Kreisförmige Station mit 5 Plätzen
- Zwei Warteschlangen (Queue A/B) die bunte Passagiere (rot/blau/grün) spawnen
- Drei Fahrzeugtypen: 8/16/32 Plätze, Farben: rot/blau/grün
- Fahrzeuge können per Drag & Drop auf einen Platz gesetzt werden
- Fahrzeuge nehmen Passagiere der richtigen Farbe auf; nach 8s Timeout dürfen sie mit mindestens 50% Füllung abfahren
- Drei Level mit steigender Spawn-Rate

How to run
- Öffne die `index.html` im Browser (kein Server nötig)
