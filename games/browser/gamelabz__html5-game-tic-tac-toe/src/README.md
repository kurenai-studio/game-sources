# ❌⭕ Tic-Tac-Toe

❌⭕ Tic-Tac-Toe — a modern, dependency-free HTML5 game built with Canvas and vanilla JavaScript.

🎮 **Play Online:** https://gamelabz.github.io/html5-game-tic-tac-toe/

## 📸 Screenshot

![Tic-Tac-Toe](assets/images/screenshot.png)

## 🎯 About

Beat an unbeatable minimax AI on the 3x3 board, or settle for a draw if you can.

## 🕹️ Controls

- Place mark: Click a cell
- Choose side / who starts: buttons
- Restart: R

## ✨ Features

- Unbeatable minimax AI
- Win/draw detection with highlight
- Persistent win/loss/draw tallies

## 🚀 Run Locally

No installation required. Open the game directly in a browser:

```bash
# Option A: just open the file
open index.html

# Option B: serve it with a tiny static server
npx serve .
```

Then visit the printed URL (default `http://localhost:3000`).

## 🛠️ Tech Stack

- HTML5 `<canvas>`
- CSS3 (custom properties, flexbox, glassmorphism)
- Vanilla JavaScript (ES2020, no frameworks)
