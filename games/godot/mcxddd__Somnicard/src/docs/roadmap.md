# 产品路线

## 当前：2.1.2（2026-11-01）

定位是可长期使用的个人扑克练习室。核心循环为开桌 → 做决定 → 桌内解释 → 复盘 → 同主题训练 → 回到牌桌；电脑对手、教练、复盘与学习均在本机完成。2.1.0 已移除在线模型服务，不需要账号，记录只保存在本机。

| 维度 | 本次工作 | 状态 |
|---|---|---|
| 核心玩法 | 2–9 人规则、分池、存档与复盘 | 已发布；正式包模拟器开桌、发牌、下注通过 |
| 学习内容 | 12 课 / 60 题、错题复习、进度与训练衔接 | 已发布 |
| 训练室 | 一键开始、自动挑题、三档评级与完整理由、偏离局面间隔复习 | 2.1.2 已发布 |
| 导航与帮助 | 五类设置、分层帮助、诊断摘要、备份说明 | 已发布；官网按钮已更新 |
| 表现 | sleepy card 品牌、发牌与筹码动画、5 种音效、震动 | 已发布；真机音效、震动与 GPU 兼容性待验 |

详情见 [版本记录](version-history.md) 和 [发布工程](release-engineering.md)，逐版本测试记录可在 Git 历史中查看。已发布状态不代表完成全部设备验收；备份迁移、系统文件选择、后台恢复、震动与不同手机 GPU 仍需真机验证。

## 发布后优先顺序

1. 收集物理手机上的渲染、键盘、音量、震动、续航和系统安装反馈，按可重复证据修复兼容性。
2. 继续以可重复的离线对局评测改进本地对手；不将难度档位直接等同于真人水平。
3. 扩展经过审核的教学局面；训练室已按弱项与复习自动挑题，后续可增加更多内置局面，避免将输赢直接等同于决策好坏。
4. 逐步增加离线策略抽象覆盖，并持续显示范围、计算预算与误差；完整多人 GTO 另作研究与计算架构评估。
5. 新的大功能另行确认范围，不将未实现模块放进现有导航占位，也不把已移除的在线服务列作当前能力。
