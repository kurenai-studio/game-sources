A playable local-multiplayer horse-racing game (one to eight players) with SD mode, whole-credit combination bets, virtual opponents, race announcers, photo finishes, and saved games. Upstream `LICENSE` (GPL-3.0-only) is copied next to this file and also kept under `src/`. Third-party notices from upstream are in `THIRD_PARTY_NOTICES.md` and `src/THIRD_PARTY_NOTICES.md`.

Upstream README: this is an independent project and is not affiliated with or endorsed by the makers or owners of Sigma Derby. No original cabinet logo or proprietary game software is included.

## Icon

`project.godot` does not set `config/icon`, and this repository contains no `icon.png` / `icon.svg`. At runtime Godot uses its engine default icon. Player avatars under `src/assets/avatars/` are original SVG illustrations covered by the project's GPL-3.0-only license.

## Third-party assets

- **First Call (Call to the Post)** in `src/assets/audio/first_call.ogg`: recording by U.S. Army Bands. Source: https://commons.wikimedia.org/wiki/File:FirstCall.ogg (original SHA-1 `03f92742557ca2354f9077b27aecc6c634fe29aa`). The archive identifies this official U.S. Army recording as public domain in the United States. Included unmodified. See `src/assets/audio/NOTICE.txt` and `src/licenses/AUDIO-NOTICE.txt`. Other mechanical, hoof, and bell sounds are generated by the game's own code.
- **Historical card data** in `src/data/historical_cards.json`: numerical fan transcriptions with provenance recorded inside the file. No scanned manual or cabinet artwork is redistributed.
- **System voices:** speech is produced by operating-system voices at runtime; no third-party voice models are distributed.
- **NSIS** is used only to build the Windows installer (see `src/licenses/NSIS-COPYING.txt`); it is not required to play from source.

No bundled font files; the UI uses the engine default font.
