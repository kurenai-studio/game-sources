# Somnicard 2.1.0

一款离线的竖屏德州扑克练习游戏，使用虚拟筹码。

## 主要变化

- 全面使用本地电脑对手、教练与分析，无需配置在线模型服务。
- 换上 sleepy card logo、启动图与 Android 图标。
- 设置按五类整理，牌桌操作、声音、教学与数据备份更易查找。
- 牌桌加入发牌、筹码入池与分池动画，可关闭动效或使用省电模式。
- 学习路线提供 12 课 60 题，支持错题复习与课程进度备份。
- 正式版采用专用签名和独立包名 `com.somnicard.game`，与试用版并存。
- 官网迁移至 https://somnicard.nightricecake.com/ ，安装包同时通过 GitHub Releases 提供，并附 SHA-256 校验文件。

## 安装与迁移记录

下载本次 Release 的 APK，按 Android 提示允许浏览器或文件管理器安装应用。正式版可与旧试用版 `com.somnicard.practice` 并存。

迁移前，在旧试用版“设置 → 数据与备份”导出学习与牌局备份；安装正式版后，在相同位置导入。确认牌局与学习进度已恢复，再决定是否卸载旧版。设备设置与当前普通牌桌不包含在学习备份里，设备设置需重新设置。

请将下载文件的 SHA-256 与附带的 `.sha256` 文件核对。备份包含隐藏底牌，请妥善保管。
