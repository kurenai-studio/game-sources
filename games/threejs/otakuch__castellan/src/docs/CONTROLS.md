# Controls

Press <kbd>?</kbd> in the game to see this list at any time, or click **Keys** in the dock.

## Mouse

| | |
|---|---|
| **Left mouse** | use the tool in hand — place a piece, or cut the ground |
| **Right drag** · **Shift + drag** | orbit |
| **Middle drag** · **Alt + drag** | pan |
| **Wheel** | zoom |
| **Shift + wheel** | brush size, or the size of the piece in hand |

On a touch screen there is no right button, so a one-finger drag orbits unless a brush is in
hand, a tap places, and two fingers pinch to zoom.

## Keyboard

| | |
|---|---|
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | pan, relative to where you are looking |
| <kbd>Q</kbd> <kbd>E</kbd> | turn |
| <kbd>Shift</kbd> + those | pan and turn faster |
| <kbd>1</kbd>–<kbd>9</kbd>, <kbd>0</kbd> | pick a tool from the open tab |
| <kbd>[</kbd> <kbd>]</kbd> | brush size, or the size of the piece in hand |
| <kbd>,</kbd> <kbd>.</kbd> | turn the piece (<kbd>Shift</kbd> for 5°), or flip which side of a wall carries the parapet |
| <kbd>Shift</kbd> held during a stroke | 35% brush strength, for fine cutting |
| <kbd>Z</kbd> | undo — ten cuts deep, and every piece you have laid |
| <kbd>Space</kbd> | run the day, or hold it |
| <kbd>R</kbd> | ring the bell — jump the clock to the next canonical hour |
| <kbd>P</kbd> | photo mode: panels away, camera drifts |
| <kbd>H</kbd> | hide the panels |
| <kbd>Esc</kbd> | cancel what you are placing · pause the day · leave photo mode |
| <kbd>?</kbd> | this list |

## Panels

Every panel has a header: drag it by the grip, fold it with **–**, put it away with **×**.
The dock along the top toggles each one and **Reset** puts them all back. On a narrow screen
the Name and Census panels start hidden and Controls starts folded.

## The canonical hours

The clock band is marked with the offices, and the working day is stretched or squeezed to
fit the season's light.
