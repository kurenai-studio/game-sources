# 🧱 Tetris

🧱 Tetris — یک بازی HTML5 مدرن و بدون وابستگی، ساخته‌شده با Canvas و جاوااسکریپت خالص.

🎮 **بازی آنلاین:** https://gamelabz.github.io/html5-game-tetris/

## 📸 تصویر بازی

![Tetris](assets/images/screenshot.png)

## 🎯 درباره بازی

تترومینوهای در حال سقوط را ردیف کن، خطوط کامل را پاک کن و با افزایش سرعت در سطوح مختلف زنده بمان.

## 🕹️ کنترل‌ها

- حرکت: کلید چپ/راست جهت‌دار
- چرخش: بالای جهت‌دار
- سقوط نرم: پایین جهت‌دار
- سقوط سریع: Space
- توقف موقت: P

## ✨ ویژگی‌ها

- هر ۷ تترومینوی استاندارد
- پیش‌نمایش قطعه بعدی و پیشرفت سطح
- نمایشگر گلس‌مورفیسم و خشت‌های درخشان

## 🚀 اجرا در محیط محلی

نصبی لازم نیست. بازی را مستقیماً در مرورگر باز کن:

```bash
# روش اول: باز کردن مستقیم فایل
open index.html

# روش دوم: سرویس با یک سرور استاتیک کوچک
npx serve .
```

سپس به نشانی چاپ‌شده مراجعه کن (پیش‌فرض `http://localhost:3000`).

## 🛠️ تکنولوژی

- HTML5 `<canvas>`
- CSS3 (متغیرهای سفارشی، flexbox، گلس‌مورفیسم)
- جاوااسکریپت خالص (ES2020، بدون فریم‌ورک)
