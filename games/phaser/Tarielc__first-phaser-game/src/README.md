# Phaser Simple Arcade Game
This web game is built by instructions of Phaser's official documentation.
See: [Making Your First Phaser Game](https://docs.phaser.io/phaser/getting-started/making-your-first-phaser-game)

Player collects stars, and every round killer bombs are spawned. Longer you play, harder it is to avoid them all!
**[Try It Out!](https://first-phaser-game-pi.vercel.app/)**
