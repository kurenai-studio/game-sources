# Action-skill：剑舞连携与守卫技能

v1.4.0 发布版本，基于 v1.3.0，通过 PR 检查后合并并部署 GitHub Pages。对照录像与原始验收数据见 [Release 附件](https://github.com/Sekai6/dewlight-gate/releases/tag/v1.4.0)。

## 运行

```powershell
npm.cmd ci
npm.cmd run dev
# http://127.0.0.1:5173/
# http://127.0.0.1:5173/?action-skill
# http://127.0.0.1:5173/?action-a
```

技能实验室可选择连携、独立技能和守卫五招，切换朝向、难度、慢放、骨骼、实际命中范围；支持暂停、1/120 秒步进和阶段步进，显示资源、冷却、实例事件、握柄误差与剑尖速度。生产构建只加载游戏入口。

## 固定参数

权威配置位于 `src/action-skill/config.ts`。

| 技能 | 按键 | 光能 | 冷却 | 总时长 | 伤害／运动 |
| --- | --- | --- | --- | --- | --- |
| 折光穿枝 | Q，地面／空中 | 20 | 3.5 秒 | 0.38 秒 | 0.10–0.24 秒有效；0.10–0.26 秒位移最多 160 像素；每目标 1 |
| 藤芽升锋 | R，地面／空中 | 25 | 5 秒 | 0.50 秒 | 0.14 秒上挑，速度 −480；每目标 1；每次离地一次 |
| 露华回旋 | F，仅空中起手 | 35 | 8 秒 | 0.76 秒 | 0.14／0.30／0.46 秒各 1；前 0.48 秒重力为原来的 20% |

Q、R 分别从 0.26／0.30 秒开始接下一技能。最后一个有效技能输入保留 0.14 秒；F 收势从 0.52 秒开始，可接普通攻击。Shift 只取消收势，不取消发力段。所有技能锁定施放朝向，不自动转身或锁敌。施放即扣能和开始冷却，失败请求不扣能；受击打断不退款。三技完整连携消耗 80 光，技能命中不返能；原普攻保留原有返能用途。

普通敌人受到升锋后暂时浮空，禁止攻击，落地后恢复。玻璃蛾表现为失衡上浮；守卫始终保持地面碰撞与原位受击反馈。

## 系统结构

| 文件／模块 | 职责 |
| --- | --- |
| `action-skill/types.ts` | 定义、实例、输入、事件、命中请求、快照、难度和动画姿态类型 |
| `action-skill/config.ts` | 技能资源、阶段、运动、伤害窗口和双难度参数 |
| `action-skill/runtime.ts` | 纯 TypeScript 120 Hz 技能运行与仲裁；阶段跨越、输入缓冲、冷却与命中去重 |
| `action-skill/query.ts` | 独立于 Phaser 和动画的根部空间命中范围查询 |
| `action-skill/art.ts` | 单 Graphics 对象与 18 槽固定事件环；折射拖带、升锋藤线、回旋花瓣 |
| `action-skill/preview.ts` | 仅开发模式加载的技能实验室 |
| `action-a/skill-clips.ts` | 三种主控技能及三种守卫新招的专用分层动作 |
| `action-a/combat-motion.ts` | Hermite 握柄及刚性剑身曲线，通过 CONTACT 求解双段手臂 |
| `boss.ts` | 预警锁定、投射物扫掠、危险区、普通／挑战招式顺序和取消清理 |
| `main.ts` | 真正位移、平台／门／守卫碰撞、生命资源、奖励和存档 |

每次施放创建递增稳定实例。命中键为实例＋命中段＋目标 ID；持续突进不会反复命中，回旋三段独立结算。守卫的技能命中不使用旧普攻的 0.25 秒去抖，也不获得弱点双倍伤害，因此三段均为 1。

求值顺序：游戏固定步输入 → 技能仲裁与时间推进 → 碰撞与伤害 → ACTION-A 移动／战斗／反应采样 → INTENT／IMPULSE → DOLL-HIT／RECOVERY → SUPPORT → CONTACT → 受限装饰跟随 → 最终姿态、剑尖轨迹及 Canvas。技能贴图复用启动时生成的骨架素材；新增技能特效不创建临时显示对象。WebGPU 消费同一 Canvas 画面。

运行层在低帧率时以最多 1/120 秒子步处理整个区间，短暂命中点不会丢失。游戏本身也以 120 Hz 更新。渲染不产生伤害。暂停、失焦及原有命中停顿不推进游戏模拟；技能不增加命中停顿、无敌、霸体、镜头震动或全屏白闪。

## 守卫五招与难度

原有冲锋、根浪保留。新招危险区在预警起点固定，不随玩家后续位置追踪；图形标记直接来自实际危险区。

| 新招 | 普通预警 | 攻击／击飞 | 应对 |
| --- | --- | --- | --- |
| 折冠散晶 | 1.0 秒 | 三向晶刃，330 像素／秒；中级失衡 | 晶刃间隙、跳跃、冲刺 |
| 根庭绽刺 | 1.1 秒 | 三处半径 35 标记，相距 240，间隔 0.18 秒；根浪重级 | 离开标记、升空；相邻危险区之间有 170 像素安全带 |
| 露冠辉落 | 1.25 秒 | 原位置半径 45 的竖直光柱；根浪重级 | 横移离开，再反击 |

普通模式 48 生命，上半血使用冲锋／根浪／散晶／根刺，下半血加入辉落；招式结束至少 1.6 秒恢复。挑战模式 64 生命，预警按 0.8 系数缩短但不低于 0.8 秒；半血后采用固定双招组合，段间至少 0.45 秒，整组结束至少 1.2 秒。两种模式奖励与通关资格完全相同。

标题与暂停设置可选择难度。战斗进行中禁用选择器，需先回到检查点重新开始；T 可在竞技场入口重试当前难度。束缚、击败、重试和检查点重置均清除晶刃、根刺、辉落和根浪。

## 教学与存档

三技从开局具备。庭院光影可反复练习，通过暂停页跳过或重开，不产生玻璃珠、击败奖励或收集 ID。练完三技只保存教学完成布尔标记。

存档沿用 v2 格式，新增可选 `difficulty` 与 `skillTutorial`，旧存档默认普通且未完成教学。活跃技能、浮空、冷却、投射物和危险区不写入存档。死亡、传送和重置清空技能状态；刷新从既有安全位置继续，战斗资源恢复。

## 复现与材料

```powershell
npm.cmd test
npx.cmd playwright test
npm.cmd run format:check
npm.cmd run build
# 基线服务：另一个终端
npx.cmd vite artifacts/action-skill/baseline --host 127.0.0.1 --port 5181
# 性能不得与测试或录像同时执行
node scripts/action-skill-performance.mjs
# 固定输入素材
node scripts/action-skill-review.mjs
$env:ACTION_A_VARIANT='before'; $env:PLAY_URL='http://127.0.0.1:5181'
node scripts/action-skill-review.mjs
Remove-Item Env:ACTION_A_VARIANT, Env:PLAY_URL
node scripts/action-skill-report.mjs
```

基线清单与 SHA256：`artifacts/action-skill/baseline.json`。本地素材和报告在忽略目录 `artifacts/action-skill/`；不纳入本轮提交。最终数值、限制和视觉确认状态见验收报告。自动几何检查不能替代用户对正常速度和慢放效果的确认。
