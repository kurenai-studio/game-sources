# 同屏双人（v6）设计

## 要解决什么

一台手机上两个人一起玩：第二个人在森林里随时加入、自选角色，之后跟着一号位走；进任何一款小游戏，两个人都上场。

## 目标 / 非目标

- 目标：森林里能加入、能选角色、跟随不脱队；四款小游戏都支持两人同场并各自拿币。
- 非目标：联机；三个人以上；分屏逛森林（森林共用一个相机）；二号位单独存档。

## 硬约束（现状决定的）

- 存档是单人的：一套币、一套体力、一份皮肤收藏、一个 `character`。二号位的形象**不写盘**，退出游戏就没了。
- 小游戏都是 `change_scene_to_file` 的独立场景，所以二号位的身份必须放在会话级静态状态里，不能只活在 forests.tscn 的节点上。
- 相机是 `Player` 的子节点，森林里只有主控那个人有相机。
- 横屏手机两个人合用一块屏幕，每人占屏幕一半的触摸区。

## 关键决定

| 决定 | 理由 |
| --- | --- |
| 新增 `Party`（static var 会话状态） | 跨场景传二号位的体型/皮肤；不碰存档 |
| 人类固定占 0..n-1 号座位，人机从 n 号往后 | 现有代码「座位号 = 下标」的假设全部不动 |
| 森林里二号位是 `Player` + `leader`，不读输入 | 复用碰撞、动画、跟随移动的数学；POI 触发照旧「谁站进去都算」 |
| 触摸按屏幕左右半分给两个人 | 「按住任何位置」那两款（教室 / 猫头鹰）不需要新按钮 |
| 摇杆/动作键做成「每人一组」，单人布局不变 | 单人手感不动；双人各占一半 |
| 币是共享钱包，两个人都各自结算、相加 | 一台手机一个存档，没必要拆分 |
| 赛跑双人用左右两半 SubViewport 分屏 | 一个相机装不下差 20 米的两个人；别的三款一个镜头能装下全场 |

## 各场景怎么改

- 森林：`JoinPanel`（右上角「＋ 加入」）选体型 + 已拥有的皮肤 → `Party.join()`；`main.gd` 生一个 `seat = 1`、`leader = 一号位` 的 Player，没相机。回森林时按 Party 状态重建。
- 教室：0/1 号课桌给人，`EatInput` 按左右半屏各认各的手指；两个人都出局才结束；结算相加。
- 猫头鹰：0/1 号座位给人，同上；出局后快进改成「两个人都出局」。
- 传炸弹：0/1 号座位给人，每人一对投掷键（各自半屏）；谁的炸弹谁扔。
- 赛跑：两个 `RacePlayer`，每人一组摇杆 + 冲刺键；双人时左右各一个 SubViewport + 相机；两个人都跑完（或超时）才结算。

## 风险

- 赛跑分屏把场景画两遍：填充率不变，顶点和 draw call 翻倍。真机帧率没实测，先按 `docs/perf-log.md` 记一条待验。
- 左右分屏后单边视野只有半宽：7 米外的整条赛道仍在视野内，7 米内两侧会被切掉。
