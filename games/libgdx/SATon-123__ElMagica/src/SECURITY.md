# Если нашлась проблема с безопасностью

ElMagica работает локально. В игре нет аккаунтов, телеметрии, мультиплеера, платежей и загрузок из сети. Для сборки Gradle скачивает зависимости; отдельные скрипты проверки и подготовки могут обращаться в сеть, когда их запускают вручную. На некоторых системах launcher перезапускает Java для совместимости.

Сейчас поддерживается Beta1.0. Это личный проект, поэтому обещать сроки ответа не буду.

Не выкладывай пароли, токены и личные данные в Issues. Если в репозитории включены приватные сообщения об уязвимостях, используй их. Если нет — создай Issue с просьбой о приватном контакте, без секретов и подробностей эксплуатации.

## Заметки для публикации

На GitHub стоит включить двухфакторную защиту аккаунта, приватные сообщения об уязвимостях, проверку секретов и Dependabot там, где они доступны. Скрипты проекта сами настройки аккаунта не меняют и ничего не публикуют.

Проверка зависимостей показывает состояние на момент запуска, а не обещает вечную безопасность. Изменения в `gradle/verification-metadata.xml` надо сверять с официальными файлами библиотек, а не просто принимать новые хеши, чтобы сборка перестала ругаться.
