# 操作手冊

第一次打開時會出現三步驟的說明（找旗子、看各方看法、看來源），看過一次之後就不會再自動跳出。之後要再看，按左上角的「說明」。

## 看城市

- **旋轉**：在畫面上拖曳。鍵盤可以用方向鍵：左右鍵繞著轉，上下鍵改變俯角。
- **縮放**：滾輪，或在觸控板、手機上用兩指縮放。
- 鏡頭不能平移，俯角限制在 25° 到 70° 之間，城市不會被轉到畫面外。

## 點選

在畫面上點一下（不是拖曳），依點到的東西打開不同的卡片：

- **島**：點地面，或點島前緣的名稱標籤，例如「01 交通」。鏡頭會飛過去，島上每則議題的上方會出現 ①②③ 編號，① 是這座島最熱的議題。
- **建物**：點模型本身、它旁邊的旗子，或它上方的編號。卡片會顯示模型縮圖、狀態、熱度、發生什麼、為什麼跟你有關、各方怎麼看，以及新聞來源。來源連結會在新分頁打開。
- **小人**：點小人，會顯示他所在的那條牽連線。
- **牽連線**：點線本身，會顯示這兩類議題、牽連程度和搬運的東西。

選取後，相關的牽連線會自動出現，畫面下方也會出現圖例。點空白處、按卡片右上角的 ×，或按 Esc，都會關閉卡片。

卡片裡的議題列表、牽連 chip、「回到某某島」按鈕都可以直接點，在卡片之間跳轉。

## 左上工具列

- **全景**：取消選取，鏡頭回到看得見整座城市的位置。
- **清單**：打開或收起右側清單。
- **說明**：再看一次操作說明。

## 右側清單

- **搜尋框**：輸入關鍵字，會篩出名稱、內容或各方看法裡有這個字的議題。
- **本週熱門**：列出全城熱度 3 的議題，點了就飛過去。搜尋時會先收起來。
- **議題分類**：每座島可以展開，議題照熱度排序，點了就飛過去。點「看整座島」則選取整座島。
- **議題牽連**：列出所有牽連線，前面的標籤是牽連程度。

## 底部工具列（HUD）

左邊是目前時間與時段名稱，接著是四顆時間按鈕：

- **清晨 06／白天 12／黃昏 18／夜晚 21**：直接跳到那個時間。

右邊是六個開關，按下後會變成深色：

- **名牌**：近看時，小人頭上顯示「正在搬 X」。
- **搬運**：預設開啟。顯示小人手上的東西和頭上的圖示。
- **牽連線**：不管選了什麼，都顯示全部牽連線。
- **暫停**：讓時鐘停住，城市停在這個時間。小人仍會走動。
- **鳥瞰**：鏡頭移到城市正上方往下看。再按一次回到全景。
- **日誌**：打開城市日誌，可以用下拉選單只看某一條牽連線。

## 手機版

螢幕寬度 800px 以下時，介面會改成手機版：

- 工具列移到右上角，改成直排。
- 清單和卡片從畫面底部滑出，清單佔 52% 高，卡片佔 34% 高。
- 拖曳上緣的把手：往上拖到底撐滿全螢幕，往下拖一段回到原本高度，再往下拖就關閉。
- 打開卡片時，清單會自動收起，鏡頭會讓目標落在卡片上方。
- 時間按鈕收進底部的「時間」按鈕裡，按一下才展開。

## 語言

- 品牌卡右上角的「EN」可以切換成英文，切換後按鈕變成「中文」。
- 也可以直接在網址後面加 `#en`，例如 https://island-game.kh-lab.workers.dev/#en ，方便分享英文版連結。
- 英文版只翻譯了介面、島名與摘要、議題名稱，議題內容、各方看法和來源還是中文。

## 減少動態

系統開啟「減少動態效果」（prefers-reduced-motion）時，城市會靜止下來：

- 時鐘停住，小人不走動。
- 鏡頭直接跳到目標，不做飛行動畫。
- 牽連線改成不流動的虛線。

切換系統設定後立刻生效，不需要重新整理。
