# Support

Use these channels for help and project communication:

- **Bug reports**: Open a GitHub issue with steps to reproduce and expected behavior.
- **Feature requests**: Open a GitHub issue and explain the use case first.
- **Questions and contribution guidance**: Use GitHub Discussions (preferred) or open a discussion-style issue if Discussions is not enabled.

## Response Expectations

- We aim to triage new issues within 72 hours.
- Review times vary based on complexity and maintainer availability.

## Before Asking for Help

- Read `README.md` and `CONTRIBUTING.md`.
- Check existing issues to avoid duplicates.
- Include your environment details (OS, Node.js version, browser) for faster help.
