# README banner provenance

The Suika 2048 dark and light banners were generated on 23 October 2026 using OpenAI’s built-in Imagegen tool. The user supplied the pengusto profile banner as the penguin character reference. Its landscape and composition were not used as a template. The light banner was derived from the new dark banner to retain the character, pose and layout.

The fruit symbols and wooden number pieces are new conceptual illustrations, not extracted game tiles or product screenshots. Their combination does not reproduce the game’s exact fruit progression. No existing game assets were supplied for generation.

The user selected both variants for the README. The repository’s MIT license remains unchanged; this record grants no additional rights or clearance for existing game assets, the supplied character reference or third-party material. The existing noncommercial prototype asset caveat remains in the main README.

Both banners are 2172 × 724 pixels. They use the same composition and were visually checked at 960, 390 and 320 px viewport widths. The native picture/source markup selects by prefers-color-scheme, with the light image as fallback. The browser checks used a local README approximation, not a live GitHub rendering.
