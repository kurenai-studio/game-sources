# 毛线星球 · Yarn Planet — 设计文档（第一章）

> 这是全体开发者（包括子代理）共同遵守的设计基线。ID、坐标、颜色以 `src/chapter/data.ts`
> 和 `src/contracts.ts` 为准；本文解释意图。修改设计前先和总负责人确认。

## 1. 一句话

一颗安静下来的小星球，像一张还没上色的速写。你背着一个大线轴，走过的地方会留下一根彩色的线。
把线从「源头」牵到「需要的地方」：电点亮灯塔，水唤醒水车和花田，一串灯照亮老街，
一根传声线让两个几十年不说话的老邻居重新开口。每接通一根线，颜色就从那里像水波一样漫开。

## 2. 设计支柱

1. **走路本身就是创作**：线沿着你走过的真实路线铺下来。每个玩家通关后的星球都长得不一样。
2. **一眼能懂、少文字**：连上 → 活过来。界面文字短，对白短而温暖，带一点幽默（参考 Messenger 的语气）。
3. **画面钩子**：未连接区域是「纸面速写」（暖白纸色 + 深色描边），只有玩家、线、插座是彩色的。
   接通时颜色从终点像波纹一样扩散，这是宣传 GIF 的核心镜头。
4. **小而密**：一颗小星球、三个街区、九根线、十五到二十分钟。细节要密（招牌图标、晾衣绳、渔网、木箱、花盆、电线杆）。

## 3. 美术方向

- **造型**：全部由代码用基本几何体拼出（盒子、圆柱、圆锥、二十面体、挤出形状），低多边形、平面着色（flat shading）。
  粗糙由风格兜住：深色描边 + 平涂 + 冷紫阴影 + 高饱和天空。
- **描边**：后处理描边（深度/法线/材质边），墨色 `#2a2c3a`，略带手绘抖动。
- **光照**：两段式卡通光（亮面 / 冷紫暗面），太阳跟随玩家所在的半球（已有 lighting.ts）。
- **速写态（未复苏）**：纸色 `#ece6d8`，保留明暗层次，描边照常。天空也是淡纸色。
- **复苏态**：饱和但柔和的配色（见下表）。复苏是由「波纹」控制的：`src/art/revival.ts` 维护若干个圆形波纹（球面角距离），
  所有共享卡通材质根据波纹决定这一点是纸色还是彩色。波纹前沿有一圈暖色亮边。
- **永远是彩色的**：玩家、线、插座（发光提示）、拾取物。

**角色**：参考 Messenger 的比例和气质（大头、短身、短手脚、圆点眼、简单配色），但全部原创：
基本几何体拼出的分段角色（无骨骼蒙皮），程序化动画（走、跑、跳、待机呼吸、挥手、说话手势、坐、干活循环）。
每个角色靠服装、帽子、配饰和颜色区分。玩家背着一个比头还大的线轴，走路时线轴会转。

**性能预算**：桌面 60fps，手机可玩。静态几何按街区和材质合并，重复小物件用 InstancedMesh。目标 < 250 draw calls、< 50 万三角形。

## 4. 星球布局

星球半径 `PLANET_RADIUS = 14`（陆地基准面），海平面 `SEA_RADIUS = 13.72`。坐标用 `dir(lat, lon)`（度）：
`x = cos(lat)·sin(lon)，y = sin(lat)，z = cos(lat)·cos(lon)`。精确锚点见 `src/chapter/data.ts`。

- **港口 harbor**（约 lat 10, lon 0）：出生点在码头。南面是海湾（海覆盖约 lat −35, lon 0 一带的大片区域）。
  灯塔在西南的小岬角上，发电机在栈桥边，吊机在东侧码头，中间有仓库、渔网、木箱、小船。
- **工坊 workshop**（约 lat 18, lon 115）：一座小山，山顶有泉眼；山脚有小溪、水车和工坊（烟囱），东南是梯田花田。
- **老街 oldstreet**（约 lat 15, lon −118）：一条斜穿的石板街，两端各有一根灯柱；中段面摊；
  一条窄巷两侧是奥托和艾克的房子，窗户正对着；一棵粉色花树。
- **大树 grove**（约 lat 70, lon 0，北极附近）：一棵巨大的树，三条根分别朝向三个街区，根上各有一个插座。
- **背面的房子 far**（约 lat −58, lon 180）：孤零零的一栋暗房子，门锁着。终章时窗口出现人影，作为第二章的钩子。
- 街区之间有土路，南半球是草甸、树林、岩石和海岸，可以自由漫游。

## 5. 核心玩法：牵线

- 靠近一个「源头」插座，按交互键（E / 手机按钮）拿起线头。线轴开始放线：线沿玩家实际走过的路线贴地铺设
  （爬台阶时线会自然下垂），颜色对应线的种类。走路时线轴会发出轻柔的音符（像音乐盒）。
- 线有长度上限（`THREAD_CAPACITY`），快用完时线轴变空、线绷紧，玩家被轻轻拉住，并提示可以收线。
- 随时可以收线（R / 手机收线按钮）：线沿原路快速收回到源头。
- 带着线靠近匹配的「终点」插座，按交互键接上。随后会有一道光脉冲从源头沿线跑到终点，到达时触发：
  复苏波纹、物件活过来（灯亮、水车转、花开……）、居民反应、存档。
- 同一时间只能牵一根线。接好的线永久留在地上，成为星球的一部分。
- 灯串 `lights` 线：光脉冲经过时，沿线每隔一段弹出一盏小灯笼。
- 传声 `voice` 线：接通后两位老人出现在窗口，开始对话。

## 6. 第一章「重新亮起来」流程

| 编号 | 连接 | 源 → 终点 | 种类 | 前置 | 效果 |
|---|---|---|---|---|---|
| h1 | 灯塔 | 栈桥发电机 → 灯塔底座 | power | — | 灯塔亮、光束旋转、海面复苏、玛洛的船靠岸 |
| h2 | 吊机 | 灯塔电箱 → 码头吊机 | power | h1 | 吊机卸货、鱼摊开张、小皮出现放风筝 |
| w1 | 水车 | 山顶泉眼 → 水车 | water | h1 | 水车转、工坊冒烟、布拉姆开工 |
| w2 | 花田 | 水车水闸 → 花田 | water | w1 | 花田盛开、蝴蝶 |
| o1 | 灯串 | 灯柱 A → 灯柱 B | lights | h1 | 沿线灯笼亮起、窗户打开、居民出门 |
| o2 | 传声线 | 奥托的窗 → 艾克的窗 | voice | o1 | 两位老人重新说话 |
| fh / fw / fo | 根 | 各街区枢纽 → 大树对应的根 | root | h2 / w2 / o2 | 大树逐步开花；三根都接好后进入终章 |

开场（0–3 分钟）：从天上落到码头，灯塔看守维克说明情况。第一根线是教学。
之后三个街区可以任意顺序完成。终章：镜头拉远，看到被彩线缠绕的整颗星球，天色转为傍晚，灯笼亮起；
随后镜头转到背面那栋暗房子，窗口亮起一个人影。字幕「第一章 · 重新亮起来」，可以拍一张明信片。

## 8. 声音

所有声音都用 WebAudio 实时合成，没有录音素材：UI 点击、脚步、放线的音乐盒音符（五声音阶，随步伐递进）、
接通和弦、复苏「哗」的上扬音、环境风声和海浪噪声，以及角色说话用的「咿呀语」。
所有声音都走 `src/audio/` 的一个统一接口，以后要换成真实素材也只改这一处。

## 9. 文本与语言

五种语言：简体中文 `zh`、繁体中文 `zh-Hant`、英语 `en`、日语 `ja`、韩语 `ko`。
规范文本（中文和英文）见 `src/chapter/script.ts`；其余三种语言由本地化负责人翻译，语气保持温暖、简短、略带幽默。

## 10. 素材与许可

本项目只使用自己用代码生成的几何、着色器和合成音效，不包含 Messenger 或其他游戏的任何模型、贴图、音频、角色、剧情或代码。
球面移动、碰撞、相机、渲染管线框架、存档、多语言和界面框架沿用作者此前自己写的小星球引擎代码。
不得加入任何外部游戏的素材，也不得加入读取这类素材的逻辑。
