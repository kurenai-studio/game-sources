# 🏰 Tower Defense

🏰 Tower Defense — یک بازی HTML5 مدرن و بدون وابستگی، ساخته‌شده با Canvas و جاوااسکریپت خالص.

🎮 **بازی آنلاین:** https://gamelabz.github.io/html5-game-tower-defense/

## 📸 تصویر بازی

![Tower Defense](assets/images/screenshot.png)

## 🎯 درباره بازی

برج‌ها را در مسیر بچین، آن‌ها را ارتقا بده و هر موج دشمن را قبل از رسیدن به پایگاهت متوقف کن.

## 🕹️ کنترل‌ها

- قرار دادن برج: کلیک روی جایگاه
- شروع موج: دکمه
- توقف موقت: P

## ✨ ویژگی‌ها

- انواع برج‌های مختلف
- موج‌های دشمن و ارتقا
- جان‌ها و اقتصاد

## 🚀 اجرا در محیط محلی

نصبی لازم نیست. بازی را مستقیماً در مرورگر باز کن:

```bash
# روش اول: باز کردن مستقیم فایل
open index.html

# روش دوم: سرویس با یک سرور استاتیک کوچک
npx serve .
```

سپس به نشانی چاپ‌شده مراجعه کن (پیش‌فرض `http://localhost:3000`).

## 🛠️ تکنولوژی

- HTML5 `<canvas>`
- CSS3 (متغیرهای سفارشی، flexbox، گلس‌مورفیسم)
- جاوااسکریپت خالص (ES2020، بدون فریم‌ورک)
