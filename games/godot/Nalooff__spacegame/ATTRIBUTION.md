A complete multiplayer spaceship game with a vertex-built modular ship editor, by Nalooff (Copyright 2026). Upstream `LICENSE` is copied next to this file and also kept under `src/`.

## Art

There is no third-party art pack in the repository. `src/assets/lock.png` is a 16×16 original lock mark. `src/Hauler-0.png`, `src/Hauler-1.png`, `src/Hull-0.png`, `src/Hull-1.png`, and `src/docs/img/` are 1600×900 in-game screenshots of the author’s own ship editor and maps. The repository does not bundle a project icon (and does not include the Godot default icon). Ships and modules are built as vertex geometry in-game.
