This (fully playable game) is my starting point for a Love2D game that uses game states and a CSV file for saving game data.  

The example game is intentionally made without libraries, images, or sound - it's just made with [LÖVE](https://www.love2d.org/)! That's not to say you shouldn't use all that stuff, because you totally should. I just wanted to make a template for an arcade game that only uses the basics for clarity. 

I made this template as a complete game, because it was really the only way to make a template without missing features and details. As to why I made it at all, well I would like to make an arcade style game to play on my [Anbernic RG 40XXV](https://retrocatalog.com/retro-handhelds/rg-40xxv). You know, because 50,000 retro and open source games just wasn't enough variety! =)  

There are some LÖVE games on [PortMaster](https://portmaster.games/), so I assume this one will run fine too.  

[![it-works.png](https://i.postimg.cc/vmgtMHvX/it-works.png)](https://postimg.cc/PLHwQH98)  
**It does!**  

I considered using [GB Studio](https://www.gbstudio.dev/) to make a GameBoy Color game, which has the benefits of easily working in an emulator and on original hardware. However, using LÖVE with my preferred tools and workflow means I can also design a game for the 640x480 resolution of my handheld, using my choice of colors, data structures, sounds, etc. We are lucky to have so many options! Personally, I enjoy the simplicity of using SDL with Lua, as structured by Love2D. In some ways it's an even more basic version of BASIC.  

I made this for LÖVE 11.5, as provided in [Debian 13 "Trixie"](https://www.debian.org/intro/why_debian).
