# Змея

Файл: `snake-v1.png`. Создан встроенным imagegen с прозрачным фоном. Один нейтральный спрайт окрашивается в четыре стихии; подготовка, скольжение и рывок анимируются в коде.

Промпт:

Use case: stylized-concept. Asset type: one production pixel-art game enemy sprite for ElMagica. A small hostile snake, coiled S-shaped body, raised triangular head, two tiny dark eyes, a short forked tongue and two tiny fangs. Front-facing slightly top-down RPG view, matching a cute gray wizard, gray slimes and a hooded cultist. Clearly a snake, not a slime, not a dragon. Neutral light gray scales with white highlights and dark navy pixel outline so runtime color tint can create fire, water, earth and air variants. Compact silhouette readable at 60x60 pixels, head angled gently to the right, tail curls below the head, all anatomy inside one square with about 10 percent transparent padding. One snake only, centered, genuinely transparent background. Crisp chunky pixel art, limited palette, no smooth gradients, no text, no labels, no floor, no cast shadow, no sprite sheet, no extra objects.
