# lovetris
This tetris on love2d

### Notation
I might fix some bugs and improve this game. *But that's not certain!*
Version Love2d 11.5
Version Lua 5.4.x

### Start
enter the command at the root of the project
`love .`

#### Control
S - Start <br>
Q - Quit <br>
P - Pause <br>
R - Resume/Restart <br>
Tetramino controlled by arrows like in regular Tetris... <br>
Shift - Hold <br>
Space - Hard Drop <br>
