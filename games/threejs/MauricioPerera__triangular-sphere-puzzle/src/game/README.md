# Juego

`GAME.md` es la fuente de verdad de los datos declarativos del juego. El artefacto
`game-data.generated.js` se genera con GAME Protocol y lo consumirá el motor cuando
comencemos a implementarlo.

Comandos desde la raíz:

```text
npm run game:lint
npm run game:build
npm run game:check
```

El `GAME.md` actual es un escenario mínimo de arranque y será reemplazado por el
diseño del juego que definamos.
