# SpaceCleaner

Аркадная мобильная игра на Java + LibGDX: корабль очищает космос от мусора, игрок управляет касаниями экрана.

## Полное описание

SpaceCleaner — аркадная игра для Android, написанная на Java с использованием фреймворков LibGDX и Box2D и принципов ООП. Игрок управляет космическим кораблём, который автоматически стреляет по падающему мусору.

Механика управления:
- **Касание экрана** — корабль плавно движется к точке касания
- **Автоматическая стрельба** — корабль стреляет с фиксированной частотой

Условия окончания игры:
- Корабль получает три попадания от мусора и теряет все жизни

Очки начисляются за уничтожение мусора и за время выживания. Скорость и частота появления мусора нарастают со временем.

Предметы-бонусы падают с определённой частотой. Подобранный предмет немедленно активирует эффект:
- **ЩИТ** (синий круг) — поглощает одно попадание
- **x2** (жёлтый круг) — двойная стрельба на 10 секунд
- **БОМ** (красный круг) — мгновенно уничтожает весь мусор на экране

В игре три экрана: главное меню, игровой экран и экран рекордов. Поддерживается повторная игровая сессия без перезапуска приложения.

## Авторские дополнения

### 1. Нарастающая сложность
Интервал появления мусора уменьшается по экспоненте от времени сессии: новые объекты начинают появляться заметно чаще уже через 30–40 секунд. Уровень опасности от 1 до 5 отображается в HUD.

### 2. Система комбо
При уничтожении нескольких объектов подряд с интервалом не более 1,5 секунды активируется комбо. Начиная с третьего подряд уничтожения на экране появляется надпись «КОМБО xN!», а к счёту добавляются бонусные очки.

### 3. Вспышка экрана при уроне
В момент получения урона экран на короткое время заливается красным полупрозрачным оверлеем, который плавно угасает. Реализовано через однопиксельную Pixmap-текстуру и `batch.setColor()`.

### 4. Тряска камеры
При получении урона или подборе бомбы камера кратковременно трясётся. Реализовано через смещение `camera.position` на случайный вектор с быстро затухающей интенсивностью.

### 5. Красный тинт корабля
При получении урона корабль на короткое время окрашивается в красноватый оттенок через `batch.setColor()` с интерполяцией прозрачности. Визуально сигнализирует о потере жизни.

### 6. Таблица рекордов
Пять лучших результатов сохраняются между сессиями через `LibGDX Preferences` и отображаются по завершении игры. При сохранении новый результат вставляется на правильную позицию в отсортированный список.

## Запуск

**Android:**
```
./gradlew android:installDebug
```

**Desktop:**
```
./gradlew desktop:run
```

## Структура проекта

```
core/src/ru/samsung/gamestudio/
├── MyGdxGame.java                  — точка входа, управление экранами, физический мир
├── GameSession.java                — состояние сессии: очки, комбо, уровень опасности
├── GameSettings.java               — константы физики, размеров, битовые маски коллизий
├── GameResources.java              — пути к ресурсам
├── GameState.java                  — перечисление состояний: PLAYING, PAUSED, ENDED
├── PowerUpType.java                — перечисление бонусов: SHIELD, DOUBLE_SHOT, BOMB
├── components/
│   ├── FontBuilder.java            — генерация шрифтов с поддержкой кириллицы
│   ├── MovingBackgroundView.java   — прокручивающийся фон
│   ├── LiveView.java               — отображение жизней
│   ├── RecordsListView.java        — список рекордов
│   ├── TextView.java               — текстовый элемент
│   ├── ImageView.java              — статичное изображение
│   └── ButtonView.java             — кнопка с текстом
├── managers/
│   ├── AudioManager.java           — музыка и звуки
│   ├── ContactManager.java         — обработка коллизий Box2D
│   └── MemoryManager.java          — сохранение и загрузка рекордов
├── objects/
│   ├── GameObject.java             — базовый физический объект (Box2D тело)
│   ├── ShipObject.java             — корабль: движение, стрельба, щит, двойной выстрел
│   ├── TrashObject.java            — мусор: движение вниз, столкновения
│   ├── BulletObject.java           — снаряд: движение вверх
│   └── PowerUpObject.java          — бонус: Pixmap-круг, тип, подбор
└── screens/
    ├── GameScreen.java             — игровой экран: эффекты, HUD, логика
    ├── MenuScreen.java             — главное меню
    └── SettingsScreen.java         — настройки звука и рекордов
```
