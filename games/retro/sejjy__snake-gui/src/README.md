#

### How to play

1. Install and build
   [raylib](https://github.com/raysan5/raylib#build-and-installation).

2. Clone the repository:

	```bash
	git clone https://github.com/sejjy/snake-gui.git
	cd snake-gui
	```

3. Compile and run:

	```bash
	make run
	```
