# 猫头鹰喂食 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在森林里加第四款小游戏：猫头鹰从树上扔糖和屎，长按张嘴吃，吃到屎出局，三关打完四个菌子比总分，按名次发币。

**Architecture:** 规则写成纯模型 `OwlRound`（`RefCounted`，种子排投喂序列，不碰节点），无头测试直接跑完整局；渲染由 `owl.tscn` 单场景内的 `OwlArena`（画）、`OwlActor`（四个蘑菇）、`OwlItem`（下落物）、`OwlUI`（HUD）组成，`owl.gd` 只编排阶段机。森林侧 `OwlTree` + `OwlPanel` 跟起跑线/蘑菇圈同一套写法。

**Tech Stack:** Godot 4.7.2、GDScript、自建无头测试（`tests/run_tests.gd`）、`EatInput`（已有的按住输入）。

**Spec:** `docs/superpowers/specs/2026-10-24-owl-candy-design.md`

## Global Constraints

- Godot 4.7.2、Mobile 渲染器、横屏 1280×720；材质只用 `StandardMaterial3D`，不写 shader。
- 可调数字全部进 `game/config.gd` 的 `const`，不散落在脚本里。
- 扣体力只在本小游戏 `_ready` 一处，走 `Save.spend_stamina()`；加币只在结算一处，走 `Save.add_coins()`。
- 森林侧跨场景引用每帧惰性 `get_first_node_in_group`，不在 `_ready` 缓存。
- 非平凡逻辑先写测试；能抽纯函数的抽成 `static func`。
- 测试命令：`bash scripts/test.sh`（先刷全局类缓存，再跑 `tests/run_tests.gd`）。
- 提交信息用中文。

## Review Focus

- **一次 delta 跨过两次抵达**：快进 2.5 倍或掉帧时 `tick` 的 delta 变大，若按帧结算会吃掉/漏掉中间那一颗。`test_fast_forward_keeps_arrivals_exact` 与 `test_two_arrivals_in_one_tick` 钉住。
- **出局后还继续吃**：出局那一刻必须闭嘴、本关不再生成新东西，否则玩家能刷分。`test_out_mouth_cannot_score`、`test_poop_ends_lane` 钉住。
- **关间分数被重置**：三关累加是计分的基础，`test_level_advance_keeps_scores` 钉住。
- **同分名次随机**：`sort_custom` 不保证稳定，同分必须显式按座位序，否则同一局面每次名次不同。`test_ranking_by_score_ties_by_seat` 钉住。
- **体力不够时进场景**：`_ready` 里换场景要 `call_deferred`，这期间不能再 tick（现有三款都这么写），任务 5 的步骤照抄。

```gdscript
extends TestBase

const SEATS := OwlRound.SEATS

func _round(seed_value := 1) -> OwlRound:
	return OwlRound.new(seed_value)

## 清掉所有自动排程，测试自己摆一颗
func _freeze(r: OwlRound) -> void:
	for m in r.mouths:
		m.wait = 0.0
		m.flying = 0.0
		m.lead = -1.0
		m.poop = false

func _drop(r: OwlRound, seat: int, poop: bool, fall := 0.5) -> void:
	var m: OwlRound.Mouth = r.mouths[seat]
	m.poop = poop
	m.fall = fall
	m.flying = fall

func _presses(player: bool) -> Array:
	return [player, false, false, false]

func _run(r: OwlRound, seconds: float, player := false) -> void:
	var step := 1.0 / 60.0
	for i in int(round(seconds / step)):
		r.tick(step, _presses(player))
```

- [ ] **Step 4: 实现 `game/minigame/owl_round.gd`**

要点（其余按现有 `StealEat` / `BombRound` 的写法）：
- `tick` 用子步循环（`MAX_STEPS := 8`）：每轮取 `step = min(left, 最快那颗的 flying)`，先按减之前的状态判 `_is_open(seat)`，再减 `flying`/`wait`，`flying` 落到 0 就 `_arrive`。`step` 永远不超过抵达时刻，所以快进也精确。
- `_is_open`：出局恒 false；玩家读 `mouths[PLAYER].open`（由 `tick` 开头从 `presses[0]` 写入）；人机读 `m.lead >= 0.0 and m.flying > 0.0 and m.flying <= m.lead`。
- `_spawn(seat)`：出局的座位直接返回；`poop = randf() < OWL_POOP[level]`；`fall = OWL_FALL[level]`；`flying = fall`；人机再摇 `lead = randf_range(span.x, span.y) * fall`，其中 `span = OWL_NPC_LEAD[seat - 1]`，糖要过 `OWL_NPC_EAT` 那一关、屎要过 `OWL_NPC_GREED` 那一关，没过就把 `lead` 置 -1。
- `_arrive(seat, open_now, ...)`：`flying = 0`；张嘴 + 屎 → `out = true`；张嘴 + 糖 → `score += 1`；闭嘴 → 什么都不做。然后 `wait = randf_range(gap)`，`poop = false`。
- `start_level(index)`：夹到 0..2，重置 `time_left` / `level_over` / 四个 `Mouth` 的临时字段（`score` 和数组本身不动），`wait = randf_range(0.3, 0.7)`。
- `ranking` 用 `sort_custom` 加显式同分比较（同分按座位序，玩家赢平局）；`coins` 取 `OWL_RANK_COINS[clampi(rank, 0, 3)]`。

- [ ] **Step 2: 写 `game/minigame/owl.gd`**

照 `bomb.gd` 的骨架：
- 常量：`SEAT_NAMES := ["你", "稳", "贪", "胆小"]`、`SEAT_COLORS := [Color(0.92,0.25,0.22), Color(0.32,0.55,0.88), Color(0.95,0.58,0.25), Color(0.66,0.40,0.86)]`、`CAMERA_POSITION := Vector3(0.0, 2.6, 8.5)`、`CAMERA_TARGET := Vector3(0.0, 1.4, -1.0)`；`enum Phase { COUNTDOWN, PLAY, BREAK, DONE }`。
- `_ready`：`Save.spend_stamina(Config.STAMINA_COST_OWL)` 失败 → `set_physics_process(false)` + `call_deferred("_bail_to_forest")` + return；`Controls.ensure()`；相机 `position`/`look_at`；`_round = OwlRound.new(randi())` 并 `print("猫头鹰种子：%d")`；建 `OwlArena`（`build()`）、四个 `OwlActor`（`position = Vector3(Config.OWL_SEAT_X[i], 0.0, 0.0)`、`setup(SEAT_COLORS[i], i == OwlRound.PLAYER)`）、四个 `OwlItem`（`setup()`、`visible = false`）；`_ui = $UI`、`_ui.set_names(SEAT_NAMES)`、连三个按钮信号；`_phase = Phase.COUNTDOWN`、`_timer = Config.OWL_COUNTDOWN`。
- `_input(event)` → `_eat.feed(event)`；`_notification`：`APPLICATION_FOCUS_OUT` 清 `_eat.finger`，`WM_GO_BACK_REQUEST` 开关暂停（`_settled` 后不响应）。
- `_physics_process(delta)` 的四个阶段：
  - `COUNTDOWN`：`_timer -= delta`，`show_countdown(str(ceili(maxf(_timer, 0.0))))`；到 0 → `hide_countdown()`、`_phase = PLAY`。
  - `PLAY`：`var speed := Config.OWL_FAST_FORWARD if _round.player_out() else 1.0`；`_round.tick(delta * speed, _presses())`；`_drain_events()`；`_update_visuals(delta)`；`_ui.set_hud(_round.level + 1, _round.time_left, _scores(), _round.player_out())`；`level_over` 时：`_round.level >= 2` → `_settle()`；否则 `_phase = BREAK`、`_timer = Config.OWL_BREAK_SECONDS`、`_round.mouths[0].open = false`、`_ui.show_countdown("第 %d 关" % (_round.level + 2))`。
  - `BREAK`：`_timer -= delta`；到 0 → `_round.start_level(_round.level + 1)`、`_ui.hide_countdown()`、`_phase = PLAY`。
  - `DONE`：return。
- `_presses() -> Array`：`PLAY` 阶段返回 `[_eat.pressing() or Input.is_action_pressed("jump"), false, false, false]`，其他阶段全 `false`。
- `_drain_events()`：`eat` → `print("吃到糖：%s" % SEAT_NAMES[seat])`；`poop` → `print("吃屎出局：%s" % SEAT_NAMES[seat])`。清空 `_round.events`。
- `_update_visuals(delta)`：四个 `OwlActor.apply(mouths[i].score, mouths[i].open, mouths[i].out, delta)`；每个 `OwlItem`：`flying > 0` 且 `fall > 0` → `set_kind(poop)`、`place(_arena.owl_point(), _actors[i].mouth_point(), 1.0 - flying / fall)`、`visible = true`，否则 `visible = false`。
- `_settle()`：`_phase = DONE`；`var order := OwlRound.ranking(_scores())`；`var rank: int = order.find(OwlRound.PLAYER)`；`var earned := OwlRound.coins(rank)`；`Save.add_coins(earned)`；`print("结算：第 %d 名，%d 分，+%d 蘑菇币")`；`_ui.show_result(rank + 1, earned, _rows(order))`。
- `_scores() -> Array` / `_rows(order) -> Array`：`_rows` 返回 `[{"name": SEAT_NAMES[i], "score": mouth.score}]`，顺序按 `order`。
