# Tetris-Unity

A classic Tetris puzzle game built with Unity and C#.

## Overview

This project recreates the classic block-stacking puzzle game. Players arrange falling blocks to complete horizontal lines and earn points.

## Features

- Falling tetromino blocks
- Block movement and rotation
- Line clearing mechanics
- Score tracking
- Game over detection

## Built With

- **Engine:** Unity
- **Language:** C#
- **Version Control:** Git and GitHub

## Getting Started

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk** and choose the project folder.
4. Open the project using a compatible Unity version.
5. Open the main scene and press **Play**.

## Project Structure

- `Assets/` — Game assets and resources
- `Packages/` — Unity package dependencies
- `ProjectSettings/` — Unity project configuration
