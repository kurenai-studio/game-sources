# 🔢 Sudoku

🔢 Sudoku — یک بازی HTML5 مدرن و بدون وابستگی، ساخته‌شده با Canvas و جاوااسکریپت خالص.

🎮 **بازی آنلاین:** https://gamelabz.github.io/html5-game-sudoku/

## 📸 تصویر بازی

![Sudoku](assets/images/screenshot.png)

## 🎯 درباره بازی

صفر ۹×۹ را با یک معمای معتبر و با راه‌حل یکتا پر کن و با بهترین زمانت در هر سطح دشواری مسابقه بده.

## 🕹️ کنترل‌ها

- انتخاب خانه: کلیک
- وارد کردن عدد: کلیدهای ۱-۹
- پاک کردن: Backspace / Delete

## ✨ ویژگی‌ها

- معماهای معتبر و با راه‌حل یکتا
- سطوح دشواری و تایمر
- برجسته‌سازی تداخل و اعداد مشابه

## 🚀 اجرا در محیط محلی

نصبی لازم نیست. بازی را مستقیماً در مرورگر باز کن:

```bash
# روش اول: باز کردن مستقیم فایل
open index.html

# روش دوم: سرویس با یک سرور استاتیک کوچک
npx serve .
```

سپس به نشانی چاپ‌شده مراجعه کن (پیش‌فرض `http://localhost:3000`).

## 🛠️ تکنولوژی

- HTML5 `<canvas>`
- CSS3 (متغیرهای سفارشی، flexbox، گلس‌مورفیسم)
- جاوااسکریپت خالص (ES2020، بدون فریم‌ورک)
