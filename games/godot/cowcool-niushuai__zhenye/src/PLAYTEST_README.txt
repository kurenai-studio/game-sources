镇夜录 v0.1.0-alpha

这是公开试玩版本，不代表最终品质。

运行方法
1. 支持 64 位 Windows 10/11。
2. 将压缩包完整解压到普通文件夹。
3. 双击 Zhenye.exe；不要单独移动或删除 Zhenye.pck。
4. Windows 若显示未知发布者提示，请确认文件来源后选择“更多信息”继续运行。

操作
- WASD 或方向键：移动
- 空格键：镇魂阵
- Esc：暂停或返回
- 法器自动攻击

内容
- 五大章节、十八种法器与进化、十三组联动、八门心法。
- 十七节点道行命盘、五十四件装备模板、五位多阶段首领。
- 无尽轮回：每五波轮换地域并迎战带词缀的首领，可从暂停界面主动结算。

建议重点反馈
- 前三分钟是否容易理解，难度是否合适。
- 哪种法器、联动、装备或命盘节点过强或过弱。
- 哪一章、哪一波或哪个首领出现明显难度突变。
- 界面文字、命盘连线、危险提示是否看得清。
- 卡顿、崩溃、音量异常或无法继续游戏的步骤。

存档
存档位于 Windows 用户目录的 Godot/app_userdata/镇夜录 下。
删除该目录中的 zhenye_save.json 可以重新开始。

第三方素材与字体许可见 THIRD_PARTY.md 和 THIRD_PARTY_LICENSES 文件夹。
