# Промпт тайлсета

Use case: stylized-concept. Asset type: production pixel-art tile atlas for a top-down fantasy arena game ElMagica. Generate ONE rectangular image with EXACTLY 6 columns and EXACTLY 4 rows, 24 equal SQUARE cells, no margins, no spacing, no borders, no labels, no text. Image aspect ratio exactly 3:2. Each cell is an independent square game tile viewed perfectly from directly overhead, NOT isometric, NO perspective. Crisp hand-clustered retro 32-bit pixel art, each tile designed as if 64x64 source pixels enlarged with nearest-neighbor. Restrained dark low-contrast floors and more defined chunky wall tiles, playable readability. Rows are FOUR distinct biomes: ROW 1 ancient arcane ruins: muted dark indigo-grey dressed stone, worn subtle golden etching; ROW 2 overgrown temple: mossy grey-green stone and sparse tiny roots; ROW 3 volcanic dungeon: dark charcoal basalt with sparse muted amber cracks, NO dangerous-looking pools or pits; ROW 4 frozen crypt: muted desaturated blue-grey stone with thin frost and tiny ice chips. In EVERY row columns 1,2,3 are FLOOR variants: 1 plain repeating stone paving, 2 same paving with sparse hairline cracks, 3 same paving with a small subtle biome accent confined to central portion. All three floor variants must have IDENTICAL edge colors and paving alignment, seamless when randomly mixed, no bevel or frame at tile edges. In EVERY row columns 4,5,6 are WALL variants, full square top-down solid impassable stone block cap surfaces, significantly darker and heavier than the floors, with a consistent narrow highlighted stone perimeter: 4 plain masonry block, 5 same block with biome detail (faint ancient rune / moss / ember fissure / frost), 6 same block with decorative stone medallion. Wall artwork fills each whole cell. Match coherent material palette within each row; distinct rows. No objects protrude across cells. No characters, no monsters, no torches, no UI, no checkerboard, no transparency, no drop shadow outside tile, no smooth gradients, no photorealism, no 3D-render. This is a usable tightly packed 6x4 tile texture atlas, not a sample sheet or full room illustration. Treat cell boundaries as exact sixths of width and exact quarters of height.
