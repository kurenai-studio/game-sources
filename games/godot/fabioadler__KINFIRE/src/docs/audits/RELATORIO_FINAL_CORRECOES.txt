🔴 CRÍTICOS (3 bugs) - TODOS CORRIGIDOS

[1] ✅ Equipagem via clique direito falha
    Arquivo: scripts/ui/inventory_panel.gd (linhas 313, 317, 318, 336)
    Problema: hero.equipment[slot] sem null check
    Correção: Adicionado null check com .get() e verificação "slot in hero.equipment"
    Impacto: Tooltip e equipagem via clique direito não causam mais crash

[2] ✅ Validação de categoria incompleta
    Arquivo: scripts/core/hero.gd (linhas 560-571)
    Problema: cls.allowed_weapons/allowed_offhands vazio não era validado
    Correção: Adicionado is_empty() check antes de verificar categoria
    Impacto: Classes sem armas definidas não permitem equipar arma incorretamente

[3] ✅ Loop infinito potencial
    Arquivo: scripts/game/dungeon_generator.gd (linha 105-106)
    Problema: _carve_line() com while true sem proteção se a == b
    Correção: Adicionado "if a == b: return" antes do loop
    Impacto: Geração de dungeon não trava em edge case

🟠 ALTOS (3 bugs) - TODOS CORRIGIDOS

[4] ✅ Double .get() call - performance
    Arquivo: scripts/ui/inventory_panel.gd (linha 125)
    Problema: hero.equipment.get(it.slot) chamado duas vezes
    Correção: Cache do resultado em variável local
    Impacto: Performance do tooltip melhorada (1 call ao invés de 2)

[5] ✅ Stairs reference null
    Arquivo: scripts/game/world.gd (linha 144)
    Problema: stairs pode ser null ou deletado (is_instance_valid ausente)
    Correção: Adicionado is_instance_valid(stairs) check
    Impacto: Minimapa não quebra quando stairs é removido

[6] ✅ Array bounds inseguro
    Arquivo: scripts/game/player.gd (linha 300)
    Problema: _path.is_empty() or _path[_path.size()-1] acessa array vazio
    Correção: Alterado para "not _path.is_empty() and ..." (short-circuit)
    Impacto: Pathfinding não crasha com _path vazio
