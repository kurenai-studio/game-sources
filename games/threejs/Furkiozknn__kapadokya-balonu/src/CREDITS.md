# Credits

Everything in the game world (terrain, fairy chimneys, balloons, sky, particles) and every sound is generated in code.
The only files are the mascot images on the landing report.

| File | What | Source | Licence |
|---|---|---|---|
| `assets/mascot/kedi-selam.png` | White Turkish Van kitten, waving (soft landing) | Furkiozknn's own Claude Game Arena mascot (`video-studio/public/maskot/kedi-selam.png`), downscaled to 256 px | Owned by the project author, used with permission |
| `assets/mascot/kedi-saskin.png` | White Turkish Van kitten, surprised (hard bump or failed flight) | Furkiozknn's own Claude Game Arena mascot (`video-studio/public/maskot/kedi-saskin.png`), downscaled to 256 px | Owned by the project author, used with permission |

The game runs without these files: `?noassets` skips them, and a missing file simply hides the kitten.
