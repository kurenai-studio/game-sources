# The Code Mirror shows Python and Java

The BSIT data structures course is not tied to a single language, so the Code Mirror shows either Python or Java. Each player picks the language in settings, and it defaults to the language the course teaches. This roughly doubles the work of writing each Puzzle, because every step needs matching code lines in both languages. That cost is the reason the Code Puzzle Type uses arranging rather than free typing: players choose or order lines from a set, so the game never compiles or runs student code.

## Consequences

- The game is written in Python, but Python is not the only language it teaches. Do not "simplify" by removing Java.
- Free-typed code Puzzles would need a safe way to run student code in two languages. They are left out on purpose, not overlooked.
