**Цель:** Очистить игровое поле от мин, открыв все безопасные ячейки. Игрок проигрывает при открытии ячейки с миной.

## Основные компоненты

1. **Игровое поле (Grid):** Двумерный массив ячеек фиксированного размера (напр., 9×9, 16×30).
2. **Ячейки (Cell):** Состояния: `Closed`, `Open`, `Flagged`. Данные: наличие мины, количество соседних мин.
3. **Генерация мин:** Случайное размещение N мин при старте, исключая первую открытую ячейку (для честной игры).
4. **Подсчет соседей:** Для каждой пустой ячейки вычисляется количество мин в радиусе 1 клетки (по горизонтали, вертикали и диагонали).
5. **Логика открытия:**
    - Одиночный клик: открывает ячейку. Если 0 соседей — рекурсивно открывает соседей. Если мина — Game Over.
    - Правый клик: ставит/снимает флаг.
6. **Условия победы:** Все ячейки без мин открыты (или количество открытых ячеек + количество флагов = общее количество ячеек).
7. **UI/UX:** Таймер, счетчик флагов, кнопка рестарта, визуализация (XP-стиль). Вся визуализация стоится на png-файлах.
8. **Меню:** Settings, About. Настройки позволяют выбрать маленькое, среднее и большое поле, а также сбросить таблицу рекордов.
9. **Таблица рекордов:** После разминирования поля показывается таблица рекордов (по одной записи для каждого размера), при обновлении рекорда можно указать свое имя.

## Проекты в решении

Проект собирается под .NET Core 8, как VSCode, так и Visual Studio 2022
1. **MinesweeperCore:** Движок, логика поведения минера, вспомогательные классы.
2. **MinesweeperWinForms:** Реализация на WinForms.
3. **MinesweeperMonoGame:** Реализация на MonoGame.
