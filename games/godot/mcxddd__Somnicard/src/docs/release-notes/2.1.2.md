# Somnicard 2.1.2

一款离线的竖屏德州扑克练习游戏，使用虚拟筹码。

## 主要变化

- 训练室重做：首页只有一个“开始练习”按钮和四个主题的掌握度。每组 5 题自动挑选，先复习偏离建议的局面，再练最弱的主题。作答后显示“好的选择 / 可以接受 / 偏离建议”三档评级、关键数字和完整理由。
- 训练室与学习路线统一为翻前入池、面对下注、主动下注、河牌判断四个主题；旧记录自动归入新主题。
- 界面统一了文字层级、颜色和卡片样式，入口加上图标；练习和牌局统计改为数字卡片和进度条。
- 新插画：教练头像（分析时会切换思考姿势）、牌背、主界面主视觉和几处空状态插画。
- 帮助改为可展开的问答。
- 新安装时有三页简介，可以跳过，只出现一次。
- “进阶”电脑对手去掉“实验”标注，游戏内实测数据已更新。

## 安装

可以直接覆盖安装 2.1.0 / 2.1.1（包名 `com.somnicard.game`），记录会保留，存档与备份格式没有变化。从旧试用版迁移的方法与 2.1.0 相同：在旧版“设置 → 数据与备份”导出，装好后在同一位置导入。

请将下载文件的 SHA-256 与附带的 `.sha256` 文件核对。
