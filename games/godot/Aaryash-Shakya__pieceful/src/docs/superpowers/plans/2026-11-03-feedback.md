# Feedback Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every pick-up, join, lock and completion on the board plays its sound and vibration with no delay added by the game, from four generated sound files the project owns.

**Architecture:** A headless tool script renders four short mono 16-bit WAV files from fixed recipes and saves them with `AudioStreamWAV.save_to_wav`; they are committed with uncompressed import settings. The board gains a `cluster_lifted` signal. A `Feedback` node in the board scene listens to the board's four signals and plays preloaded streams through one polyphonic `AudioStreamPlayer` per sound and vibrates with `Input.vibrate_handheld`, both through replaceable `Callable` fields so headless tests can record what fires.

**Tech Stack:** Godot 4.7.2, GDScript, Mobile renderer. Tests are plain headless scripts extending `BaseTest`.

**Spec:** `docs/superpowers/specs/2026-11-03-feedback-design.md`. Also read `INTENT.md` and `AGENTS.md`.

## Global Constraints

- Godot 4.7.2, GDScript, Mobile renderer. Android only. Package name `io.github.aaryash_shakya.pieceful`, do not change it.
- No new dependencies, plugins or network calls. No Oboe plugin in this slice.
- Sound files: mono, 16-bit PCM, 44 100 Hz, imported with `compress/mode=0`, no silence at the start. Lengths: pick 0.05 s, join 0.07 s, lock 0.12 s, complete 0.93 s.
- The generator uses `SeededRng` for randomness, never the engine's random functions, and gives the same bytes on every run.
- Vibration: join 12 ms at 0.5, lock 25 ms at 1.0, completion 60 ms at 1.0, none on pick-up.
- A drop that joins and locks plays only the lock feedback.
- Do not set `audio/driver/output_latency` or `audio/driver/mix_rate`: Godot's Android driver ignores both (spec, "The audio driver finding").
- Nothing is loaded, created or connected per play, and the feedback node does no per-frame work.
- Out of scope: the settings screen, effects, music, the slot sound, cleanup, saving.
- Run `godot --headless --import` after adding any file with a new `class_name` or any asset, then `godot --headless --script tests/<name>.gd`. A passing run prints `0 failure(s)` and exits 0.
- Match the surrounding code style, sparse comments that explain why. Conventional commits, one per task.

## Review Focus

- A WAV file imported with Godot's default compression (QOA), for example after its `.import` file is deleted and recreated: the loaded stream must still be 16-bit PCM (Task 1, `_test_files_exist_and_load`).
- Two snaps less than one sound's length apart: the second must not cut off the first (Task 3, `_test_wiring` pins `max_polyphony == 4`; the sound itself is owner check 2).
- A press on a locked piece or on empty table: no pick-up tick (Task 2, `_test_locked_piece_cannot_be_picked_up`).
- A second finger landing while a cluster is held: no second tick (Task 2, `_test_hold_pinch_moves_cluster`).
- Sound off with vibration on, and the reverse: each switch silences only its own channel (Task 3, `_test_sound_off`, `_test_vibration_off`).

### Task 1: The four sound files and their generator

**Files:**
- Create: `tools/sound_synth.gd`, `tools/make_sounds.gd`, `assets/sounds/LICENSE.md`, `tests/test_sounds.gd`
- Generate: `assets/sounds/pick.wav`, `join.wav`, `lock.wav`, `complete.wav` and their `.wav.import` files

**Interfaces:**
- Consumes: `SeededRng.new(seed_value)`, `SeededRng.next_float()`.
- Produces in `tools/sound_synth.gd` (`extends RefCounted`, no `class_name`; load it with `preload("res://tools/sound_synth.gd")`):
  - `const MIX_RATE := 44100`, `const MASTER_GAIN := 1.5`, `const ATTACK := 0.001`, `const DECAY_FLOOR := 0.0001`, `const NOISE_SEED := 1`
  - `const SOUNDS := [&"pick", &"join", &"lock", &"complete"]`
  - `static func render(sound: StringName) -> AudioStreamWAV`: `format = FORMAT_16_BITS`, `stereo = false`, `mix_rate = MIX_RATE`, `loop_mode = LOOP_DISABLED`, `data` filled as below.
- Produces `tools/make_sounds.gd` (`extends SceneTree`): `_init` saves `render(name)` to `res://assets/sounds/<name>.wav` for each name in `SOUNDS`, `printerr`s and `quit(1)` on any error other than `OK`, else `quit(0)`.

The recipes are the spec's table "The sounds" (component start, length, volume, waveform, pitches). Per sample, with `t` the time since the component's start and `d` its length:

```text
tone:  f(t) = f0 * pow(f1 / f0, t / d); phase starts at 0 and gains f(t) / MIX_RATE after each sample
       gain = vol * t / ATTACK if t < ATTACK, else vol * pow(DECAY_FLOOR / vol, (t - ATTACK) / (d - ATTACK))
       sine = sin(TAU * phase); triangle = 1 - 4 * absf(fposmod(phase + 0.25, 1.0) - 0.5)
click: n = roundi(d * MIX_RATE), a fresh SeededRng.new(NOISE_SEED) per click
       sample k = (rng.next_float() * 2 - 1) * pow(1 - float(k) / n, 3) * vol
mix:   frames = roundi(max over components of (start + d) * MIX_RATE); sum the components,
       multiply by MASTER_GAIN, clamp to [-1, 1], store roundi(x * 32767) with encode_s16
```

- [ ] **Step 1: Write the failing test `tests/test_sounds.gd`** extending `BaseTest`. `const Synth := preload("res://tools/sound_synth.gd")`, `const LENGTHS := {&"pick": 0.05, &"join": 0.07, &"lock": 0.12, &"complete": 0.93}`, path `"res://assets/sounds/%s.wav" % name`. Helper `_peak(stream: AudioStreamWAV, from_frame: int, to_frame: int) -> int`: the largest `absi(stream.data.decode_s16(2 * i))` in the range. `_init` runs these, then `finish()`; each loops over `Synth.SOUNDS`:
  - `_test_render_format`: `s := Synth.render(name)`: `s.format == AudioStreamWAV.FORMAT_16_BITS`, `not s.stereo`, `s.mix_rate == 44100`, `s.loop_mode == AudioStreamWAV.LOOP_DISABLED`.
  - `_test_render_is_deterministic`: `Synth.render(name).data == Synth.render(name).data`.
  - `_test_files_exist_and_load`: `FileAccess.file_exists(path)`; `load(path) is AudioStreamWAV`; its `format == AudioStreamWAV.FORMAT_16_BITS` (fails on a QOA import), `not stereo`, `mix_rate == 44100`. The 44 100 Hz check stands in for a latency setting: it is Godot's fixed Android mix rate, so the files are never resampled.
  - `_test_lengths`: `absf(load(path).get_length() - LENGTHS[name]) <= 0.001`; for pick, join and lock also `get_length() < 0.15`.
  - `_test_onset`: with `frames := stream.data.size() / 2`, `_peak(stream, 0, 132) >= 0.1 * _peak(stream, 0, frames)` (sound within the first 3 ms) and `_peak(stream, 0, frames) >= 1000`.
  - `_test_files_match_generator`: loaded and rendered `data.size()` are equal, and every sample differs by at most 1.
  - `_test_licence_note`: `FileAccess.file_exists("res://assets/sounds/LICENSE.md")`, and its text contains `"CC BY 4.0"` and `"tools/make_sounds.gd"`.

### Task 3: The feedback node, vibration permission and notes

**Files:**
- Create: `src/game/feedback.gd`, `tests/test_feedback.gd`
- Modify: `src/game/board.tscn`, `export_presets.cfg` (`permissions/vibrate`), `docs/engine-decision.md`, `docs/technical-notes.md`

**Interfaces:**
- Consumes: the four `assets/sounds/*.wav` from Task 1; `Board.cluster_lifted` from Task 2; `Board.pieces_joined`, `Board.cluster_locked`, `Board.puzzle_completed`, `Board.state`, `PuzzleState.is_locked`.
- Produces in `class_name Feedback extends Node` (`src/game/feedback.gd`):
  - `const SOUND_PICK := &"pick"`, `SOUND_JOIN := &"join"`, `SOUND_LOCK := &"lock"`, `SOUND_COMPLETE := &"complete"`
  - `const STREAMS := {SOUND_PICK: preload("res://assets/sounds/pick.wav"), ...}` for all four
  - `const MAX_POLYPHONY := 4`
  - `const JOIN_VIBRATION_MS := 12`, `JOIN_VIBRATION_AMPLITUDE := 0.5`, `LOCK_VIBRATION_MS := 25`, `LOCK_VIBRATION_AMPLITUDE := 1.0`, `COMPLETE_VIBRATION_MS := 60`, `COMPLETE_VIBRATION_AMPLITUDE := 1.0`
  - `@export var board: Board`; `var sound_enabled := true`; `var vibration_enabled := true`
  - `var play_sound: Callable`, called as `play_sound.call(sound: StringName)`; defaults to a method that calls `_players[sound].play()`
  - `var vibrate: Callable`, called as `vibrate.call(duration_ms: int, amplitude: float)`; defaults to `Input.vibrate_handheld`
  - `var _players: Dictionary[StringName, AudioStreamPlayer]`: made in `_ready`, one child per `STREAMS` entry, `stream` from `STREAMS`, `max_polyphony = MAX_POLYPHONY`, bus `Master`
  - `attach(target: Board) -> void`: sets `board` and connects its four signals; `_ready` calls it when `board` is set
- Behaviour, each sound only when `sound_enabled`, each vibration only when `vibration_enabled`:
  - `cluster_lifted`: `SOUND_PICK`, no vibration.
  - `pieces_joined(root, _)`: nothing if `board.state.is_locked(root)` (the lock follows in the same call); else `SOUND_JOIN` and the join vibration.
  - `cluster_locked`: `SOUND_LOCK` and the lock vibration.
  - `puzzle_completed`: `SOUND_COMPLETE` and the completion vibration.
- In `src/game/board.tscn`: an `ext_resource` for `res://src/game/feedback.gd` and a child `[node name="Feedback" type="Node" parent="."]` with that script and `board = NodePath("..")`.
