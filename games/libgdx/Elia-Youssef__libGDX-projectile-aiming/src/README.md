# Projectile Aiming

Projectile Aiming is a physics-based targeting game built with libGDX. Drag from the launcher to set
direction and power, inspect the live trajectory preview, then release to fire at three targets.

## Features

- Mouse-controlled angle and linear power selection
- Real-time parabolic trajectory preview
- Shared fixed-step integrator for preview and live flight
- Frame-rate-independent projectile simulation
- Three reachable targets with persistent hit feedback
- Single-projectile lockout while a shot is active
- GL-free simulation separated from rendering and input
- Entirely code-generated visuals

## Controls

| Input | Action |
| --- | --- |
| Hold left mouse button | Aim and set launch power |
| Move mouse while held | Change direction and power |
| Release left mouse button | Fire one projectile |

The HUD tracks progress as `Hits: n / 3`. A hit changes the target center from red to green.

## Requirements

- JDK 21
- Windows, macOS, or Linux with desktop OpenGL support
- Internet access on the first build so Gradle can download libGDX 1.14.1

## Build and run

On Windows:

```powershell
.\gradlew.bat clean build
.\gradlew.bat lwjgl3:run
```

On macOS or Linux:

```bash
./gradlew clean build
./gradlew lwjgl3:run
```

The game opens in a fixed 800x600 desktop window.

## Simulation design

`AimingWorld` advances the projectile on a fixed 1/120-second step. Preview dots are generated by
the same `Projectile.step` routine from the same launch state, keeping the predicted and live paths
aligned. Input power is clamped to the supported range before launch.

## Project structure

```text
core/      Aiming simulation, projectile and target models, rendering, and input
lwjgl3/    Desktop launcher
```

## Assets

Projectile Aiming is asset-free. The ground, launcher, trajectory dots, projectile, targets, and HUD
are drawn at runtime with libGDX primitives and the built-in font.
