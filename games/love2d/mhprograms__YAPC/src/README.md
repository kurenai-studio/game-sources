This is a ~~barebones~~(v0.1 - v0.4) clone of Atari Pong.

This is a clone of the original Atari Pong game ~~; however, it's barebones.~~

## Getting Started

### Dependencies

* LÖVE2D

### Installing

* Clone the repository or download the source

### Executing program

* Run your game with
```
love /path/to/your/downloaded/folder
```
