# 🌑 Shadow Survivors

**Shadow Survivors** is a fast-paced 2D top-down survival shooter built with **Godot 4.7** and **GDScript**.

Fight through increasingly dangerous enemy waves, collect upgrades, defeat powerful bosses, and survive as long as you can in a dark neon arena.

The game is fully offline and does not require an account, internet connection, or external assets.

---

## 🎮 Play the Game

### Windows

Download the latest Windows version from:

**[⬇️ Download Shadow Survivors](https://github.com/Wadan3/shadow-survivors/releases/latest)**

After downloading:

1. Extract the ZIP file.
2. Open the extracted folder.
3. Run:

```text
ShadowSurvivors.exe
```

No installation is required.

## 👾 Enemies

Shadow Survivors includes several enemy classes with different behaviors.

### Grunt

Standard enemy with balanced health and movement speed.

### Runner

Fast enemy with lower health that can quickly reach the player.

### Tank

Slow but highly durable enemy.

### Elite

A stronger enemy designed for later waves.

### Boss

A powerful enemy with increased health and special attack patterns.

Boss encounters appear as the player progresses through the game.

---

## 🧬 Upgrade System

Defeating enemies gives XP.

When enough XP is collected, the player levels up and can choose upgrades.

Available upgrades include:

* Increased weapon damage
* Increased fire rate
* Increased movement speed
* Increased maximum health
* Additional projectiles
* Increased bullet speed
* Reduced dash cooldown

Build a different character setup during every run.

---

## 🎁 Pickups

Enemies can occasionally drop useful items.

### ❤️ Health

Restores player health.

### ⚡ Rapid Fire

Temporarily increases firing speed.

### 💥 Damage Boost

Temporarily increases weapon damage.

## 🌊 Wave System

## 💻 Run From Source

### Requirements

Install:

**Godot 4.7.x Standard**

The .NET/Mono version is not required.

### Run

Clone the repository:

```bash
git clone https://github.com/Wadan3/shadow-survivors.git
```

Enter the project folder:

```bash
cd shadow-survivors
```

Open `project.godot` with Godot.

Then press:

```text
F5
```

or click:

```text
▶ Run Project
```

The game should launch directly into the main menu.

## 🪟 Export for Windows

The project already contains a Windows Desktop export preset.

In Godot:

```text
Project
→ Export
→ Windows Desktop
→ Export Project
```

Install the Windows export templates first if Godot requests them.
