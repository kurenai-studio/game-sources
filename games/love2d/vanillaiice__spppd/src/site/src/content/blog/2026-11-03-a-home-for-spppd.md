title: A home for SPPPD
date: 2026-11-03
description: The game has a website, with downloads, the changelog and this blog.
---

SPPPD now has a home at spppd.xyz. Every new version will be downloadable
from here, for Windows, Android, and anywhere else LÖVE runs.

The same address is the official online server, so the game already knows the way.
Pick ONLINE, host a room, and send the code to up to three friends.

The latest version, 2.3.0, makes fences bite: a hard hit wrecks the car, and you
restart from where you hit, stopped. Bouncing off the walls flat out no longer pays.
Everything else that changed is in the [changelog](/changelog/).

New versions and what went into them will be posted here.
