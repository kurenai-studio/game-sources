# FlappyBird

Аркадная мобильная игра на Java + LibGDX: птица летит между колоннами, игрок управляет касаниями экрана.

## Полное описание

FlappyBird — аркадная игра для Android, написанная на Java с использованием фреймворка LibGDX и принципов ООП. Игрок управляет птицей, которая непрерывно движется вперёд между рядами колонн.

Механика управления:
- **Касание экрана** — птица делает рывок вверх
- **Без касания** — птица падает под действием гравитации

Условия окончания игры:
- Столкновение с верхней или нижней колонной
- Вылет птицы за границы экрана

Очко начисляется за каждую успешно пройденную пару колонн. Расстояние между колоннами постоянное, вертикальная позиция прохода меняется случайно.

В игре три экрана: главное меню, игровой экран и экран рестарта. Поддерживается повторная игровая сессия без перезапуска приложения.

## Авторские дополнения

### 1. Прогрессивная сложность
Скорость колонн постепенно растёт: каждые 5 очков колонны ускоряются на 2 единицы (базовая скорость 10, максимум 28). Это делает игру заметно сложнее по мере набора очков и удерживает интерес на протяжении всей сессии.

### 2. Анимация гибели птицы
При столкновении птица не исчезает мгновенно — она замирает, начинает вращаться вниз головой и падает в течение 1 секунды, прежде чем появится экран рестарта. Реализовано через отдельное состояние `GameState.DYING` с отрисовкой через `TextureRegion` с параметром вращения.

### 3. Вспышка экрана при столкновении
В момент гибели экран заливается красным полупрозрачным оверлеем, который плавно угасает за 0,4 секунды. Эффект реализован через `ShapeRenderer` поверх игровой сцены с настройкой `GL_BLEND`.

### 4. Смена цвета колонн
По мере роста скорости колонны постепенно меняют оттенок от белого к красному — визуально сигнализируя игроку о нарастающей опасности. Тинтинг реализован через `batch.setColor()` с интерполяцией по текущей скорости колонны.

### 5. Система медалей
На экране рестарта отображается медаль по результату сессии:
- **Бронза** — 0–4 очка
- **Серебро** — 5–14 очков
- **Золото** — 15–29 очков
- **Платина** — 30+ очков

### 6. Сохранение рекорда
Лучший результат сохраняется между сессиями через `LibGDX Preferences` и отображается на экране рестарта рядом с текущим счётом.

## Запуск

**Android:**
```
./gradlew android:installDebug
```

**Desktop:**
```
./gradlew desktop:run
```

## Структура проекта

```
core/src/ru/samsung/gamestudio/
├── MyGdxGame.java              — точка входа, управление экранами, хранение рекорда
├── characters/
│   ├── Bird.java               — птица: физика, анимация полёта и гибели
│   └── Tube.java               — колонна: движение, цветовой тинтинг, коллизии
├── components/
│   ├── FontManager.java        — генерация шрифтов с поддержкой кириллицы
│   ├── MovingBackground.java   — фон с параллакс-эффектом
│   ├── PointCounter.java       — отображение очков, рекорда и произвольного текста
│   └── TextButton.java         — кнопка с текстом
└── screens/
    ├── ScreenGame.java         — игровой экран: состояния PLAYING/DYING/GAME_OVER, вспышка
    ├── ScreenMenu.java         — главное меню
    └── ScreenRestart.java      — экран рестарта с медалью и рекордом
```
