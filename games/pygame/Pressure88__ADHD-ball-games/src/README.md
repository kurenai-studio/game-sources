# ADHD Ball Games

Небольшая игра на Python и Pygame CE с тремя режимами: планки, бесконечные кольца и боевая арена. Моды мячей подключаются отдельными Python-файлами.

## Режимы

- **Планки** — одиночное прохождение или гонка двух мячей. Нужно разбить планки с растущим здоровьем.
- **Кольца** — мяч с гравитацией проходит через отверстия бесконечного потока сужающихся вращающихся колец.
- **Арена** — дуэль двух мячей в квадратной комнате без гравитации или бой с неподвижным боссом за 60 секунд. Мячи двигаются автоматически, отскакивают от стен и используют свои боевые моды.

## Запуск

Нужны Python 3.10+ и Pygame CE.

### Windows

```powershell
cd путь\к\ADHD-ball-games
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py main.py
```

### Linux

```bash
cd ADHD-ball-games
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В главном меню выбери режим мышью или стрелками и нажми Enter. В меню мячей список можно прокручивать колёсиком. В гонках и аренной дуэли моды назначаются игрокам `A` и `B`; русские клавиши `Ф` и `И` тоже поддерживаются. `Esc` возвращает в меню, `R` перезапускает бой или попытку.

Чтобы посмотреть имена модов для режима планок:

```bash
python main.py --list-balls
```

Чтобы открыть конкретный мод первым в меню:

```bash
python main.py --ball speed_up
```

## Свои моды

### Планки

Добавь файл в `balls/`. В нём должен быть класс `Behavior`:

```python
class Behavior:
    name = "Мой мяч"
    description = "Короткое описание"
    color = (120, 220, 255)

    def initial_speed(self):
        return 340.0

    def damage(self, hits, ball, plank_number):
        return 1

    def on_bounce(self, ball, hits, plank_number):
        pass
```

Новый файл автоматически появится в меню. `ball.speed` можно менять в `on_bounce`, а урон задавать формулой в `damage`.

### Арена

Добавь отдельный файл в `arena_balls/`. В классе `Behavior` задаются `name`, `description`, `color`, `min_speed`, `max_speed`, `health`, `radius`, `contact_damage`, `shot_damage`, `shot_interval` и `shot_speed`. Если `start_speed` не задан, мяч начинает с `min_speed`. Столкновения меняют скорость в пределах этих ограничений.

Дополнительные параметры:

| Параметр | Значение |
|---|---|
| `speed_transfer` | Доля разницы скоростей, передаваемая сопернику при контакте, например `0.2` — 20% |
| `melee_armor`, `ranged_armor` | Снижение ближнего и дальнего урона; `0.25` блокирует 25% |
| `melee_penetration`, `ranged_penetration` | Пробитие соответствующей брони; `1.0` игнорирует её полностью |
| `vampirism` | Доля нанесённого урона, возвращаемая как здоровье; `0.2` — 20% |
| `bouncing` | Установи `1`, чтобы снаряды отскакивали от стен |
| `bouncing_count` | Число отскоков снаряда |
| `shot_pattern` | `"cross"`, `"aimed"`, `"spiral"` или `"shotgun"` |

Контактный урон считается ближним, урон снарядов — дальним. У босса по 25% ближней и дальней брони. Боевые моды независимы от модов планок.
