# 亲爱的失败者

> 基于 Three.js 的 2D 横版平台跳跃战斗游戏 | 暗黑奇幻像素风格

---

## 🎮 游戏简介

《亲爱的失败者》是一款受《死亡细胞》（Dead Cells）启发的 2D 横版平台跳跃战斗游戏。玩家扮演一位像素风骑士，穿越充满敌人的关卡，通过近战连击、平台跳跃和收集物品，最终抵达终点光柱获取胜利。

### 特色

- ⚔️ **爽快近战连击** — 两段攻击动画，打击火花、伤害飘字、屏幕震动
- 🧠 **智能敌人AI** — 近战兵巡逻追击、远程兵保持距离发射弹幕
- 🎨 **像素风格渲染** — 所有纹理通过 Canvas 动态生成，无需外部资源
- 💡 **动态光影** — 角色周围光晕效果，攻击拖尾与粒子特效
- 🎯 **连击计分系统** — 连续命中积累连击倍率，鼓励进攻
- 📷 **平滑摄像机** — 跟随玩家移动，支持屏幕震动

## 🕹️ 操作说明

| 按键 | 动作 |
|------|------|
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `W` / `↑` / `空格` | 跳跃（按住可变跳高） |
| `J` / `鼠标左键` | 近战攻击（节奏点击可触发二连击） |
| `R` | 死亡或胜利后重新开始 |

## 🚀 快速开始

### 环境要求

- 现代浏览器（Chrome 90+, Firefox 90+, Edge 90+）
- 无需 Node.js 或任何构建工具

### 运行方式

**方式一：使用本地服务器（推荐）**

```bash
# 使用 Python
python -m http.server 8080

# 或使用 Node.js (npx)
npx serve .

# 或使用 VS Code Live Server 插件
```

然后在浏览器打开 `http://localhost:8080`

**方式二：直接打开**

由于使用了 ES Module import map，部分浏览器可能需要通过 HTTP 服务器访问。直接双击 `index.html` 可能在部分浏览器中因跨域限制无法加载 Three.js。

> 游戏通过 CDN 加载 Three.js (v0.160.0)，首次加载需要网络连接。

## 🎯 游戏机制

### 战斗系统

- **二段连击**：第一段横斩（15伤害）+ 第二段上挑（22伤害）
- **连击窗口**：第一段攻击动画中再次按攻击触发第二段
- **连击计数**：每次命中增加连击数，2秒无命中则重置
- **得分倍率**：得分 = 伤害 × 10 × (1 + 连击数 × 0.15)

### 敌人类型

| 敌人 | 生命 | 行为 | 伤害 |
|------|------|------|------|
| 近战兵 | 40 | 巡逻 → 发现玩家 → 追击 → 近身攻击 | 12 |
| 远程兵 | 30 | 巡逻 → 发现玩家 → 保持距离 → 发射弹幕 | 10 |

### 物品

- ❤️ **血瓶** — 恢复 30 生命值
- 🪙 **金币** — 获得 50 分

### 关卡

手工设计的横向关卡，包含：
- 连续地面与高低浮动平台
- 墙壁障碍物
- 10个敌人（近战×6 + 远程×4）
- 12个金币 + 4个血瓶
- 终点光柱区域

## ⚙️ 自定义配置

编辑 `src/config.js` 可调整游戏参数：

```javascript
// 物理参数
PLAYER_SPEED: 280,          // 移动速度
PLAYER_JUMP_FORCE: -620,   // 跳跃力度
GRAVITY: 1800,             // 重力加速度

// 战斗参数
ATTACK1_DAMAGE: 15,        // 一段攻击伤害
ATTACK2_DAMAGE: 22,        // 二段攻击伤害
PLAYER_MAX_HP: 100,        // 最大生命值

// 敌人参数
MELEE_HP: 40,              // 近战敌人生命
RANGED_HP: 30,             // 远程敌人生命
ENEMY_SIGHT_RANGE: 350,    // 敌人视野范围
```

编辑 `src/level.js` 可自定义关卡布局（平台位置、敌人配置、物品放置）。

## 🐛 常见问题

**Q: 画面不显示 / Three.js 加载失败？**
A: 请确保使用 HTTP 服务器打开（而非 `file://` 协议），并检查网络连接以加载 Three.js CDN。

**Q: 按键没有反应？**
A: 请点击游戏画面确保窗口获得焦点。按键使用英文输入法布局。

**Q: 性能卡顿？**
A: 游戏设计目标为 60fps。如果卡顿，请检查浏览器是否开启硬件加速，或降低 `window.devicePixelRatio`。
