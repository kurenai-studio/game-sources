# SumUp Assets Log

Owner: senior-graphic-designer. Last checked: 2026-10-17 (the Google Play store graphics, section 5).

The rule (CLAUDE.md): nothing paid and nothing third party, and every visual and every sound is made in code. This log lists every visual and every sound the game uses, what makes it, and where that code lives. It also records the exceptions Bart approved: the Outfit font and its license (Hard Stop 1), and the GPL text (2026-10-13).

Status says whether the item exists yet. Owners follow the ownership table in CLAUDE.md. Folder and class details follow docs/ARCHITECTURE.md where it is more specific.

The launcher icon PNGs are the only image files the shipped game contains. They are generated by code in this repo, not hand made or downloaded. They are committed, so a build never depends on running the tool; rerun it whenever the Gumdrop colors, tile radius, lip or tile font change. Godot writes a `.png.import` file next to each when it imports the folder: engine settings, not a third party file.

**Checks.** Since Phase 3 the contrast, ramp and label checks in tools/ (contrast_check.gd, ramp_check.gd, label_check.gd) load the shipping SkinData resources through SkinCatalog, not the Phase 1 token files, so they prove what ships. The label check measures each skin in its own font: Outfit for Gumdrop and Nova, the system font for Slate. Since 2026-10-14 the contrast check also covers Nova's wordmark glow (accent and ink on the glow, DESIGN_SYSTEM.md 6.3).

The phone shots are laid out on a 1350 by 2400 canvas and drawn at 0.8 scale into 1080 by 1920, exactly as project.godot's canvas_items stretch shows the game on a 9:16 phone, with a small simulated safe area (48 px on top, 24 at the bottom). `--fixed-fps 60` gives every frame the same time step, so looping motion such as the active booster's wobble lands on the same frame each run; the capture tool refuses to run without it.
