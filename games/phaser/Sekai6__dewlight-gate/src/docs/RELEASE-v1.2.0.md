# v1.2.0 — ACTION-A-DOLL-HIT

## 更新

- ACTION-A 第五轮：全身发力、支撑重心联动、空中两段攻击身份和收势恢复。
- 新增 ACTION-A-DOLL-HIT：苔影轻击、玻璃蛾扑击、守卫冲锋和根浪分别产生不同冲量。
- 主控实际击飞，躯干翻转，四肢惯性摆动，落地弹跳、翻滚和起身。
- 短暂失控后按空格或 Shift 受身；支持 0.12 秒输入缓冲。受身不额外触发跳跃或冲刺，不重置技能冷却。
- 倒地期间延续受伤保护，碰撞和翻滚不追加伤害；致命伤及坠落沿用检查点恢复。
- 开发预览增加四种伤害、受身、根部轨迹与关节约束诊断，生产构建不暴露入口。

## 验证

发布准备前：56 项单元测试、70 项浏览器回归通过，格式检查、TypeScript、生产构建及生产入口隔离验证通过。本机原生 WebGPU 测试实际执行；CI 无适配器时会明确跳过，不代表 GPU 验证成功。

本机三轮配对测试：连续击飞主线程 P95 为 5.3 → 5.5 ms（+3.8%），普通场景 5.1 → 5.1 ms；帧间隔 P95 不变，对象和纹理数量稳定。性能数值不代表所有设备。

## 兼容性与限制

旧存档无需迁移。击飞及受身属于本版明确的玩法变化，伤害数值和 Boss 预警时长保持不变。四肢采用支撑面有限约束，并非通用多刚体物理引擎。动作观感可通过 Release 的前后录像评估；自动化通过不等于审美验收。

录像每段 24 秒，依次展示轻击、飞扑、冲锋和根浪；每种伤害先自动起身，再演示受身。120 Hz 模拟，30 fps 编码。
