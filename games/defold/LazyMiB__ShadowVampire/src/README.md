# Shadow Vampire

This game made for [Brackeys Game Jam 2025.1](https://itch.io/jam/brackeys-13). Version 0.1 corresponds to the version for jam.

**Nothing can go wrong**, because you can't die in this game: when your oxygen or energy runs out, you're teleported to a recharging station. But the shadows are chasing you, and the flag is so far away... *Nothing can go wrong*?

## Controls

* A, D: move
* W, Space: jump
* R: tp to spawn
* Esc, Q: pause

### In menu's

* Esc, Q: resume, exit
* W, Space: start
* S: to about / to menu
* 1, 2: toggle checkboxes
