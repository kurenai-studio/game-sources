# Defold Brick breaker

Defold Brick Breaker is a very simple clone 
of a popular game. I built this project 
in a couple of days while learning Defold, 
and I really enjoyed using the engine! 
The game recreates only the essential core mechanics, 
without power-ups.

https://electroblaststep.itch.io/defold-brick-breaker
