# v3 天空：朝霞、蓝天白云、晚霞、星空

日期：2026-10-18
状态：已确认（用户选 A：低多边形云；星星要闪）
父文档：`docs/superpowers/specs/2026-10-18-v3-stamina-day-design.md`（4.8）

## 1. 要解决什么

真机上抬头是**灰蒙蒙一片**，看不出一天的变化。两个原因叠加：

1. 雾密度 `0.0012`：120 米外就压 13% 灰。
2. 天空只有「天顶 / 地平线」两个色，且地平线被夜色色和日落色各稀释一次，出来是灰绿。

目标：抬头就能读出「今天过到哪了」——朝霞 → 蓝天白云 → 午后偏暖 → 晚霞 → 星空。

## 2. 前提（决定了配色曲线的取值范围）

玩家实际能看到的天色只有 **`time_of_day` 0.28 ~ 0.86** 这一段：

- 睡醒是满体力 = 0.28（日出后一点，正好做朝霞）
- 体力见底压到 0.86 就停（夜）

0.28 以下、0.86 以上永远不会出现，配色曲线不用管。

## 3. 做法（三层，都不引进着色器）

### 3.0 先修的两个真 bug（不做这个，下面全是白干）

1. **天空从来没被渲染过**：`forest.tscn` 里把 `ProceduralSkyMaterial` 直接赋给了 `Environment.sky`，
   而那里要的是 `Sky` 资源（`Sky.sky_material` 才装材质）。类型对不上 → `Environment.sky` 是 `null`
   → `DayNight` 写 `_sky.sky_*` 全部静默无效，屏幕上一直是**视口清屏灰 + 雾**。这就是「灰蒙蒙」的根。
   修法：补一个 `Sky` 子资源包住材质。
2. **雾把整片天吃掉**：`Environment.fog_sky_affect` 默认 1.0，指数雾在无穷远处取满 → 天空等于雾色。
   真机实测：t=0.50 时天空像素是 (0.93, 0.96, 0.99) 的近白，改完后是 (0.22, 0.55, 0.88) 的蓝。
   修法：`fog_sky_affect = 0.0`。

### 3.1 天空底色：按段时间轴

`DayNight.sky_top(t)` / `sky_horizon(t)` 改成关键帧插值（表见 4）。

| 时段 | t | 观感 |
|---|---|---|
| 朝霞 | 0.28 | 地平线暖橙粉，天顶淡紫蓝 |
| 上午 | 0.36 | 清爽蓝，地平线近白 |
| 正午 | 0.50 | 天顶饱和蓝 #2F6FC8，地平线近白 |
| 午后 | 0.68 | 开始偏暖 |
| 日落前 | 0.78 | 紫天顶，橙地平线 |
| 晚霞 | 0.80 | 地平线橙红，天顶深紫 |
| 入夜 | 0.84 → 0.86 | 藏青天顶，深蓝地平线 |

雾密度 `0.0012 → 0.0008`、`fog_sky_affect = 0.0`、`sky_curve = 0.45`（只改 `forest.tscn` 的 Environment / 材质）。
雾色继续跟 `sky_horizon` 走。

`sky_curve` 从默认 0.15 提到 0.45：森林在 26° 高的地形碗里，地平线的暖色带原本压在山脊后面看不见，
铺得高一点朝霞晚霞才翻得过山。同理天顶在 0.28 也带一点暖（`#949ED6`），不然刚醒只有地平线是暖的。

### 3.2 云：低多边形团块

- 10 团，每团 4 个压扁的 `SphereMesh`，挂在**跟随相机**的 200 米环上（和太阳月亮同一套做法，不产生视差）。
- 缓慢绕 Y 自转当飘移（`0.004 rad/s`）：一圈约 26 分钟，不会飘出环外，不用回绕逻辑。
- 颜色跟太阳高度走：白天纯白，朝霞/晚霞变暖。**不透明度靠往天空色上混**，不用 alpha —— 云始终不透明，免掉透明排序的接缝。
- 天黑（`cloud_fade` 归零）就不画了。
- 云和星星都关雾（`fog_enabled = false`）：天空元素不该被地面雾压灰。

### 3.3 星星：会闪

- 150 颗小球，半径 300 米半球（y > 0.08），每颗大小略有差异。
- `star_fade(t)`：0.78 起淡入、0.855 全亮、0.86 满天星。淡入靠往天色上混，保持不透明。
- **闪烁用 3 组**：星星分 3 个 `MultiMesh`，每组的材质亮度各自按 `sin` 脉动，相位错开 2.1 弧度。整片天持续有明有暗，逐星不是独立随机，但看得出在闪。
  - 为什么不用逐实例颜色：150 次 `set_instance_color` 每帧是 0.2~0.3 ms 的 GDScript 开销，3 组脉冲是 0。
- 星星不随时间转（云在转就够，转多了晕）。

## 4. 关键帧表（唯一口径，别处不许再算天色）

```
t:        0.28        0.36        0.50        0.68        0.78        0.80        0.84        0.86
sky_top:  949ED6      4A8CD4      2F6FC8      3E70B4      6B6BA8      45407A      1A1B3E      0B0E24
horizon:  FFB98A      CFE3F5      DCEBF7      F2D9C0      FFA76B      FF6E3C      6A3C50      1C2542
```

## 5. 数字（全进 `game/config.gd`）

`CLOUD_COUNT 10`、`CLOUD_PUFFS 4`、`CLOUD_DISTANCE 210`、`CLOUD_HEIGHT_MIN 95`、`CLOUD_HEIGHT_MAX 160`、`CLOUD_DRIFT 0.004`、`STAR_COUNT 150`、`STAR_GROUPS 3`、`STAR_DISTANCE 300`、`STAR_TWINKLE_SPEED 2.4`

云的高度按「210 米处 24~37° 仰角」定：地形碗的山脊就有 26°，云摆在 45~85 米（≈17°）会被山挡住，等于没有。

## 6. 成本

- DRAW +4（云 1 + 星星 3），三角面约 +1.3 万（现在是 348k）。
- 每帧开销：两次节点位置 + 一次自转 + 3 个材质色，没有逐实例写入、没有每帧实例化节点。

## 7. 验收

- `bash scripts/test.sh` 全绿，新增纯函数测试：正午天顶是蓝的、入夜变暗偏蓝、朝霞地平线暖、晚霞橙红、云的显隐与配色、星星只在夜里。
- 真机：睡醒抬头看到朝霞和云；正午蓝天白云；体力见底太阳压山后晚霞转星空，星星在闪。
