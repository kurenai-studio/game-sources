# ip-02-three-game · 拾光者 CORE RUNNER

> 互动编程 · 作业二｜Three.js｜作者：马雪容

一个能完整玩起来的 3D 收集小游戏：你是一颗会发光的小球，
要在 60 秒内收齐平台上的 12 枚能量核心，同时躲开 4 个红色巡逻者。

**在线试玩**：<https://Maxr0428.github.io/ip-02-three-game/>

---

## 游戏规则

| 要素 | 说明 |
| --- | --- |
| 目标 | 收集全部 12 枚能量核心（暖橙 / 冷青交替） |
| 时间 | 60 秒倒计时，最后 10 秒计时变红提醒 |
| 护盾 | 3 格；碰到巡逻者扣 1 格并触发 1.4 秒无敌 + 击退 |
| 胜利 | 60 秒内集齐 12 枚 |
| 失败 | 护盾耗尽，或时间到 |

## 操作方式

| 按键 | 功能 |
| --- | --- |
| W A S D / 方向键 | 移动（方向始终跟随当前视角） |
| 鼠标拖拽 | 旋转轨道视角（触屏单指同样支持） |
| 滚轮 | 缩放视距 |
| 空格 | 在结算面板直接开始 / 重开一局 |

## 技术实现

- **three.js r152**（UMD 版随仓库附带于 `lib/`，离线双击 `index.html` 即可运行，无任何构建步骤）。
- **场景搭建**：圆形平台 + 发光边缘环 + 三圈导轨细线 + 14 座错落方碑 + 420 颗星尘；
  半球环境光 + 暖色主光（2048 阴影贴图）+ 冷色轮廓光，玩家自带点光源。
- **相机**：自实现的轻量轨道控制（约 90 行），支持拖拽旋转、滚轮缩放、平滑跟随玩家。
- **交互**：键盘输入按相机偏航角换算成世界方向，转视角后「前」永远是屏幕前方；
  碰撞采用距离判定，受击后有击退与无敌闪烁，避免连续扣血。
- **性能**：`pixelDensity` 上限 2、单帧步长封顶 50ms（切后台回来不瞬移），
  桌面 Chrome 实测稳定 60fps。
