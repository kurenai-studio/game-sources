## 开始使用

在本目录打开 PowerShell：

```powershell
# 打开编辑器，进入后按 F6 运行当前场景，或按 F5 运行整个项目
powershell -ExecutionPolicy Bypass -File .\tools\run.ps1 -Editor

# 直接运行竖屏游戏（不需要额外参数）
powershell -ExecutionPolicy Bypass -File .\tools\run.ps1

# 导入资源，运行规则回归测试、UI 集成测试和完整牌局启动检查
powershell -ExecutionPolicy Bypass -File .\tools\check.ps1

# 生成调试 APK
powershell -ExecutionPolicy Bypass -File .\tools\export-android.ps1
```

`-ExecutionPolicy Bypass` 仅作用于这次启动的 PowerShell，不会修改系统执行策略。

APK 路径：`builds/android/somnicard-debug.apk`。它用于开发测试，不是商店发布包。

连接安卓手机：在手机中开启开发者选项与 USB 调试，使用支持数据传输的 USB 线连接，确认手机上的调试授权，然后执行：

```powershell
adb devices
# 仅当设备状态显示 device 且只有一台目标设备时执行
adb install -r .\builds\android\somnicard-debug.apk
```

## 项目结构

- `project.godot`：引擎项目入口。
- `scenes/main.tscn`：启动场景。
- `scripts/main.gd`：牌桌界面、操作按钮、电脑行动定时器和记录保存。
- `scripts/ui/home.gd`：竖屏主界面、继续牌桌与主要功能入口。
- `scripts/ui/data_settings.gd`：设置中的本地备份文件操作与结果反馈。
- `scripts/ui/table_view.gd`：2–9 人环形座位和自适应牌桌显示。
- `scripts/ui/bet_sizing.gd`：BB、底池比例与合法下注总额的转换。
- `scripts/ui/review.gd`：历史列表、回放、建议界面与玩法帮助。
- `scripts/ui/sheet.gd`：滚动底部面板与软键盘空间处理。
- `scripts/ui/settings.gd` / `preferences.gd` / `confirm.gd`：设置草稿、偏好迁移/保存与操作确认。
- `scripts/ui/card_view.gd` / `seat_badge.gd` / `lobby_art.gd`：原创可缩放卡牌、徽章与入座页插画。
- `scripts/poker/table.gd`：独立的多座位下注状态机和分池结算。

## 玩第一手

1. 在 Godot 按 F5，选择桌型和初始筹码，再点击“开始”。第一手你是庄家。
2. 轮到你时可以跟注/过牌、弃牌、加注或全押。点击 BB 或底池比例档位会先填入金额，点击加注按钮后才提交。
3. 顶部可切换筹码/BB和暂停；记录从“更多”进入，速度、快进、配色和全押确认在“设置”中调整。输入框中的“加到”是本轮总额，下方会显示本次额外投入。
4. 摊牌后在牌桌与记录中查看获胜者、牌型和分池结果。点击“下一手”保留筹码继续。
5. 你输光或全桌只剩一人有筹码时，“补码重开本桌”按最初选择的筹码深度重开所有座位。
6. “换桌”会暂停当前牌局；“返回原桌”保持筹码与牌局不变，并丢弃临时人数/深度。只有开桌并确认重置后才替换当前桌。
7. “教练”打开当前决策分析，不会代替你下注；“复盘”可查看以往完整牌局。教学在设置中分别开关，BB / 筹码切换同步回主牌桌。
8. 重启后可“恢复上次牌桌”，点击顶部“继续”恢复行动；选择开始新桌则替换当前自动存档，历史完整牌局保留。

桌面快捷键：F 弃牌、空格过牌/跟注、R 聚焦下注输入、P 暂停。输入框内打字时不会触发操作快捷键。

Windows 牌局记录保存在 `%APPDATA%\Godot\app_userdata\Somnicard\hands`。完整记录在整手结束后写入，包含重放所需的牌堆和操作；当前牌桌另存于同级的 `session.json`。电脑和建议接口无法访问完整牌堆或他人底牌。数据仅存本机；卸载应用或清除应用数据可能删除记录。

## 开发边界

第一版采用虚拟筹码和离线 2–9 人无限注德州扑克。引擎、电脑策略和教学解释分开设计。对手只能获取它自己的手牌、公共牌和公开下注记录。复盘建议按当时可知的信息计算，避免用后面发出的牌倒推决策。

本地规则策略与胜率估算属于练习辅助，不宣称最优策略或 GTO。未来 API 密钥不写进项目或 APK，正式联网版通过服务端代理接入。

已完成桌面自动测试、竖屏及宽窗口居中显示检查与安卓调试包构建；本轮按用户安排不做真机验收，触摸、中文字体、软键盘、后台恢复与设备性能仍待后续实测。调试包不是商店上架发行包。
