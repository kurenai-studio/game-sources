# 《镇夜录》垂直切片设计

## 核心定位

- 类型：PC 端单人俯视角动作 Roguelite。
- 题材：架空东方志怪，游方镇妖师在鬼夜中清除失控邪祟。
- 视觉：玄黑水墨底色、朱砂符箓、旧金法器、青玉灵光。
- 单局：章节包含 8 至 16 个战斗波次与终关首领；无尽轮回每五波更换地域并迎战强化首领。
- 操作：移动、自动法器、一个主动镇魂阵；复杂度集中在走位与构筑。

## 首名角色

**游方镇妖师**

- 初始法器：飞剑。
- 主动术法：镇魂阵，击退并伤害近身邪祟。
- 定位：均衡远程角色，用飞剑处理单体，以其他法器补充清场能力。

## 首批法器

| 法器 | 战斗职责 | 五阶变化 | 进化 |
|---|---|---|---|
| 飞剑 | 自动追击近敌，稳定单体输出 | 增加剑数、伤害与穿透 | 五阶飞剑 + 养剑诀 = 万剑归宗 |
| 符火 | 命中后范围爆炸 | 提高爆炸范围和伤害 | 五阶符火 + 真火心法 = 三昧真火 |
| 雷印 | 周期性打击多个目标 | 增加雷击数量 | 五阶雷印 + 调息法 = 九霄雷狱 |
| 镇魂铃 | 周期性释放近身冲击波 | 扩大范围并强化击退 | 五阶镇魂铃 + 护心镜 = 黄泉镇魂钟 |
| 铜钱镖 | 在敌群中连续弹射 | 增加弹射次数和铜钱数量 | 五阶铜钱镖 + 聚灵玉 = 落宝金钱 |
| 阴阳玉 | 持续环绕角色造成接触伤害 | 增加玉数和环绕半径 | 五阶阴阳玉 + 踏罡步 = 两仪轮转 |
| 缚妖索 | 将多个目标串联起来 | 增加连接目标数量 | 五阶缚妖索 + 聚灵玉 = 天罗缚妖阵 |
| 招魂幡 | 形成持续近身伤害领域 | 扩大领域和伤害 | 五阶招魂幡 + 真火心法 = 万魂归幡 |
| 纸人术 | 释放自动追敌的纸傀分身 | 增加纸傀数量与穿透 | 五阶纸人术 + 踏罡步 = 撒豆成兵 |
| 八卦镜 | 发射持续旋转的直线镜光 | 增加镜光长度、宽度和伤害 | 五阶八卦镜 + 调息法 = 八门金光镜 |
| 潮生葫 | 宽阔潮浪贯穿敌群 | 双浪并在尽头折返 | 五阶潮生葫 + 真火心法 = 煮海吞江葫 |
| 引渡桨 | 近身扇区控制和船痕 | 追加回桨与破邪船痕 | 五阶引渡桨 + 踏罡步 = 一苇渡幽冥 |
| 冥河莲灯 | 定点持续压制 | 增加莲灯数量与终脉冲 | 五阶冥河莲灯 + 聚灵玉 = 黄泉引魂莲 |
| 玄冰针 | 高速扇形穿透 | 增加针数与穿透 | 五阶玄冰针 + 养剑诀 = 太阴万劫针 |
| 寒狱碑 | 延迟范围爆发 | 多目标落碑并产生裂痕 | 五阶寒狱碑 + 护心镜 = 万载寒狱碑 |
| 六花伞 | 近身扫击和弹幕防御 | 双向伞面并化解更多弹体 | 五阶六花伞 + 调息法 = 六花回天伞 |
| 判官笔 | 长距离直线贯穿 | 增加并行判词数量 | 五阶判官笔 + 洞玄法眼 = 生死判牒 |
| 照夜灯 | 多点范围镇压和牵引 | 增加魂灯数量与范围 | 五阶照夜灯 + 吞煞诀 = 万象长明灯 |

每局可以获得全部十八种法器，并通过升级逐步完成全法器构筑。

## 首批心法

- 养剑诀：提高法器攻击频率，也是飞剑进化条件。
- 真火心法：提高所有伤害，也为符火进化提供条件。
- 踏罡步：提高移动速度。
- 护心镜：提高生命上限并立即治疗。
- 聚灵玉：提高残魂拾取范围。
- 调息法：缩短法器和主动术法的冷却时间。
- 洞玄法眼：提高对精英和首领的伤害，也是判官笔进化条件。
- 吞煞诀：镇伏邪祟后恢复少量生命，也是照夜灯进化条件。

## 首批敌人

- 游魂：标准追逐敌人。
- 纸傀：速度快、生命低。
- 石祟：速度慢、生命高、接触伤害高。
- 鬼灯：保持距离并向玩家发射鬼火。
- 僵尸：周期性加速冲向玩家。
- 裂魂：死亡后分裂为两个高速魂火。
- 纸傀祭师：荒村专属，在中距离召出三只纸傀。
- 阴山尸祟：阴山专属，首次死亡后进入复生状态并以半血重新站起。
- 古刹镇守鬼：古刹专属，锁定玩家位置释放减速封锁区。
- 藻缚溺鬼、引魂河灯、无头艄公、捞魂网客和水蛭巫祝构成水乡敌群，分别拥有水藻减速、扇射、船痕冲锋、网阵和治疗能力。
- 雪魈、冰棺尸、风刃魅和霜狱监构成雪岭敌群，分别拥有扑击、死亡冰爆、十字风刃和寒狱光环。
- 每三个波次出现一只强化精英邪祟。
- 无尽模式为普通敌人追加迅疾、巨化、灵盾和复仇四类词缀，并使用不同轮廓标记提示其能力。

## 章节与首领

| 章节 | 波次 | 地图事件 | 首领 | 主要招式 |
|---|---:|---|---|---|
| 荒村鬼夜 | 8 | 纸傀夜行 | 百目傩君 | 旋转鬼火阵与十字眼阵 |
| 乱葬阴山 | 10 | 群坟开棺 | 白骨夫人 | 复生骨卫、缺口骨墙与扇形骨针 |
| 锁妖古刹 | 12 | 古刹业火 | 无相鬼佛 | 可击破阵眼与带安全扇区的轮转弹幕 |
| 幽都水乡 | 14 | 黄泉倒灌 | 无渡河伯 | 潮道、安全水路与引魂河灯 |
| 寒狱雪岭 | 16 | 万壑雪崩 | 玄霜狱主 | 双向雪崩、冰棺守卫与安全走廊 |

五个章节拥有不同地面配色、场景符号、敌人数值、刷怪密度、事件、音乐和首领外形。首领在 66% 和 32% 生命时进入第二、第三阶段，并引入新的走位或目标处理机制，而不只提高生命和弹幕数量。

章节战斗地图尺寸为 `3600×2400`，无尽地图为 `6000×4000`。无尽模式混合五章敌群，每五波轮换地貌、音乐、事件和首领；首领依次获得狂怒、铁壁、召魂和灾变词缀，生命与威胁随轮回数持续提高。

## 当前阶段验收

1. 十八种法器拥有明显不同的攻击方式和战斗职责。
2. 升级池能够获得、升级并进化法器。
3. 单局可以逐步集齐十八种法器，并完成全部法器联动。
4. 五个章节的场景、事件、敌潮和首领战能够被清楚区分。
5. 不依赖外部美术也能看出东方志怪的颜色和轮廓语言。

## 局外闭环

- 精英掉落装备宝匣，首领必定掉落装备，首次通关额外获得高品质装备。
- 装备包含本命法器、道冠、法袍、腰饰、云履和护符六个部位。
- 品质分为凡品、良品、灵品、玄品、地品和天品。
- 装备具有随机词缀，支持五次强化、穿戴和分解。
- 本命法器决定角色开局携带的法器。
- 装备属性可以影响伤害、生命、移速、拾取、冷却、经验、掉率和少量续航。
- 灵品以上本命法器和护符可低概率出现“噬魂吸血”，按实际伤害恢复生命，每秒恢复量不超过生命上限的 2%。
- 玄品以上装备按部位追加一条规则特性，包括开局铜钱、免费刷新、致命护命、波次治疗、踏风和额外修行选择。
- 局外资源为香火、器魄、玄铁和残卷，并通过本地存档永久保存。
- 特定波次结束进入鬼市，可以使用独立铜钱购买、刷新和锁定局内强化。
- 道行命盘包含十七个节点，使用香火永久提升生命、持续回血、伤害、减伤、移速、冷却、残魂获取、拾取、经济和寻宝属性。
- 六个单点神通分别提供开局额外三法器、首领增伤、死亡复生、全图摄魂、鬼市折扣和无心法进化。
- 天师敕令满阶额外获得一次规则型护命效果。
