## Open questions and notes for the DM

- **Fixtures depend on a test file.** `tools/balance/fixtures.gd` preloads `tests/sim/fixtures/creature_fixtures.gd` and calls `catalog()`. If the sim engineer renames it, every bot fails to compile, tier 0 included. The standing rule is preload, so I kept it. A copy of the catalog under `tools/balance/` is the alternative.
- **`GameData` fields.** The fixtures set `game.catalog`, `game.levels` and `game.run` directly. If those ever get setters or typed readers that refuse this, the fixtures break.
- **Plain recipe puts the Bramble Cottage on a low road spot** (it is the fifth attacker in the turn, so it lands around the fifth or sixth spot). In `r5_fx1` it fired 0 times in plain plays. That is RULES 12.6's order, so I did not change it. The game designer may want to know before E5.2.
- **Bot weights for the new towers are guesses** (Bramble 1.0, Scarecrow 0.8 with cap 2, Snow Fort 1.0, Moth Lantern 0.7). The first real tier 1 run pass will show whether the bots play the new towers worse than the old ones; fixture win rates cannot.
- **A bot Scarecrow gets no event.** The report can only show that it was built, not that it frightened anything. A `frightened` counter on the sim side would let the bots show it. This is a suggestion, not a request.
