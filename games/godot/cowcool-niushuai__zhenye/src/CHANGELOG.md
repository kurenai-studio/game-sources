# 更新日志

## v0.1.0-alpha — 2026-11-10

首个公开试玩版本。

### 内容

- 五大章节：荒村鬼夜、乱葬阴山、锁妖古刹、幽都水乡、寒狱雪岭。
- 十八种法器、十八种五阶进化、十三组联动、八门心法。
- 十八类基础敌人、五位多阶段首领、五十四件装备模板。
- 十七节点道行命盘，包含六个单点神通。
- 无尽轮回模式：`6000×4000` 大地图、每五波轮换地域、周期首领与敌人/首领词缀。
- 完整局外循环：铜钱、香火、器魄、装备强化与分解、自动存档、逐波战报。

### 体验

- 640×360 内部分辨率，2 倍整数缩放与像素对齐。
- 独立章节音乐、环境音、法器音效和首领机制演出。
- 失败可带回已拾取战利品，无尽模式可主动结算。

### 已知问题

- macOS 构建未签名，首次启动需要右键打开或执行 `xattr -cr`。
- 手柄、键位重映射与多语言尚未接入。
- 数值与界面仍在调整，存档结构可能随版本变化。
