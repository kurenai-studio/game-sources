For item 2, Zero Hour human units acquire only in weapon range and do not chase; the M4.1 scan used the AI rule for both controllers.

1. **Attack-move click has no visual.** Show a marker at the click.
2. **Human-controlled units seem to auto-attack and chase from far away.** Units gathered in front of the factory moved aggressively at the enemy from a large distance. The user believes original Zero Hour units do not do this. Unverified: check Zero Hour's default stance and acquire/chase range before changing.
3. **Attack-move fails for a split army.** If part of the army is already engaged and the rest is still in the base, the attack-move leaves the units in the base standing there.
4. **No visual clue when a dozer is sent back to finish an unfinished building.** Sending a dozer away from a building that is not fully built and then right-clicking the building to resume gives no feedback. Zero Hour source (GeneralsGameCode `afc2a103f`, `GeneralsMD`):

   - Command feedback: issuing the command plays the selected unit's `VoiceBuildResponse` (`CommandXlat.cpp:1854`, `:617`).
   - State feedback: an unfinished building shows its construction percent text while `OBJECT_STATUS_UNDER_CONSTRUCTION` is set (`Drawable.cpp:3618`, `drawConstructPercent`).
   - Not looked up: the cursor art, the dozer's build animation and the exact percent layout. Wargrid has no audio, so its equivalent of the voice line and cursor is open (candidates: a resume cursor or outline on hover, a brief marker on the building when ordered, and a percent label while under construction).
