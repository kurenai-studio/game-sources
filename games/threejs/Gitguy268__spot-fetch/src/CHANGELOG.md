# Changelog

All notable changes to this project are recorded here. The format follows

## [Unreleased]

### Added

- The first public version of the game.
- Water, snow, sand or earth spatters up where the ball lands, more of it the harder the hit.
- A **Volledig scherm** button for full screen, hidden where the browser cannot do it.
- `LICENSE` (MIT), `NOTICE`, `README.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, issue and pull request templates, CI and a Dependabot configuration.

### Changed

- The GLB model loader is downloaded only when a dog is configured with a model file. The start-up bundle is about 42 kB smaller (12 kB gzipped).
