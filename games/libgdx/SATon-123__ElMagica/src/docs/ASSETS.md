# Картинки и звук

Картинки делались через генерацию изображений OpenAI: идеи и правки от SA_Ton_, помощь с подготовкой от Codex. Это не полностью ручная пиксельная графика. Исходные листы и промпты лежат в `art-source/`, игра их не загружает. Скачанных паков спрайтов при проверке проекта не было.

## Где искать готовые файлы

| Папка | Содержимое |
| --- | --- |
| `assets/characters/player/` | Маг; цвет стихии и анимации задаются в Java |
| `assets/characters/enemies/` | Слизень, стрелок и змея |
| `assets/characters/bosses/` | Шесть сочетаний стихий |
| `assets/characters/npc/` | Торговец |
| `assets/rooms/{ruins,temple,volcano,ice}/tiles/` | По три пола и стены для каждого биома |
| `assets/rooms/<biome>/obstacles/` | По восемь вариантов укрытий |
| `assets/rooms/<biome>/gates/` | Закрытые и открытые ворота |
| `assets/items/<biome>/` | Книга и зелье лечения |
| `assets/items/coins/` | Монета и кучка монет |
| `assets/shop/` | Пьедестал, карты и зелье |
| `assets/ui/menu/` | Обложка меню |
| `assets/ui/icons/` | Иконки из спрайта мага |
| `assets/audio/music/` | Спокойная, боевая и боссовая музыка |
| `assets/audio/sfx/` | Одиннадцать звуковых эффектов |

## Если понадобится нарезать заново

`tools/split_assets.py` собирает 91 отдельную картинку и иконки игры. Нужны Python и Pillow, самой игре они не нужны.

Персонажей, товары и укрытия режем по силуэтам, прихватывая отдельные детали рядом. Пиксели соседнего объекта отбрасываем. У ворот границы подобраны отдельно. Ровная сетка используется только для пола и стен: остальные листы недостаточно ровные для такой нарезки.

Размеры отрисовки и хитбоксы от нарезки не меняются. Исходные листы и хеши готовых файлов записаны в `asset-manifest.json`.

## Звук и шрифт

Музыку и эффекты создаёт `tools/generate_audio.py` на стандартной библиотеке Python, без сторонних сэмплов. Запускать его нужно только при изменении звука. Пиксельный шрифт описан в `PixelText.java`, отдельного файла шрифта нет.
