# Changelog

All notable changes to Shadow Survivors are documented here.

## 1.0.0 — 2026-08-23

- Added complete main-menu-to-game-over state flow.
- Added player movement, mouse aiming, pulse blaster, dash, health, and invulnerability.
- Added Grunt, Runner, Tank, Elite, and Boss enemies.
- Added scalable automatic waves and every-fifth-wave boss encounters.
- Added XP, leveling, seven upgrade types, score, kill count, and survival scoring.
- Added Health, Rapid Fire, and Damage Boost pickups.
- Added procedural neon arena, particles, camera shake, animations, and synthesized SFX.
- Added responsive HUD, pause menu, upgrade selection, and game-over results.
- Added local high-score and best-wave persistence.
- Added Windows export preset, documentation, MIT license, and Godot `.gitignore`.
- Validated with Godot 4.7 stable and an automated gameplay smoke suite.
