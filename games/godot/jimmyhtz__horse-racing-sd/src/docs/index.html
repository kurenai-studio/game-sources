About this release

This first public version is a prerelease. Windows installation, removal, packaged audio and help have been checked locally. Native Windows, macOS and Linux builds pass automated startup and help checks. Mac and Linux voice and interactive behavior still need community testing. The ARM64 Linux build has not been run on ARM hardware.

The Windows installer is unsigned. The macOS app is ad-hoc signed and is not Apple-notarized. Operating systems may ask you to confirm an unidentified publisher. Use only downloads linked from this project and keep normal system protections enabled.

Live Track and Off Track modes are planned. Their unfinished settings remain visible and dimmed. Play uses virtual credits.
