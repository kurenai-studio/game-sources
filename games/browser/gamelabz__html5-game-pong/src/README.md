# 🏓 Pong

🏓 Pong — a modern, dependency-free HTML5 game built with Canvas and vanilla JavaScript.

🎮 **Play Online:** https://gamelabz.github.io/html5-game-pong/

## 📸 Screenshot

![Pong](assets/images/screenshot.png)

## 🎯 About

Classic two-paddle duel: outplay the AI, angle your returns, and race to the winning score.

## 🕹️ Controls

- Move paddle: Mouse or Up/Down / W S
- Pause: P
- Restart: R

## ✨ Features

- Smooth ball physics with angle control
- Beatable but challenging AI opponent
- Glowing paddles and ball, glass HUD

## 🚀 Run Locally

No installation required. Open the game directly in a browser:

```bash
# Option A: just open the file
open index.html

# Option B: serve it with a tiny static server
npx serve .
```

Then visit the printed URL (default `http://localhost:3000`).

## 🛠️ Tech Stack

- HTML5 `<canvas>`
- CSS3 (custom properties, flexbox, glassmorphism)
- Vanilla JavaScript (ES2020, no frameworks)
