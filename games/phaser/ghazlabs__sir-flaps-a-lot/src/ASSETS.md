# Asset Attribution and Licensing

This file tracks external assets used by the project and their license requirements.

## Current Asset Inventory

At the moment, the MVP uses primitive geometry and text rendered directly in Phaser.
No external image, font, or audio asset is currently bundled in `src/`.

## Attribution Rules for Future Contributions

When adding external assets, update this file with:

- Asset name and type (image, sprite sheet, audio, font, etc.)
- Source URL
- Author or publisher
- License type
- Required attribution text (if any)
- Usage location in the codebase
