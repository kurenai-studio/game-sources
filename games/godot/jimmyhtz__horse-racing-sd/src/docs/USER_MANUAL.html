Quick start

Launch Horse Racing and play SD mode with whole virtual credits. The game has no real-money deposits, payments or redemption. Only Player 1 starts IN on a fresh installation.

Select a player's summary to open their betting console. If the seat is OUT, use IN to join. Press the upper part of a round BET button to add credits to a pair, or the bottom arrow to remove credits. A bright border marks a wager.

Choose READY when satisfied. When every participating seat is Ready, select START RACE. Enter the Start PIN if the manager has enabled it. The race locks the wagers.

The first two horses make the winning pair in either order. Watch the credits count up and choose Return to Betting. A close contest for second may get a replay.

F1 opens help. In Settings, hover over or focus a setting and press F1, or select its question-mark button. F8 opens Settings and F11 toggles fullscreen.

Betting and Ready

SD uses a quinella. A 1-2 ticket wins when horses 1 and 2 take the first two places in either order. Each payoff is the total return per winning credit, including that credit's stake. A 10x payoff on a one-credit winning ticket returns 10 credits. That is 9 credits above the stake.

Available credits and reserved wagers are tracked separately. The wager-arrow increment applies to both the add and subtract regions. Clear bets releases draft wagers.

Selecting another player's summary keeps your draft bets and requests the destination player's PIN if set. You may turn Ready off and change a wager until the start locks the round. A player needs credits or a reserved wager to join. OUT removes participation.

Players and PINs

The player editor lets you choose nicknames, avatars and unique color combinations. Enter the same four digits twice to replace a player PIN. Leaving both fields blank preserves the existing PIN. Player and manager PIN edits apply on Return to Game.

If a player forgets a PIN, open Settings from that player's PIN prompt. After the manager unlocks Settings, that player's page opens with the replacement field focused. Save the new PIN with Return to Game to return to the player's PIN prompt.

A player PIN protects access to that seat. The Start PIN is requested when Manager-only start is enabled. Settings and the protected operator and payout functions have separate purposes. These PINs are safeguards for a shared local game.

Settings profiles

Use the Settings menu or search across sections. Active preferences apply immediately. Revert restores preferences from entry to Settings. Reset and preset actions describe their scope before confirmation.

Named profiles store general preferences, such as audio, display and Race Control. Use Save, Replace, Rename, Delete, Import or Export in Saved profiles. Profile names are 1 to 40 characters. Applying a profile preserves balances, locked wagers, account PINs and game progress. Numbered virtual styles are part of the game save.

A dimmed catalog control labeled Planned is disabled and does nothing. Some placeholders point to a working action or editor elsewhere.

Saved games

The current game saves locally. Settings > Save Game records a named game, and Load Game opens the saved-game library. The full game save carries players, credits, wagers, general settings, card rotation and virtual-player configuration.

Use Export game file in the saved-game library to make a portable .sdgame file and Import game file to restore it as a separate game. Import restores that game's settings and progress. The local named-profile library stays available. Share save files only with people you trust because they can carry player and account information.

New Game saves the current game first. It carries over the current settings, identities, PINs, active seats and virtual styles, starts players at 100 credits, and begins fresh wagers, results and rotation. Saving and switching games is available between races.

The game keeps a backup of the current save. If loading reports damage, preserve the original and backup. A locked race is recovered from its saved state so restarting cannot reroll locked wagers.

Virtual credits and operator actions

Reload opens the operator's controls to add, remove or set a seat's virtual credits. The operator can settle or cancel a pending cash-out. A cash-out freezes credits for that operator action and cancels unconfirmed wagers. All of these actions concern game credits only.

Operator changes are available between races. The operator console has its own PIN. The protected payback controls use a separate PIN.

Card selection and long-run payback

The protected configuration queues the next card rotation. The selected average payout percentage is a long-run target for the saved rotation. It is separate from a displayed pair payoff, and individual cards and sessions can vary. Choosing particular cards or changing stake by card can change a player's average.

The target range is 70% through 200%. Select SD source cards to use the corrected historical fan collection at 80%, with Variable cards at other targets. Select Variable cards to use the generated collection at any target. The historical collection is based on the available corrected cards and does not establish factory frequencies.

Use for next round starts the new rotation on the next betting card. Current bets retain their quoted payouts. Each saved game has its own cards and rotation, and race results do not select future cards.

Race Control

Lead changes and Average field separation alter pace across the full course. They work together. With both at True random, horses use the original movement pattern. Higher Lead changes gives more opportunity for visible swaps without requiring any particular number. Higher separation tends to spread the field.

The pacing controls preserve the finish identities and winning chances. Race duration and replay settings change presentation. The Photo-finish target calibrates a separate replay decision from the gap behind second and reflects the active pace setup.

The target is approximate across many races, not a quota. Its default is 20%. Set Replay travel and Photo replay duration on the Replay page to control what happens after a race qualifies.

Race playback and result

Start Race locks wagers and prepares the recorded movement. Nominal race duration controls the time to the result in normal playback. Horses keep moving during the run-out. The normal race finishes before a qualifying replay begins.

Position guides draw a faint line at each nose beneath the figures. You can make the guides brighter and adjust horse size, lane spacing, number size or the finish stripe for readability.

The first two numbers identify the winning pair. Winning combinations highlight in the payoff strip and on player tickets. Reduced motion and Reduce flashing can keep those highlights steady.

Photo finish and replay

At the instant the second horse reaches the tape, the game measures the gap to the closest horse behind it. A close first/second finish alone does not qualify because their order leaves the winning pair unchanged. Photo-finish target in Race Control governs qualification.

Replay travel looks backward through the recorded movement to find the chosen number of horse lengths covered by the second-place horse. The displayed horse size contributes to that length. Photo replay duration determines how long that window plays, with extra slowdown near the tape. A longer duration makes the same movement slower. Neither control changes eligibility.

The replay camera frames all five horses and stops when the second horse's nose reaches the finish. The decision hold controls how long the frozen photo is shown before payout presentation proceeds. Use monochrome, number enlargement or second-place highlighting to make the decision easier to see.

Announcers and subtitles

Race calls the action and confirms the result. House handles the payout. Betting stays silent. Choose an automatic or named installed voice and try Test race voice or Test house voice. Separate mute and volume controls are on Audio.

Humor, sarcasm, energy and detail blend independently for each role. They influence phrase selection, and energy also influences excited delivery. The director may speed up a call, up to 1.6x, to fit its window. Timing, available phrases, talkativeness and voice spacing affect how many calls you hear.

Windows uses installed SAPI voices and measures the length of locally prepared audio clips. macOS and Linux use installed native system voices with estimated speaking times. Linux requires a working Speech Dispatcher service and voice. If a voice is missing or a sample is silent, check Master volume and the role's mute and volume, then try a listed voice. Subtitles are available independently of audible output.

Sounds and the start signal

Bell is the SD default. Horn uses First Call, also called Call to the Post. Horn and bell plays both. Off skips the signal. The selected signal finishes before the race motion begins.

Mechanical and hoof sounds have separate switches and volume sliders. Master volume controls the combined output. Celebration sound follows the largest award, while each player's counter shows their own return.

Display, camera and accessibility

Use Windowed, Maximized or Fullscreen. Window resolution selects a size for Windowed mode. F11 toggles fullscreen. Increase interface text, control sizes or horse numbers for readability.

The working camera controls adjust seated height and normal track zoom. The other camera direction controls shown as Planned are disabled.

Frame rate, synchronization and unfocused frame rate affect rendering load and smoothness. They do not change the recorded race.

Virtual players and numbered styles

On the betting screen, use a seat's V control to cycle through numbered styles and the two random modes, then back to human control. A virtual seat marks itself Ready and has no credit account. Its bets are simulated and do not use the human seat's credits.

In Virtual player styles, select a seat and edit its selected numbered style. Each of the ten styles is shared by the seats that select it. Restore a numbered style with Return Style to defaults. Apply these edits on Return to Game.

Random Style: Fixed keeps its hidden personality while the mode is selected. Random Style: Each Race draws a fresh hidden personality for each race. Hidden personalities cannot be edited. The virtual player can choose no tickets if the style has zero appetite or no displayed payoff is in range, but it does not sit out automatically.

The styles use the public card, the seat's prior selections and the last public winner. They cannot see a future result. There is no rebuy or balance-fraction control for the simulated virtual seats.

Working numbered-style controls

Amount to bet sets a simulated stake budget. Amount variation changes that budget across races. Favorites to longshots shifts preference from lower to higher payoffs. Spread across combinations increases the number of candidates selected, subject to Maximum combinations.

Random choice strength makes payoff-based weighting more even. Repeat previous selections favors the seat's last choices. Follow last winning pair gives the last winning combination more weight when it qualifies.

Minimum and Maximum preferred payoff set the inclusive range of eligible return multipliers, from 2x to 200x. Minimum must be at or below Maximum. A pair outside the range cannot be selected.

SD mode and planned features

Horse Racing 0.22.0 uses SD mode and quinella wagering. Live Track, Off-Track TV and other wager types are shown as Planned and cannot be selected.

Some planned fields have an active equivalent elsewhere. Use Save Game and Load Game for named games, the Announcers page to test voices, and the betting-panel V control and Virtual player styles page for simulated players.

Local diagnostics

The game keeps cumulative local diagnostics. Settings > Export Log creates a ZIP for troubleshooting. The archive can include game activity, player nicknames and settings. Review it before sharing.

Local diagnostic history does not travel with a game file. Imported games can accumulate their own history on the destination computer. The logging catalog controls labeled Planned are disabled.

Race Control

  • Lead changes
  • Average field separation
  • Photo-finish target

Lead changes

Adjusts variation in each horse's stride across the race so the lead can change more often. It works with Average field separation. Both at True random restore the original movement pattern. Finish identities and winning chances stay the same.

Average field separation

Adjusts how spread out the field tends to look, including near the finish. It combines with Lead changes and can change the visible gap behind second place. The replay threshold is calibrated for the pacing setup. The winning pair and winning chances stay the same.

Photo-finish target

Targets the approximate percentage of races reviewed. At the second horse's crossing, the game compares the closest remaining nose with a calibrated gap. A first-versus-second gap alone does not count. The 20% midpoint is a target across many races. Travel and duration only affect replays already selected.

Photo replay duration

Sets how many seconds a qualifying replay takes to cover its recorded travel window. More seconds make the same travel slower. The replay slows near the tape and stops when second place reaches it. Eligibility is set by Photo-finish target.

Replay travel, horse lengths

Sets how far back to begin a qualifying replay, measured in displayed horse lengths traveled by the second-place horse before its nose reaches the finish. It changes the travel window, not the time or qualification rule. Photo replay duration sets the playback time.

Photo decision hold, seconds

Sets the length of the frozen decision phase after replay motion stops, before payout.

Monochrome photo finish

Uses monochrome for the frozen finish photo.

Enlarge photo numbers

Amount to bet

Sets a simulated stake budget up to 200 credits. Zero produces no tickets. Amount variation can change the budget from race to race.

Favorites to longshots

Move toward Favorites to favor lower displayed payoffs or toward Longshots to favor higher payoffs. Random choice strength blends that preference toward equal weighting.

Spread across combinations

Higher spread can select more eligible pairs. Maximum combinations and the simulated stake budget cap how many can be selected.

Random choice strength

Makes weighting by payoff more even. Repeating a prior selection or following the last winner can still favor a qualifying pair.

Amount variation

Changes how much the simulated stake budget varies from one race to the next.

Repeat previous selections

Gives the seat's previous selections extra weight when they still qualify under the current card and payoff range.

Follow last winning pair

Gives the most recent public winning pair more weight if it is eligible under the current payoff range.

Maximum combinations

Caps the number of different simulated tickets from 1 to 10. Spread and the budget can result in fewer.

Minimum preferred payoff

Sets the lowest eligible total return multiplier, from 2x to 200x. It must be at or below Maximum preferred payoff.

Maximum preferred payoff

Sets the highest eligible total return multiplier, from 2x to 200x. It must be at or above Minimum preferred payoff.
