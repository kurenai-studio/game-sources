# Somnicard 2.1.1

一款离线的竖屏德州扑克练习游戏，使用虚拟筹码。

## 主要变化

- 输入下注金额时弹出数字键盘：按筹码显示时是 0–9 数字键盘，按 BB 显示时带小数点。牌桌和训练室都适用。
- “进阶”电脑对手更强：权益估算更稳定，双人桌按钮位开局更宽。在同牌对比测试中，新进阶对旧进阶约 +14 BB/100，对标准约 +30 BB/100。
- 内部代码整理，训练室和牌桌的功能与操作不变。

## 安装

可以直接覆盖安装 2.1.0 正式版（包名 `com.somnicard.game`），记录会保留。从旧试用版迁移的方法与 2.1.0 相同：在旧版“设置 → 数据与备份”导出，装好后在同一位置导入。

请将下载文件的 SHA-256 与附带的 `.sha256` 文件核对。
