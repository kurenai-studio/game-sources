Developer phrase editor

This offline tool edits the announcer library for the developer. It is not a game-manager feature. No file is changed until you export and replace the library yourself.

Import the current library first.

Categories control race situation and speaker. Race handles start, position changes, the finish and the official result. House handles small wins, jackpots and no-winner results. Personality values may overlap. The game checks current positions, measured audio duration and the next event before speaking.

Validation checks structure and placeholders. It cannot judge whether new wording makes sense, so test every new line with its intended race situations before shipping. Do not hard-code horse numbers or promise a result in an unfinished race.
