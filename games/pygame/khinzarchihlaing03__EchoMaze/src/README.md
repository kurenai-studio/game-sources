# EchoMaze – A Time-Loop Puzzle Game

## 1. Project Overview
EchoMaze is a 2D puzzle game made with Python and Pygame. Players need to find a way out of a maze by using their past movements. The game allows players to create ghosts that repeat their previous actions and help them solve puzzles.

## 2. Motivation
I enjoy playing puzzle games because they require creative thinking and problem solving. But most traditional maze games focus on finding a path from the starting point to the destination. So I wanted to create a puzzle game that introduces a different way of solving problems. I also want to learn more about game development and improve my Python programming skills.

## 3. Goal
Build an open-source 2D puzzle game using Python and Pygame where players can record and replay their movements. The game will allow players to create ghost characters that repeat previous actions to solve puzzles, activate switches, open doors, and escape mazes.

## 4. Main Features

### Basic Game
- Move the player using arrow keys or WASD.
- Each level contains walls, doors, switches, and exits.
- Add collision detection so players cannot move through walls.
- Create multiple puzzle levels with increasing difficulty.

### Time-Loop System
- Record the player's movements during each time loop.
- Allow players to restart time and create a ghost character.
- Make ghosts automatically repeat the recorded movements.
- Allow ghosts to activate pressure plates and open doors.
- Support multiple ghosts so players can solve more complicated puzzles.

### Other Features
- Add a main menu and restart button.
- Show the number of time loops used.
- Save completed levels.
- If time remains, add sound effects, animations, and a level editor.

## 5. Development Tools
- **Python:** Main programming language
- **Pygame:** Game development
- **JSON:** Store level data and game progress
- **GitHub:** Share the project as open-source software

## 6. Expected Result
The expected result is a complete and playable 2D puzzle game in which users can solve maze challenges by cooperating with their past actions.

## 7. Conclusion
EchoMaze combines traditional maze gameplay with a creative time-loop mechanic. Through this project, I aim to develop a functional and enjoyable open-source game while applying Python programming, algorithms, and software development concepts.
