# gd-game-3d-maze
Godot Game - 3D Maze

Can you escape a DFS maze(EZ) or survive a Prim maze(Hard)? Then crank up X, Y, and Z and see how far you can go.

> GLHF, Don't be lost

## Controllers

- Left joysticks : movements: go up, down, left and right

- Right Buttons: (green) Change view to left, right, top, bottom. (blue) rotate left and right

> Blue keys can be use to change X/Y/Z and Start Game (left blue key : hard mode/-1,  right blue key: easy mode/+1)

## Install , Download and Run

- Install Godot on your phone; [GODOT DL PAGE](https://godotengine.org/download/android/) or [GOOGLEPLAYSTORE](https://play.google.com/store/apps/details?id=org.godotengine.editor.v4)

- Download [TohidEq/gd-game-3d-maze](https://github.com/TohidEq/gd-game-3d-maze/archive/refs/heads/main.zip) or clone it in your phone

> And extract it somewhere idk...

- Open Godot and select "Import" btn, go to the unzipped directory of [TohidEq/gd-game-3d-maze](https://github.com/TohidEq/gd-game-3d-maze/archive/refs/heads/main.zip) and then select `project.godot` and done

- Top right of the Godot app, u can click on PLAY icon and game will start on your phone
