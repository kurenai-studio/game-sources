# Pong for TIC-80

Simple 2-player pong game for the TIC-80 fantasy console.

## Controls

Keyboard controls for both players:

- Player 1
    - A (up)
    - X (down)

- Player 2
    - Up
    - Arrow down

## Installation

Grab the latest [pong.tic](https://github.com/poyo86/pong.tic/releases/latest/download/pong.tic) file and load it on TIC-80
