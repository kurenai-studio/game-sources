本轮仅更新本地工作区。在线试玩尚未更新，战斗判定、攻击节奏、预警时长、资源和存档格式保持兼容。


## 本轮实现

### 动作与驱动

- `Clip.transition` 按动作配置过渡：受伤 25 ms、挥剑 35 ms、普通恢复 120 ms；中断从当前输出姿态继续，并保留受限的离开速度，避免突然停住。
- `Animator.update` 新增可选的实例标识；`ActorInput.instance` 为同一次攻击提供稳定身份。主控在攻击开始时锁定空中或地面动作，落地不重新蓄力，新的攻击仍重新派发装饰事件。
- 两段挥剑加入肩胯、后手反向平衡和身体伸缩；移动攻击使用上身遮罩，下身继续步态。冲刺压低重心，受伤压缩躯干后恢复。
- 苔影加强蹬地扑击，玻璃蛾区分收翼和俯冲并修正左右倾斜，守卫强化举身、砸地和根足重量。砸地下挥在原有 1.05 秒预警结束时接触地面，与根浪生成时刻一致。
- 刀光由实际剑尖与握柄位置生成，运动速度影响亮度和线宽。装饰事件不负责伤害，也不新增命中停顿。

### 支撑与绘制

- 步态只累计地面有效位移，排除冲刺、受伤和腾空；敌人以实际位移计算动画速度。
- 停步摆动脚在 80 ms 内落下，转向保留世界坐标支撑点，非支撑脚限制每次模拟步的位移。
- `ActorInput.support` 可提供平台标识和位置；脚部锚点随平台移动。双腿共同修正骨盆，再求解 IK，完整身体一起移动。
- `canvas.ts` 使用轻量部件数据，角色在自己的固定大小 Canvas 上合成，再以一个对象绘入主画布。姿态未改变时复用合成结果；不创建逐帧纹理或显示对象。主控和普通敌人使用 512×512 合成画布，守卫使用 1024×1024，均按 2 倍局部分辨率绘制。
- Canvas 与可选 WebGPU 后处理消费相同画面；减少动态效果保留动作和预警，降低装饰摆动、残影与粒子。

## 对照与复现

基线保存在忽略目录 `artifacts/action-a-round2/baseline`，是第二轮改动前的 ACTION-A，并非最初固定帧版本。录像各 720 帧、30 fps、24 秒，模拟固定为 120 Hz；通过逐帧截图编码，采集速度不改变视频时长。四段分别展示主控、苔影、玻璃蛾和守卫；场景定位属于视觉对照，完整通关另由浏览器回归验证。

先在另一个终端启动已保存的基线：

```powershell
npx vite artifacts/action-a-round2/baseline --port 5176 --host 127.0.0.1
```

录像需要 FFmpeg，可设置 `FFMPEG` 为可执行文件路径；未设置时，脚本尝试使用本机 Python 的 `imageio-ffmpeg`。它仅用于开发录像，不是游戏依赖。

```powershell
python -m pip install imageio-ffmpeg
$env:ACTION_A_OUTPUT='artifacts/action-a-round2'
$env:FIXED_CAPTURE='1'
$env:ACTION_A_VARIANT='before'
$env:PLAY_URL='http://127.0.0.1:5176'
node scripts/action-a-review.mjs
$env:ACTION_A_VARIANT='after'
$env:PLAY_URL='http://127.0.0.1:5173'
node scripts/action-a-review.mjs

# 性能测量应单独运行，关闭录像和其他测试。
$env:BASELINE_PORT='5176'
$env:REQUIRE_CPU_GAIN='1'
node scripts/action-a-performance.mjs
node scripts/action-a-report.mjs
```

性能脚本分别记录动作计算、场景更新、Canvas 绘制和整帧处理 P95；整帧处理是 PRE_STEP 至 POST_RENDER 的墙钟时间，含提交与可能的 GPU 等待，不是操作系统 CPU 利用率。

## 验收与边界

第二轮整体验收：37 项单元测试、59 项完整浏览器回归、TypeScript、生产构建、格式检查与生产入口隔离检查通过。原生 WebGPU 实际运行通过，未跳过；同步对照页已验证两段均为 24 秒，并能同步四分之一速播放与暂停，无请求失败或页面错误。

### 继续精修

- 空中挥剑增加身体旋转、后手反向平衡和连续收腿；剑骨骼补偿旋转，保持 85 ms 命中姿势的刀刃方向。落地后的移动攻击保留这一旋转，避免突然摆正。
- 守卫的冲锋片段覆盖实际最长 1.15 秒阶段，在起势后保持前倾和根足推进，直到游戏逻辑进入恢复。
- 停步脚在落脚完成的那一帧保持目标位置，避免跳回默认站姿。覆盖 29 个步态停止时机，并同时反向，脚部单步最大位移实测约 1.25 个世界像素。
- 动画实例复制支撑平台输入，支持调用方复用并修改同一个平台对象，避免前后帧坐标被一起覆盖。
- 本次精修后：39 项单元测试通过；16 项动作、Boss 与完整三碑路线专项回归通过；构建、格式及生产入口隔离检查通过。前述 59 项是精修前的整套运行记录，不将专项结果混计为新的一次全套运行。

- 单元测试覆盖跨角度插值、循环、遮罩、中断、实例身份、事件去重、暂停重置、阻尼、IK 和守卫砸地接触时点。
- 浏览器专项覆盖双向走跑、支撑脚 3 像素约束、移动平台、攻击跨落地、暂停恢复、全部动作的有限姿态与合成画布边界、对象池稳定性。
- 仍须结合正常速度和四分之一速度录像确认动作美感；几何与自动回归不能替代人的审美验收。
- 支撑系统针对现有水平平台，不提供斜坡、旋转平台或通用动画编辑器。性能结论只代表指定本机场景；无原生 WebGPU 适配器时必须记录跳过。

最终测量和测试结果见项目下的本地报告 `artifacts/action-a-round2/performance.json`、`verification.json` 及同步对照页。录像中间帧默认清理，仅保留视频和代表截图；设置 `KEEP_CAPTURE_FRAMES=1` 可保留逐帧图片。
