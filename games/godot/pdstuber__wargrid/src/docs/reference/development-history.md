## Demo scene notes (M2 controls, M3 base controls)

`game/` contains a custom-drawn desert scene, engine-light simulation and explicit test suites. `tools/` contains launch/test wrappers and replay comparison. M3 extends authoritative snapshots with copied economy records, integer work/timers and command results. Economy contracts live in [M3 plan](../superpowers/plans/2026-11-02-m3-base-supplies.md); movement contracts live in [M2 plan](../superpowers/plans/2026-11-01-m2-groups.md); [M1 plan](../superpowers/plans/2026-11-01-m1-vehicle.md) and [M0 plan](../superpowers/plans/2026-11-01-m0-foundation.md) record baseline contracts.

M2 controls: left-click or drag selects; Shift adds, empty click/Escape clears. Right-click sends one group move. WASD/arrows pan; wheel selects zoom 0.5/1/2. Selection freezes camera until release/cancel. B toggles authored obstruction for repath testing; occupied edits reject with HUD feedback. Twenty vehicles start on 16×16 map. HUD shows selected/moving/pending/arrived/blocked counts. Prototype choices and limits live in [movement note](movement.md) and [group movement](group-movement.md).

M3 base controls: select builder, press 1/2/3 for reactor/depot/factory placement; hover snaps preview, left release submits once, Escape/right cancels. Placement/selection freeze pan/zoom. Right-click unfinished owned foundation resumes; collector right-click source gathers; ordinary ground click moves. Select building for Produce/E, exact-entry queue Cancel or unfinished-construction Cancel. HUD reports credits, power, work, queues and immediate/due rejection. B has no base-scene effect.
