### A fun game made with pygame where your goal is to climb as high as possible.

## Run the game
```
git clone https://github.com/timodev96/Hack-Jumper.git
cd Hack-Jumper
pip install -r requirements.txt
python main.py
```
## or just download the [`.exe`](https://github.com/timodev96-alt/Hack-Jumper/releases/tag/Main)
