**Description (≤4000):**
BloomGrid is a calm-but-tense block puzzle set in deep space. Drag three pieces onto an 8x8 grid. Complete a full row or column to clear it. Chain clears for combos. Cross a row and a column in one move for a supernova.

Classic has no timer. Race adds a countdown. Spin is limited per run.

No account required. This version is offline. Scores and an optional display name stay on the device.
